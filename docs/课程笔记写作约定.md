# 四门课程笔记的写作约定

## 标题

- 离散数学：`离散数学 · 主题`，例如 `离散数学 · 代数系统与群论`。
- CSAPP：`CSAPP · 第 N 章 · 主题`。
- 概率论与数理统计：`概率论与数理统计 · 笔记（一） · 主题`。
- 计算方法与优化：`计算方法与优化 · 笔记（一） · 主题`；习题用 `习题 1`。

修改展示标题不必重命名文件。发布日期按原计划保留。

## 结构

以群论篇为参照：导读、学习重点、编号章节、定义与结论、证明与例题、复习检查或课后自测。

- 二级标题：`## 一、主题`。
- 三级标题：`### 1.1 主题`。
- 四级标题用于证明步骤、例题和代码讲解。
- 课件页码保留在相关标题或正文中，便于查找原资料。
- 不为统一排版删去证明、算法前提或未完成推导的说明。

## Fuwari 提示框

`note` 放定义、记号和背景；`important` 放定理、推论和关键结论；`caution` 放易错点；`warning` 放限制与风险；`tip` 放方法和学习重点。避免整节都放进一个提示框。

```markdown
:::note[定义：群]

定义内容。

:::
```

方括号不要转义。提示框起止行独占一行，并保持同一级缩进。若正文不是列表项的一部分，提示框应顶格书写。

## 答案与代码

短答案使用 `:spoiler[答案]`。跨段解析或包含块公式的证明使用：

```markdown
:::spoiler[答案与解析]

第一段解析。

$$
a^2+b^2=c^2
$$

:::
```

长答案默认折叠，支持点击和键盘展开。代码使用带语言名称的围栏；列表内代码的起止围栏与每行代码必须属于同一缩进层级。使用普通空格，不使用不间断空格。

## 表格与公式

- 表格行之间不留空行。
- 表格公式中的竖线写成 `\vert` 或 `\lvert`、`\rvert`，防止被当作列分隔符。
- 块公式前后的 `$$` 各自独占一行。
- 只在逻辑分组之间保留代码空行，避免每行代码后都插一个空行。

## 检查

运行 `node scripts/check-course-rendering.mjs` 检查四门课程，覆盖所有发布日期。检查公式错误、未解析的指令、表格、代码块内容、提示框数量与默认关闭的答案框。随后运行 `npm run build`，并核对生成页面中的标题和提示框。
