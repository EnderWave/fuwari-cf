## 1. 核心问题框架：当样本量 $n$ 增大时，样本均值会发生什么？

  

设 $X_1, \dots, X_n$ 独立同分布（i.i.d.），满足 $\mathbb{E}X_i = \mu$，$\text{Var}(X_i) = \sigma^2 < \infty$。在固定 $n$ 时，样本均值 $\bar{X}_n = \frac{1}{n}\sum_{i=1}^n X_i$ 仍然是一个随机变量（换一批样本，它的值就会变）。本章旨在回答关于 $\bar{X}_n$ 的四个核心问题：

  

| 核心问题 | 数学表达 | 对应理论工具 |

| :--- | :--- | :--- |

| **1. 会不会收敛？** | $\bar{X}_n \to \mu\ ?$ | 五种收敛方式、弱大数定律（WLLN）、强大数定律（SLLN） |

| **2. 误差缩小多快？** | $\|\bar{X}_n - \mu\| \approx\ ?$ | 方差 $\frac{\sigma^2}{n}$ 与标准误差（Standard Error）$\frac{\sigma}{\sqrt{n}}$ |

| **3. 极限是什么形状？** | $\frac{\sqrt{n}(\bar{X}_n - \mu)}{\sigma} \sim\ ?$ | 中心极限定理（CLT）、学生化（Slutsky）、一阶/二阶/多元 Delta Method |

| **4. 有限样本多可靠？** | $\mathbb{P}(\|\bar{X}_n - \mu\| \ge \varepsilon) \le\ ?$ | Markov 不等式、Chebyshev 不等式（严格上界）、Berry–Esseen 定理（近似误差界） |

  

## 2. 收敛的语言（Lecture 3.1）

  

### 2.1 五种随机收敛方式的定义与物理直觉

  

在抛公平硬币（$\mu = 0.5$）的重复模拟实验中，面对同一组数据（多条随 $n$ 演化的累计频率曲线 $\bar{X}_n$），不同的观察视角对应不同的数学收敛定义：

- **看一列（固定 $n$，横向看许多次重复实验）**：第 $n$ 步偏离 $0.5$ 超过 $\varepsilon$ 的比例有多大？ $\to$ **依概率收敛（$\xrightarrow{P}$）**

- **看一行（固定一条样本路径 $\omega$，一直做下去）**：这一次实验的轨迹最终会停留在 $0.5$ 吗？ $\to$ **几乎必然收敛（$\xrightarrow{\text{a.s.}}$）**

- **看形状（只看 $\bar{X}_n$ 的分布直方图）**：随 $n$ 增大，分布的整体形状趋近什么？ $\to$ **依分布收敛（$\xrightarrow{d}$）**

  

:::important[定义 3.1：五种随机收敛方式汇总]

设 $X_1, X_2, \dots$ 与 $X$ 为随机变量（除依分布收敛外，其余四种均要求定义在**同一概率空间**上）：

1. **依概率收敛（Convergence in probability）**：

   $$

   X_n \xrightarrow{P} X \iff \forall \varepsilon > 0,\ \lim_{n \to \infty} \mathbb{P}(|X_n - X| > \varepsilon) = 0

   $$

   - **直觉**：“明显偏离这件事越来越罕见”，并非“最终完全相等”，**允许某些路径在后面仍然偶尔跳出误差带**。

2. **依分布收敛（Convergence in distribution）**：设 $X_n, X$ 的累积分布函数（CDF）分别为 $F_{X_n}, F_X$，

   $$

   X_n \xrightarrow{d} X \iff \lim_{n \to \infty} F_{X_n}(t) = F_X(t) \quad \text{在 } F_X \text{ 的每一个连续点 } t \text{ 成立}

   $$

   - **直觉**：只比较分布函数的极限形状，**不要求变量在同一次实验中“配对接近”**（例如 $X \sim N(0,1)$，$-X$ 与 $X$ 分布完全相同，故 $-X \xrightarrow{d} X$，但在同一次实验中二者符号相反，距离绝不趋于 0！）。

3. **二次均值收敛（$L^2$ 收敛 / Convergence in quadratic mean）**：设 $\mathbb{E}[X_n^2] < \infty, \mathbb{E}[X^2] < \infty$，

   $$

   X_n \xrightarrow{L^2} X \iff \lim_{n \to \infty} \mathbb{E}\big[(X_n - X)^2\big] = 0

   $$

   - **偏差–方差分解（当极限为常数 $c$ 时）**：因 $\mathbb{E}[(X_n - c)^2] = \text{Var}(X_n) + (\mathbb{E}X_n - c)^2$，故：

     $$

     X_n \xrightarrow{L^2} c \iff \mathbb{E}X_n \to c \ \text{且}\ \text{Var}(X_n) \to 0

     $$

4. **$L^1$ 收敛（平均绝对误差收敛 / Convergence in mean）**：设 $\mathbb{E}|X_n| < \infty, \mathbb{E}|X| < \infty$，

   $$

   X_n \xrightarrow{L^1} X \iff \lim_{n \to \infty} \mathbb{E}|X_n - X| = 0

   $$

   - **与 $L^2$ 的对比**：$L^1$ 按原大小计入误差，$L^2$ 先平方再平均（将罕见大误差显著放大，对尾部极端值更敏感）。

5. **几乎必然收敛（Almost sure convergence, a.s.）**：

   $$

   X_n \xrightarrow{\text{a.s.}} X \iff \mathbb{P}\left\{\omega : \lim_{n \to \infty} X_n(\omega) = X(\omega)\right\} = 1

   $$

   - **直觉**：先固定一条样本路径 $\omega$，$(X_1(\omega), X_2(\omega), \dots)$ 就是普通实数列；所有收敛到 $X(\omega)$ 的路径构成一个概率为 $1$ 的集合（**允许存在概率为 $0$ 的例外不收敛路径**）。

:::

  

:::warning[高频考点：为什么依分布收敛只检查极限 CDF $F_X$ 的连续点？]

**经典算例**：考察退化常数列 $X_n \equiv 1/n$，其自然极限为常数 $X \equiv 0$。

- 二者的 CDF 分别为 $F_{X_n}(t) = \mathbf{1}\{t \ge 1/n\}$，$F_X(t) = \mathbf{1}\{t \ge 0\}$。

- 在 $t = 0$ 处：对任意 $n$ 都有 $F_{X_n}(0) = \mathbb{P}(1/n \le 0) = 0 \neq 1 = F_X(0)$！这是因为极限分布在边界点 $t=0$ 上集中了点质量，微小的 $1/n$ 偏移就会导致事件概率发生跳跃突变。

- 但 $t = 0$ 恰是极限分布函数 $F_X(t)$ 的**唯一跳点（不连续点）**！而在所有连续点 $t \neq 0$ 处（$t < 0$ 时恒为 $0$；$t > 0$ 时当 $n > 1/t$ 后恒为 $1$）均有 $F_{X_n}(t) \to F_X(t)$。因此**不在跳点处强求收敛**，才能保证 $1/n \xrightarrow{d} 0$ 这一符合直觉的结论成立。

:::

  

### 2.2 五种收敛方式的蕴含关系与四大必背反例

  

五种收敛方式的严格推导蕴含链条如下（顺箭头无条件成立，逆向或未画箭头方向一般不成立）：

$$

\begin{aligned}

L^2 \ (\text{均方误差}\to 0) &\implies L^1 \ (\text{平均绝对误差}\to 0) \implies P \ (\text{偏离概率}\to 0) \implies d \ (\text{分布函数收敛}) \\

\text{a.s.} \ (\text{几乎每条路径收敛}) &\implies P \ (\text{偏离概率}\to 0) \implies d \ (\text{分布函数收敛})

\end{aligned}

$$

  

:::tip[唯一重要的反向特例：极限为常数 $c$ 时，$d \implies P$]

一般情况下 $X_n \xrightarrow{d} X \nRightarrow X_n \xrightarrow{P} X$。**但当极限是常数 $c$ 时，依分布收敛等价于依概率收敛**：

$$

X_n \xrightarrow{d} c \iff X_n \xrightarrow{P} c

$$

**三行证明**：对任意 $\varepsilon > 0$，$\mathbb{P}(|X_n - c| > \varepsilon) \le \mathbb{P}(X_n \le c - \varepsilon) + \mathbb{P}(X_n > c + \varepsilon) = F_{X_n}(c - \varepsilon) + 1 - F_{X_n}(c + \varepsilon)$。因为 $c \pm \varepsilon \neq c$ 都是常数 $c$ 的 CDF $F_c(t) = \mathbf{1}\{t \ge c\}$ 的连续点，故随着 $n \to \infty$，两项分别趋于 $0 + (1 - 1) = 0$。

:::

  

为了彻底吃透为什么蕴含图中的箭头不能反向，必须掌握以下**四个教科书级反例**（设 $U \sim \text{Uniform}(0,1)$，所有变量在同一概率空间构造）：

  

| 否定方向 | 反例构造 | 关键指标计算 | 核心物理/数学洞察 |

| :--- | :--- | :--- | :--- |

| **反例一**：<br>$L^1 \nRightarrow L^2$<br>$P, \text{a.s.} \nRightarrow L^2$ | **高度为 $\sqrt{n}$ 的窄尖峰**：<br>$A_n = \sqrt{n}\,\mathbf{1}\{U < 1/n\}$ | $\mathbb{P}(A_n \neq 0) = \frac{1}{n} \to 0$<br>$\mathbb{E}\|A_n\| = \frac{\sqrt{n}}{n} = \frac{1}{\sqrt{n}} \to 0$<br>$\mathbb{E}[A_n^2] = (\sqrt{n})^2 \cdot \frac{1}{n} = 1 \nrightarrow 0$ | $A_n \xrightarrow{P, \text{a.s.}, L^1} 0$，但 $A_n \not\xrightarrow{L^2} 0$。偏离概率只看“是否偏离”而不管尖峰多高；二阶矩把高度平方后恰与概率 $1/n$ 抵消为常数 $1$ |

| **反例二**：<br>$P \nRightarrow L^1$<br>$\text{a.s.} \nRightarrow L^1, L^2$ | **高度提高到 $n$ 的窄尖峰**：<br>$B_n = n\,\mathbf{1}\{U < 1/n\}$ | $\mathbb{P}(B_n \neq 0) = \frac{1}{n} \to 0$<br>$\mathbb{E}\|B_n\| = n \cdot \frac{1}{n} = 1 \nrightarrow 0$<br>$\mathbb{E}[B_n^2] = n^2 \cdot \frac{1}{n} = n \to \infty$ | 对任意固定路径 $U(\omega)=u>0$，当 $n > 1/u$ 时区间 $[0,1/n)$ 缩到 $u$ 左侧，从此 $B_n(\omega) \equiv 0$，故 **$B_n \xrightarrow{\text{a.s.}, P} 0$**；但 $L^1, L^2$ 均不收敛！ |

| **反例三**：<br>$d \nRightarrow P$ | **对称反向配对**：<br>$X \sim N(0,1),\ X_n = -X$ | $F_{X_n}(t) = \Phi(t) = F_X(t)$<br>$\mathbb{P}(\|X_n - X\| > 1) = \mathbb{P}(\|X\| > 0.5) \approx 0.617$ | $X_n \xrightarrow{d} X$，但同一次实验中 $X_n$ 与 $X$ 距离为 $2\|X\|$，不随 $n$ 减小，故 $X_n \not\xrightarrow{P} X$ |

| **反例四**：<br>$L^2, L^1, P \nRightarrow \text{a.s.}$ | **逐层扫过 $[0,1]$ 的滑动块（打字机序列）**：<br>$T_{2^m+j}(\omega) = \mathbf{1}\left\{\frac{j}{2^m} \le \omega < \frac{j+1}{2^m}\right\}$<br>($m \ge 0,\ 0 \le j < 2^m$) | $\mathbb{E}T_n = \mathbb{E}[T_n^2] = 2^{-m} \to 0$<br>对任意固定 $\omega \in [0,1]$：<br>$\limsup_n T_n(\omega) = 1,\ \liminf_n T_n(\omega) = 0$ | $T_n \xrightarrow{L^2, L^1, P} 0$（每一步取 $1$ 的概率 $2^{-m}$ 越来越小）；但每个固定的 $\omega$ 在每一层 $m$ 都会**恰好被扫中一次而取 1**，永远在 $0$ 和 $1$ 之间反复跳动，无任何路径收敛！ |

  

### 2.3 期望何时能跟着依概率/依分布收敛？（渐近一致可积与截断法）

  

由反例二（或异常损失模型 $R_n$ 以 $1/n^2$ 概率取 $n^2$，其余取 $0$；$Y_n$ 以 $1/n^2$ 概率取 $n$，其余取 $0$）可知：虽然 $R_n \xrightarrow{P} 0$ 且 $Y_n \xrightarrow{P} 0$，但 $\mathbb{E}[R_n] = n^2 \cdot \frac{1}{n^2} = 1 \nrightarrow 0$，而 $\mathbb{E}[Y_n] = n \cdot \frac{1}{n^2} = \frac{1}{n} \to 0$。**出错频率下降并不自动带来平均损失下降，关键还要看尾部极端损失增长有多快！**

  

:::important[定理 3.2（All of Statistics 定理 5.19）：渐近一致可积与期望收敛]

1. **渐近一致可积（Asymptotic Uniform Integrability）**：若 $Z_n \xrightarrow{P} b$，且序列 $\{Z_n\}$ 的尾部期望满足：

   $$

   \lim_{M \to \infty} \limsup_{n \to \infty} \mathbb{E}\big[|Z_n|\,\mathbf{1}\{|Z_n| > M\}\big] = 0

   $$

   则必有 $\mathbb{E}[Z_n] \to b$。（*计算两层极限的顺序：先固定截断水平 $M > 0$ 让 $n \to \infty$，最后才让 $M \to \infty$！对 $R_n$，当 $n^2 > M$ 时尾部期望恒为 $1 \neq 0$；对 $Y_n$，当 $n > M$ 时尾部期望为 $1/n \to 0$。*）

2. **截断法（Truncation）的核心思想**：将非负变量拆为主体有界部分与尾部贡献：

   $$

   \mathbb{E}[Z_n] = \underbrace{\mathbb{E}\big[Z_n\mathbf{1}\{Z_n \le M\}\big]}_{\le \delta + M\mathbb{P}(Z_n > \delta)\ (\text{由依概率收敛控制})} + \underbrace{\mathbb{E}\big[Z_n\mathbf{1}\{Z_n > M\}\big]}_{\text{由渐近一致可积控制}}

   $$

3. **有界连续函数的期望收敛**：若 $X_n \xrightarrow{d} X$，且函数 $g$ **有界且连续**（如 $g(x) = \min(|x|, 1)$），则必有 $\mathbb{E}[g(X_n)] \to \mathbb{E}[g(X)]$。

:::

  

### 2.4 收敛的运算定理：连续映射、四则运算与 Slutsky 定理

  

:::important[定理 3.3–3.5：连续映射定理与 Slutsky 定理]

1. **连续映射定理（Continuous Mapping Theorem, 向量版）**：

   设 $\mathbf{Z}_n, \mathbf{Z} \in \mathbb{R}^k$，映射 $g: \mathbb{R}^k \to \mathbb{R}^m$ 的不连续点集为 $D_g$，且极限分布落在不连续点集上的概率为 0（$\mathbb{P}(\mathbf{Z} \in D_g) = 0$）。则：

   $$

   \mathbf{Z}_n \xrightarrow{P} \mathbf{Z} \implies g(\mathbf{Z}_n) \xrightarrow{P} g(\mathbf{Z}), \quad \mathbf{Z}_n \xrightarrow{d} \mathbf{Z} \implies g(\mathbf{Z}_n) \xrightarrow{d} g(\mathbf{Z}), \quad \mathbf{Z}_n \xrightarrow{\text{a.s.}} \mathbf{Z} \implies g(\mathbf{Z}_n) \xrightarrow{\text{a.s.}} g(\mathbf{Z})

   $$

   - **关键提醒**：① 连续映射保持 $P, d, \text{a.s.}$ 收敛，但**仅有连续性不自动保持 $L^1, L^2$ 收敛**！（反例：$R_n = \sqrt{n}\mathbf{1}\{U < 1/n^2\} \xrightarrow{L^2} 0$，但平方后 $g(R_n) = R_n^2 = B_n$ 的二阶矩 $\mathbb{E}[R_n^4] = 1 \nrightarrow 0$）；② 若极限落在不连续点上则失效（如 $X_n=1/n\to 0$，$g(x)=\mathbf{1}\{x>0\}$ 在 $0$ 处不连续，$g(X_n)=1 \nrightarrow g(0)=0$）。

2. **依概率收敛的和、积、商**：若在同一概率空间上 $X_n \xrightarrow{P} X$ 且 $Y_n \xrightarrow{P} Y$，由并集界 $\mathbb{P}(\max(|X_n-X|,|Y_n-Y|)>\varepsilon) \le \mathbb{P}(|X_n-X|>\varepsilon)+\mathbb{P}(|Y_n-Y|>\varepsilon) \to 0$ 得联合收敛 $(X_n,Y_n) \xrightarrow{P} (X,Y)$，再由连续映射立得 $X_n + Y_n \xrightarrow{P} X + Y$，$X_n Y_n \xrightarrow{P} XY$（**无需独立，也无需有限矩**）。

3. **$L^2$ 收敛的加法规则**：若 $X_n \xrightarrow{L^2} X$ 且 $Y_n \xrightarrow{L^2} Y$，由不等式 $(a+b)^2 \le 2a^2 + 2b^2$ 得 $\mathbb{E}|(X_n+Y_n)-(X+Y)|^2 \le 2\mathbb{E}|X_n-X|^2 + 2\mathbb{E}|Y_n-Y|^2 \to 0$，故 $X_n + Y_n \xrightarrow{L^2} X + Y$。

4. **Slutsky 定理（统计推断高频工具）**：设 $c$ 为**常数**。若 $X_n \xrightarrow{d} X$，且 **$Y_n \xrightarrow{P} c$（或 $Y_n \xrightarrow{d} c$）**，则：

   $$

   X_n + Y_n \xrightarrow{d} X + c, \qquad X_n Y_n \xrightarrow{d} cX, \qquad \frac{X_n}{Y_n} \xrightarrow{d} \frac{X}{c} \quad (c \neq 0)

   $$

   - **为什么常数 $c$ 如此特殊？** 因为当其中一项收敛到常数 $c$ 时，无需独立性即可自动保证联合依分布收敛 $(X_n, Y_n) \xrightarrow{d} (X, c)$！若两项都依分布收敛到非常数随机变量，仅凭边缘依分布收敛一般推不出和或积的依分布收敛。

:::

  

**课堂自测**：设 $U \sim \text{Uniform}(0,1)$，$A_n = \sqrt{n}\mathbf{1}\{U < 1/n\}$。问 $A_n^2$ 是否依概率收敛到 $0$？$\mathbb{E}[A_n^2]$ 是否趋于 $0$？为什么？

:spoiler[**解析**：因为 $A_n \xrightarrow{P} 0$ 且 $g(x) = x^2$ 处处连续，由连续映射定理立得 **$A_n^2 \xrightarrow{P} 0$**（事实上 $A_n^2 = n\mathbf{1}\{U < 1/n\} = B_n$，$\mathbb{P}(A_n^2 > \varepsilon) = 1/n \to 0$）。但 **$\mathbb{E}[A_n^2] = 1 \nrightarrow 0$**！这再次印证：依概率收敛可以经连续映射保持，但期望未必跟着收敛。]

  

## 3. 概率不等式与大数定律（Lecture 3.2）

  

### 3.1 Markov 不等式与 Chebyshev 不等式：分布未知时如何控制尾概率？

  

在现实工程中，变量的精确分布往往未知，但我们通常掌握部分矩信息（非负性、均值、方差）。掌握的信息越多，能换来的尾概率上界就越紧：

  

:::important[定理 3.6–3.7：Markov 不等式与 Chebyshev 不等式]

1. **Markov 不等式（只知非负 $Y \ge 0$ 与一阶矩 $\mathbb{E}Y < \infty$，上界按 $1/t$ 衰减）**：

   $$

   Y \ge 0,\ t > 0 \implies \mathbb{P}(Y \ge t) \le \frac{\mathbb{E}Y}{t}

   $$

   - **三行证明（示性函数放缩）**：因 $Y \ge 0$，对每个样本点恒有 $t\,\mathbf{1}\{Y \ge t\} \le Y$；两边取期望得 $t\,\mathbb{P}(Y \ge t) \le \mathbb{E}Y$，除以 $t > 0$ 即得。

   - **关键用法（先做非负严格递增变换 $g$，再用 Markov）**：若 $g \ge 0$ 严格递增且 $g(t) > 0$，则 $\mathbb{P}(X \ge t) = \mathbb{P}(g(X) \ge g(t)) \le \frac{\mathbb{E}[g(X)]}{g(t)}$。

     - 取平方化 $g(x) = x^2$ 作用于 $|X - \mu|$ $\implies$ **Chebyshev 不等式**；

     - 取指数化 $g(x) = e^{\lambda x}\ (\lambda > 0)$ $\implies$ **Chernoff 方法**：$\mathbb{P}(X \ge t) \le e^{-\lambda t}\mathbb{E}[e^{\lambda X}]$（利用 MGF 获得指数级衰减的紧界！）。

2. **Chebyshev 不等式（知道均值 $\mu$ 与有限方差 $\text{Var}(X) = \sigma^2 < \infty$，上界按 $1/t^2$ 衰减）**：

   $$

   \forall t > 0,\qquad \mathbb{P}(|X - \mu| \ge t) = \mathbb{P}\big((X - \mu)^2 \ge t^2\big) \le \frac{\text{Var}(X)}{t^2} = \frac{\sigma^2}{t^2}

   $$

   - **对比示例**：已知 $\mathbb{E}X = 100$，求 $\mathbb{P}(X \ge 120)$ 的上界。

     - 若只知 $X \ge 0$：用 Markov 得 $\mathbb{P}(X \ge 120) \le \frac{100}{120} \approx 0.833$；

     - 若再知 $\text{Var}(X) = 25$：用 Chebyshev 得 $\mathbb{P}(X \ge 120) \le \mathbb{P}(|X - 100| \ge 20) \le \frac{25}{20^2} = \frac{1}{16} = 0.0625$（界显著变紧！）。

   - **控制样本均值与充分样本量**：对 i.i.d. 样本，$\text{Var}(\bar{X}_n) = \sigma^2 / n$，代入 Chebyshev 得：

     $$

     \mathbb{P}(|\bar{X}_n - \mu| \ge \varepsilon) \le \frac{\sigma^2}{n\varepsilon^2} \quad \left(\text{对 } \text{Bernoulli}(p)\ \text{因 } \sigma^2 = p(1-p) \le \frac{1}{4},\ \text{有 } \mathbb{P}(|\bar{X}_n - p| \ge \varepsilon) \le \frac{1}{4n\varepsilon^2}\right)

     $$

:::

  

### 3.2 弱大数定律（WLLN）与强大数定律（SLLN）

  

:::important[定理 3.8–3.9：弱大数定律（WLLN）与 Kolmogorov 强大数定律（SLLN）]

设 $X_1, X_2, \dots$ 独立同分布（i.i.d.）：

1. **弱大数定律（WLLN）**：若一阶绝对矩有限 $\mathbb{E}|X_1| < \infty$，记 $\mu = \mathbb{E}X_1$，则样本均值**依概率收敛**到总体均值：

   $$

   \bar{X}_n \xrightarrow{P} \mu \iff \forall \varepsilon > 0,\ \lim_{n \to \infty} \mathbb{P}(|\bar{X}_n - \mu| \ge \varepsilon) = 0

   $$

   - **有限方差版的三行课堂证明**：当附加假设 $\text{Var}(X_1) = \sigma^2 < \infty$ 时，由 $\text{Var}(\bar{X}_n) = \sigma^2 / n$ 及 Chebyshev 不等式得 $\mathbb{P}(|\bar{X}_n - \mu| \ge \varepsilon) \le \frac{\sigma^2}{n\varepsilon^2} \to 0\ (n \to \infty)$，故 $\bar{X}_n \xrightarrow{P} \mu$。（*注：一般版 WLLN 只需 $\mathbb{E}|X_1| < \infty$，证明需用特征函数或截断法。*）

2. **强大数定律（Kolmogorov SLLN）**：在**完全相同的条件**（i.i.d. 且 $\mathbb{E}|X_1| < \infty$）下，样本均值**几乎必然收敛**到总体均值：

   $$

   \bar{X}_n \xrightarrow{\text{a.s.}} \mu \iff \mathbb{P}\left\{\omega : \lim_{n \to \infty} \bar{X}_n(\omega) = \mu\right\} = 1

   $$

:::

  

:::caution[两大常见误区与核心辨析]

1. **抛硬币次数增加后，究竟什么变稳定了？**

   设 $X_i \stackrel{\text{iid}}{\sim} \text{Bernoulli}(1/2)$，$S_n = \sum_{i=1}^n X_i$ 为正面总次数，$\bar{X}_n = S_n / n$ 为正面比例：

   - **比例偏差 $\bar{X}_n - 1/2$ 趋于 0**：其标准差为 $\text{SD}(\bar{X}_n) = \frac{1}{2\sqrt{n}} \to 0$；

   - **计数偏差 $S_n - n/2$ 越撑越开**：其标准差为 $\text{SD}(S_n) = \frac{\sqrt{n}}{2} \to \infty$（$n=100$ 时 $\text{SD}=5$，$n=10000$ 时 $\text{SD}=50$）。**大数定律保证的是“正反面比例趋近 $1:1$”，绝不是“正面次数与反面次数之差趋于 $0$”！**

2. **大数定律的一阶矩条件 $\mathbb{E}|X_1| < \infty$ 能省略吗？（Cauchy 反例）**

   设 $X_1, X_2, \dots \stackrel{\text{iid}}{\sim} \text{Cauchy}(0, 1)$（密度 $f(x) = \frac{1}{\pi(1+x^2)}$，满足 $\mathbb{E}|X_1| = \infty$）。

   由 Cauchy 分布的可加性与缩放性质：$S_n = \sum_{i=1}^n X_i \sim \text{Cauchy}(0, n)$，从而对任意 $n$：

   $$

   \bar{X}_n = \frac{1}{n}S_n \sim \text{Cauchy}\left(0,\ \frac{1}{n} \cdot n\right) = \text{Cauchy}(0, 1)

   $$

   **惊人结论**：无论样本量 $n$ 多大，Cauchy 样本均值 $\bar{X}_n$ 的分布始终与单个样本 $X_1$ 完全相同，丝毫不向 $0$（或任何常数 $c$）集中，大数定律彻底失效！

:::

  

#### 经典综合练习：未知均值下方差估计量的无偏性与相合性（Consistency）

  

设 $E_1, \dots, E_n \stackrel{\text{iid}}{\sim} F$，$\mathbb{E}[E_i] = b$，$\text{Var}(E_i) = \sigma^2 < \infty$。对比两个方差估计量：

$$

\tilde{\sigma}_n^2 = \frac{1}{n}\sum_{i=1}^n (E_i - \bar{E}_n)^2 = \frac{1}{n}\sum_{i=1}^n E_i^2 - \bar{E}_n^2, \qquad \hat{\sigma}_n^2 = \frac{1}{n-1}\sum_{i=1}^n (E_i - \bar{E}_n)^2 = \frac{n}{n-1}\tilde{\sigma}_n^2

$$

1. **有限样本无偏性对比**：由平方和分解 $\sum_{i=1}^n (E_i - \bar{E}_n)^2 = \sum_{i=1}^n (E_i - b)^2 - n(\bar{E}_n - b)^2$ 取期望得 $(n-1)\sigma^2$，故 $\mathbb{E}[\tilde{\sigma}_n^2] = \frac{n-1}{n}\sigma^2$（偏小），而 $\mathbb{E}[\hat{\sigma}_n^2] = \sigma^2$（无偏）。

2. **大样本相合性（依概率收敛）证明**：

   - 因 $\mathbb{E}[E_1^2] = \sigma^2 + b^2 < \infty$，由弱大数定律（WLLN）知 $\frac{1}{n}\sum_{i=1}^n E_i^2 \xrightarrow{P} \mathbb{E}[E_1^2] = \sigma^2 + b^2$，且 $\bar{E}_n \xrightarrow{P} b$；

   - 由连续映射定理（取连续函数 $g(x,y) = x - y^2$），立得 $\tilde{\sigma}_n^2 \xrightarrow{P} (\sigma^2 + b^2) - b^2 = \sigma^2$；

   - 又因确定性修正因子 $\frac{n}{n-1} \to 1$，故 $\hat{\sigma}_n^2 = \frac{n}{n-1}\tilde{\sigma}_n^2 \xrightarrow{P} 1 \cdot \sigma^2 = \sigma^2$。

   - **核心结论**：分母 $n-1$ 修正的是**有限样本无偏性**；在 $n \to \infty$ 时，**两个版本都具有相合性（都依概率收敛到真值 $\sigma^2$）**！

  

## 4. 中心极限定理（CLT）与 Delta Method（Lecture 3.3）

  

### 4.1 中心极限定理（CLT）：误差的自然尺度 $\sqrt{n}$ 与正态近似

  

既然大数定律告诉我们 $\bar{X}_n \xrightarrow{P} \mu$（原尺度的分布越来越窄，最终坍缩为单点常数 $\mu$），要想看清误差 $\bar{X}_n - \mu$ 的分布形状，就必须把它放大！

**为什么要乘 $\sqrt{n}$？** 因为 $\text{SD}(\bar{X}_n) = \frac{\sigma}{\sqrt{n}}$，只有乘以 $\sqrt{n}$ 后，放大误差的方差才恒定为非零常数：

$$

\text{Var}\big(\sqrt{n}(\bar{X}_n - \mu)\big) = n \cdot \frac{\sigma^2}{n} = \sigma^2

$$

  

:::important[定理 3.10：经典 i.i.d. 中心极限定理（Lindeberg–Lévy CLT）]

设 $X_1, X_2, \dots$ 独立同分布（i.i.d.），满足 $\mathbb{E}X_1 = \mu$，且**方差有限非零 $0 < \text{Var}(X_1) = \sigma^2 < \infty$**。则标准化样本均值依分布收敛到标准正态分布：

$$

Z_n = \frac{\bar{X}_n - \mu}{\sigma / \sqrt{n}} = \frac{\sqrt{n}(\bar{X}_n - \mu)}{\sigma} \xrightarrow{d} N(0, 1) \iff \forall z \in \mathbb{R},\ \lim_{n \to \infty} \mathbb{P}(Z_n \le z) = \Phi(z)

$$

- **LLN 与 CLT 的统一分解式**：$\bar{X}_n = \mu + \frac{\sigma}{\sqrt{n}} Z_n$（第一项 $\mu$ 由大数定律保证；第二项按 $\sigma/\sqrt{n}$ 缩小，其分布形状 $Z_n$ 由 CLT 刻画）。

- **大样本近似写法与记号红线**：当 $n$ 较大时，用于估算概率的近似记为 $\bar{X}_n \approx N\left(\mu, \frac{\sigma^2}{n}\right)$ 或 $S_n \approx N(n\mu, n\sigma^2)$。**严禁写成 $\bar{X}_n \xrightarrow{d} N(\mu, \sigma^2/n)$**（因为依分布收敛的右端必须是不随 $n$ 变化的固定极限分布！）。

:::

  

#### CLT 的四大实战细节：样本量计算、连续性修正、学生化与 Berry–Esseen 界

  

1. **用 CLT 四步法求样本量（对比 Chebyshev）**：

   设 $X_i \stackrel{\text{iid}}{\sim} \text{Bernoulli}(0.5)$（$\mu=0.5, \sigma=0.5$），求使 $\mathbb{P}(|\bar{X}_n - 0.5| \le 0.1) \ge 0.95$ 的样本量 $n$：

   - ① 标准误差：$\text{SD}(\bar{X}_n) = \frac{0.5}{\sqrt{n}}$；

   - ② 标准化：$\mathbb{P}(|\bar{X}_n - 0.5| \le 0.1) \approx \mathbb{P}\left(|Z| \le \frac{0.1}{0.5/\sqrt{n}}\right) = \mathbb{P}(|Z| \le 0.2\sqrt{n})$；

   - ③ 查标准正态分位点：$2\Phi(1.96) - 1 = 0.95 \implies 0.2\sqrt{n} \ge 1.96$；

   - ④ 解出 $n$：$n \ge (1.96 / 0.2)^2 = 96.04 \implies n = 97$。（*注：$n=97$ 是基于正态近似的样本量设计；而 Chebyshev 给出的 $n \ge 500$ 是不依赖正态近似的严格充分保证。*）

2. **连续性修正（Continuity Correction）：给每个离散整数分配一格宽度为 1 的连续面积**

   当用连续正态分布 $Y \sim N(n\mu, n\sigma^2)$ 近似整数取值变量 $S_n$（如二项分布）时，把每个整数 $k$ 对应到半格边界区间 $[k - 0.5, k + 0.5)$：

   $$

   \mathbb{P}(a \le S_n \le b) \approx \mathbb{P}\left(a - \frac{1}{2} \le Y \le b + \frac{1}{2}\right), \qquad a, b \in \mathbb{Z}

   $$

   - **算例**：抛公平硬币 $100$ 次（$S_{100} \sim \text{Bin}(100, 1/2)$，$\mu=50, \text{SD}=5$），求 $\mathbb{P}(45 \le S_{100} \le 55)$：

     - 未修正近似：$\mathbb{P}(-1 \le Z \le 1) = 2\Phi(1) - 1 \approx 0.6826$；

     - **连续性修正后**：$\mathbb{P}(44.5 \le Y \le 55.5) \approx \mathbb{P}\left(\frac{44.5-50}{5} \le Z \le \frac{55.5-50}{5}\right) = 2\Phi(1.1) - 1 \approx 0.7286$（与二项分布精确求和 $0.7287$ 几乎完全吻合！）。

   - **局限提醒**：相同样本量 $n=100$ 下，中心对称区间近似极佳，但若 $p=0.01$（稀有事件，$np=1$ 极度偏斜且贴近边界 $0$），正态近似会严重失真（此时应改用 Poisson 近似）。

3. **学生化（Studentization）：当总体标准差 $\sigma$ 未知时，用样本标准差 $\hat{\sigma}_n$ 替换为何依然渐近正态？**

   在实际问题中 $\sigma$ 往往未知，用样本标准差 $\hat{\sigma}_n = \sqrt{\frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X}_n)^2}$ 替换分母构造统计量 $T_n$：

   - ① 由相合性 $\hat{\sigma}_n^2 \xrightarrow{P} \sigma^2 > 0$ 及连续映射定理（$x \mapsto \sigma / \sqrt{x}$ 在 $\sigma^2 > 0$ 处连续），得修正因子 $\frac{\sigma}{\hat{\sigma}_n} \xrightarrow{P} 1$；

   - ② 拆成两个因子的乘积并应用 **Slutsky 定理**（$c = 1$）：

     $$

     T_n = \frac{\sqrt{n}(\bar{X}_n - \mu)}{\hat{\sigma}_n} = \underbrace{\frac{\sqrt{n}(\bar{X}_n - \mu)}{\sigma}}_{\xrightarrow{d} N(0,1)\ (\text{由 CLT})} \cdot \underbrace{\frac{\sigma}{\hat{\sigma}_n}}_{\xrightarrow{P} 1} \xrightarrow[\text{Slutsky}]{d} N(0, 1)

     $$

4. **Berry–Esseen 定理（CLT 近似误差的 $O(n^{-1/2})$ 有限样本上界）**：

   若 $\mathbb{E}|X_1 - \mu|^3 < \infty$，令归一化三阶绝对中心矩 $\rho = \frac{\mathbb{E}|X_1 - \mu|^3}{\sigma^3}$，则存在与分布无关的普适常数 $C$，使得：

   $$

   \sup_{z \in \mathbb{R}} \big|\mathbb{P}(Z_n \le z) - \Phi(z)\big| \le \frac{C\rho}{\sqrt{n}}

   $$

   例如对公平硬币 $\text{Bernoulli}(1/2)$，$\mathbb{E}|X_1 - 1/2|^3 = 1/8, \sigma^3 = 1/8 \implies \rho = 1$，$n=100$ 时一致误差上界为 $C/10$。

  

### 4.2 一阶、二阶与多元 Delta Method（光滑函数变换后的渐近分布）

  

当我们关心的指标不是样本均值 $\bar{X}_n$ 本身，而是它的某个非线性函数 $g(\bar{X}_n)$ 时，**连续映射定理只能给出 $g(\bar{X}_n) \xrightarrow{P} g(\mu)$（退化为常数）**。要想知道 $g(\bar{X}_n)$ 围绕 $g(\mu)$ 的**误差分布与标准误**，必须使用基于 Taylor 展开的 **Delta Method**：

  

:::important[定理 3.11–3.13：一阶、二阶与多元 Delta Method 完整汇总]

1. **一阶 Delta Method（当 $g'(\theta) \neq 0$ 时，切线斜率把误差线性放大或压缩，缩放尺度仍为 $\sqrt{n}$）**：

   若 $\sqrt{n}(T_n - \theta) \xrightarrow{d} N(0, \sigma^2)$，且函数 $g$ 在 $\theta$ 处可微，则由一阶 Taylor 展开 $g(T_n) - g(\theta) = g'(\theta)(T_n - \theta) + o_p(n^{-1/2})$ 得：

   $$

   \sqrt{n}\big[g(T_n) - g(\theta)\big] \xrightarrow{d} N\big(0,\ [g'(\theta)]^2 \sigma^2\big), \qquad g(T_n) \approx N\left(g(\theta),\ \frac{[g'(\theta)]^2 \sigma^2}{n}\right)

   $$

2. **二阶 Delta Method（当一阶导数消失 $g'(\theta) = 0$ 时，放大尺度从 $\sqrt{n}$ 变为 $n$，极限变为卡方型！）**：

   若 $g'(\theta) = 0$ 且 $g$ 在 $\theta$ 附近二阶可微，$\sqrt{n}(T_n - \theta) \xrightarrow{d} \sigma Z\ (Z \sim N(0,1))$，则展开至二阶项 $g(T_n) - g(\theta) = \frac{1}{2}g''(\theta)(T_n - \theta)^2 + o_p((T_n - \theta)^2)$。原本 $n^{-1/2}$ 的横向误差平方后变为 $n^{-1}$ 量级，故乘以 $n$ 得：

   $$

   n\big[g(T_n) - g(\theta)\big] \xrightarrow{d} \frac{1}{2}g''(\theta)\sigma^2 Z^2, \qquad Z^2 \sim \chi^2_1

   $$

   *注：此时若仍乘 $\sqrt{n}$，则 $\sqrt{n}[g(T_n)-g(\theta)] \xrightarrow{P} 0$（退化为常数 0）！*

3. **多元 CLT 与多元 Delta Method（梯度把多维椭圆误差云团投影到一维）**：

   - **多元 CLT**：设 $\mathbf{X}_1, \dots, \mathbf{X}_n \in \mathbb{R}^d$ i.i.d.，均值向量 $\boldsymbol{\mu}$，协方差矩阵 $\Sigma$，则 $\sqrt{n}(\bar{\mathbf{X}}_n - \boldsymbol{\mu}) \xrightarrow{d} N_d(\mathbf{0}, \Sigma)$。

   - **多元 Delta Method**：若 $\sqrt{n}(\mathbf{T}_n - \boldsymbol{\theta}) \xrightarrow{d} N_d(\mathbf{0}, \Sigma)$，且 $g: \mathbb{R}^d \to \mathbb{R}$ 在 $\boldsymbol{\theta}$ 处可微，则由局部线性化 $g(\mathbf{T}_n) - g(\boldsymbol{\theta}) \approx \nabla g(\boldsymbol{\theta})^\top (\mathbf{T}_n - \boldsymbol{\theta})$ 得：

     $$

     \sqrt{n}\big[g(\mathbf{T}_n) - g(\boldsymbol{\theta})\big] \xrightarrow{d} N\big(0,\ \tau^2\big), \qquad \tau^2 = \nabla g(\boldsymbol{\theta})^\top \Sigma \nabla g(\boldsymbol{\theta})

     $$

:::

  

#### 经典课堂算例精讲（一阶、二阶与多元 Delta Method）

  

1. **一阶算例（平均响应时间的平方根变换）**：设 $X_i \stackrel{\text{iid}}{\sim} \text{Exp}(1)$（$\mu = 1, \sigma^2 = 1$），定义 $T_n = \sqrt{\bar{X}_n}$。

   - 由 CLT：$\sqrt{n}(\bar{X}_n - 1) \xrightarrow{d} N(0, 1)$；

   - 取 $g(x) = \sqrt{x}$，则 $g(1) = 1$，$g'(x) = \frac{1}{2\sqrt{x}} \implies g'(1) = \frac{1}{2}$；

   - 代入一阶 Delta Method：$\sqrt{n}(T_n - 1) \xrightarrow{d} N\left(0, \left(\frac{1}{2}\right)^2 \times 1\right) = N\left(0, \frac{1}{4}\right)$，大样本下 $T_n \approx N\left(1, \frac{1}{4n}\right)$。

2. **二阶算例（平方误差统计量 $D_n = (\bar{X}_n - 1)^2$）**：承接上例，$h(x) = (x - 1)^2$ 在 $\mu = 1$ 处一阶导数 $h'(1) = 0$，二阶导数 $h''(1) = 2$。

   - 在 $\sqrt{n}$ 尺度下：$\sqrt{n}D_n = \frac{[\sqrt{n}(\bar{X}_n - 1)]^2}{\sqrt{n}} \xrightarrow{P} 0$（退化）；

   - 在 $n$ 尺度下：$nD_n = \big[\sqrt{n}(\bar{X}_n - 1)\big]^2 \xrightarrow{d} Z^2 \sim \chi^2_1$（非负、右偏的自由度 1 卡方分布，不再是正态！）。

3. **多元 Delta Method 压轴算例（精确率 $P$ 与召回率 $R$ 合成 $F_1$-score 的渐近波动）**：

   每次测试得到指标向量 $\mathbf{Z}_i = (P_i, R_i)^\top$ i.i.d.，已知总体均值与协方差矩阵为：

   $$

   \boldsymbol{\mu} = \begin{pmatrix} 0.8 \\ 0.6 \end{pmatrix}, \qquad \Sigma = \begin{pmatrix} 0.04 & 0.012 \\ 0.012 & 0.0225 \end{pmatrix}, \qquad F_n = g(\bar{P}_n, \bar{R}_n) = \frac{2\bar{P}_n \bar{R}_n}{\bar{P}_n + \bar{R}_n}

   $$

   - **步骤 1（样本均值向量的联合 CLT）**：$\sqrt{n}(\bar{\mathbf{Z}}_n - \boldsymbol{\mu}) \xrightarrow{d} N_2(\mathbf{0}, \Sigma)$；

   - **步骤 2（计算总体目标值）**：$g(\boldsymbol{\mu}) = g(0.8, 0.6) = \frac{2(0.8)(0.6)}{0.8 + 0.6} = \frac{0.96}{1.4} = \frac{24}{35} \approx 0.6857$；

   - **步骤 3（求梯度向量并代入 $\boldsymbol{\mu}$）**：

     $$

     \frac{\partial g}{\partial p} = \frac{2r(p+r) - 2pr}{(p+r)^2} = \frac{2r^2}{(p+r)^2}, \qquad \frac{\partial g}{\partial r} = \frac{2p^2}{(p+r)^2} \implies \nabla g(0.8, 0.6) = \begin{pmatrix} 2(0.6)^2 / 1.4^2 \\ 2(0.8)^2 / 1.4^2 \end{pmatrix} = \begin{pmatrix} 18/49 \\ 32/49 \end{pmatrix}

     $$

     *物理意义*：因 $32/49 > 18/49$，当 $P=0.8, R=0.6$ 时，综合指标 $F_1$ 对短板指标 $R$ 的局部变化更敏感！

   - **步骤 4（计算二次型渐近方差 $\tau^2$）**：令 $a = 18/49, b = 32/49$，

     $$

     \tau^2 = \nabla g(\boldsymbol{\mu})^\top \Sigma \nabla g(\boldsymbol{\mu}) = 0.04a^2 + 2(0.012)ab + 0.0225b^2 \approx 0.005398 + 0.005758 + 0.009596 \approx 0.020751

     $$

     故严格极限为 $\sqrt{n}\left(F_n - \frac{24}{35}\right) \xrightarrow{d} N(0, 0.020751)$，大样本下 $F_n \approx N\left(\frac{24}{35}, \frac{0.020751}{n}\right)$。

  

### 4.3 工具选择指南与特征函数证明 CLT 线索（补充 A & B）

  

**随堂总结：三大工具如何选择？**

1. **要严格保证（只知均值、方差，对一切满足条件的分布求尾概率上界或充分样本量）** $\to$ **Chebyshev 不等式**（例：公平硬币保证 $\mathbb{P}(|\bar{X}_n-0.5|\ge 0.1)\le 0.05$ 需 $n \ge 500$）；

2. **要近似计算大样本均值事件的概率（i.i.d. 且方差有限）** $\to$ **中心极限定理 CLT**（例：$X_i \stackrel{\text{iid}}{\sim} \text{Exp}(1), n=100$，求 $\mathbb{P}(\bar{X}_{100} \ge 1.2) \approx \mathbb{P}(Z \ge \frac{1.2-1}{1/\sqrt{100}}) = \mathbb{P}(Z \ge 2) \approx 0.023$）；

3. **已知统计量的渐近正态，求光滑非线性函数变换后的极限分布** $\to$ **Delta Method**（例：已知 $\sqrt{n}(T_n - 2) \xrightarrow{d} N(0, 9)$，$g(x)=\log x$ 在 $2$ 处导数 $g'(2)=1/2$，故 $\sqrt{n}(\log T_n - \log 2) \xrightarrow{d} N(0, 9 \times (1/2)^2) = N(0, 9/4)$）。

  

:::note[补充 A & B：为什么引入特征函数？有限方差下 CLT 的三步证明]

在 2.5 节中我们看到，矩母函数 $M_X(t) = \mathbb{E}[e^{tX}]$ 未必对所有分布存在。为了彻底解决存在性问题，引入复数域上的**特征函数（Characteristic Function）**：

$$

\varphi_X(t) = \mathbb{E}[e^{itX}] = \mathbb{E}[\cos(tX)] + i\,\mathbb{E}[\sin(tX)], \qquad i^2 = -1

$$

- **特征函数的三大王牌性质**：

  1. **总是存在**：因为模长 $|e^{itX}| = 1$，所以期望对**任何随机变量**都存在，无需任何矩条件；

  2. **独立求和变乘积**：若 $X \perp\!\!\!\perp Y$，则 $\varphi_{X+Y}(t) = \varphi_X(t)\varphi_Y(t)$；

  3. **唯一性与连续性定理（Lévy）**：特征函数唯一确定分布，且 $X_n \xrightarrow{d} X \iff \forall t \in \mathbb{R}, \varphi_{X_n}(t) \to \varphi_X(t)$。

- **有限方差下 CLT 的三步优雅证明**：

  1. **标准化**：令 $Y_i = \frac{X_i - \mu}{\sigma}$，则 $Y_1, \dots, Y_n$ i.i.d.，且 $\mathbb{E}Y_1 = 0, \mathbb{E}[Y_1^2] = \text{Var}(Y_1) = 1$。在 $u \to 0$ 时对 $\varphi_{Y_1}(u)$ 作二阶 Taylor 展开：

     $$

     \varphi_{Y_1}(u) = 1 + i(\mathbb{E}Y_1)u - \frac{\mathbb{E}[Y_1^2]}{2}u^2 + o(u^2) = 1 - \frac{u^2}{2} + o(u^2) \quad (u \to 0)

     $$

  2. **独立和变乘积**：因 $Z_n = \frac{\sqrt{n}(\bar{X}_n - \mu)}{\sigma} = \frac{1}{\sqrt{n}}\sum_{i=1}^n Y_i$，故对任意固定 $t \in \mathbb{R}$：

     $$

     \varphi_{Z_n}(t) = \left[\varphi_{Y_1}\left(\frac{t}{\sqrt{n}}\right)\right]^n = \left[1 - \frac{t^2}{2n} + o\left(\frac{1}{n}\right)\right]^n

     $$

  3. **取极限并调用连续性定理**：利用重要极限 $\lim_{n\to\infty} (1 + a/n)^n = e^a$，得：

     $$

     \lim_{n \to \infty} \varphi_{Z_n}(t) = e^{-t^2/2} = \varphi_{N(0,1)}(t) \implies Z_n \xrightarrow{d} N(0, 1)

     $$

:::

  

## 5. Python 仿真验证：二项分布连续性修正与多元 Delta Method

  

下面的脚本验证了抛 100 次公平硬币时连续性修正对正态近似精度的提升，以及精确率/召回率合成 $F_1$-score 的多元 Delta Method 渐近方差公式：

  

```python title="ch3_clt_delta_method_sim.py" {12-15,24-27}

import numpy as np

from scipy.stats import binom, norm

  

# 1. 验证 n=100, p=0.5 时 P(45 <= S_100 <= 55) 的精确值、未修正 CLT 与半格连续性修正

exact_prob = binom.cdf(55, 100, 0.5) - binom.cdf(44, 100, 0.5)

clt_raw = norm.cdf(1.0) - norm.cdf(-1.0)

clt_cc = norm.cdf(1.1) - norm.cdf(-1.1)

print(f"[Binomial(100, 0.5)] 精确值: {exact_prob:.4f} | 未修正CLT: {clt_raw:.4f} | 连续性修正: {clt_cc:.4f}")

  

# 2. 验证多元 Delta Method：F_n = 2*P_bar*R_bar / (P_bar + R_bar) 的渐近方差

rng = np.random.default_rng(2026)

mu = np.array([0.8, 0.6])

Sigma = np.array([[0.04, 0.012], [0.012, 0.0225]])

n_sample, n_trials = 400, 100_000

  

# 每次实验抽 n_sample 个样本，样本均值向量服从 N(mu, Sigma / n_sample)

z_bars = rng.multivariate_normal(mu, Sigma / n_sample, size=n_trials)

p_bar, r_bar = z_bars[:, 0], z_bars[:, 1]

f_n = 2 * p_bar * r_bar / (p_bar + r_bar)

  

grad = np.array([18 / 49, 32 / 49])

tau2_theory = grad @ Sigma @ grad

tau2_emp = n_sample * np.var(f_n)

print(f"[Multivariate Delta Method] 理论渐近方差 tau^2: {tau2_theory:.6f} | 模拟 n*Var(F_n): {tau2_emp:.6f}")
```
