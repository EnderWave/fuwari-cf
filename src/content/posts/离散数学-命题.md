## 导读

命题逻辑用符号表达陈述及其真假关系。本篇从命题符号化出发，讨论逻辑等价、范式、联结词与自然推理中的形式证明。

全章围绕**如何用形式化的代数与符号系统刻画人类逻辑推理**展开，分为五个核心板块：

1. **1.1 命题符号化（Slides 4–22）**：从自然语言的真假与悖论出发，定义原子命题与五种常用逻辑联结词，给出合式公式（WFF）的递归形式文法、运算符优先级与左结合约定，以及指派（Assignment）与真值表形式语义，并探讨可满足性问题（SAT）的指数级计算复杂度。

2. **1.2 永真公式与逻辑变换（Slides 23–40）**：将合式公式划分为永真式（重言式）、可满足式与矛盾式，建立逻辑等价（$\Leftrightarrow$）与永真蕴含（$\Rightarrow$）两大关系体系，深入辨析代入规则（全局变换）**与**替换规则（局部变换，仅对恒等式成立）的本质差异，并证明对偶原理与广义 De Morgan 定理。

3. **1.3 范式与主范式（Slides 41–59）**：通过消去蕴含/等值、内移否定、分配律展开构造析取范式（DNF）与合取范式（CNF），进而引入极小项（$m_i$）与极大项（$M_i$），证明**主析取范式（CDNF，**$\sum$**）与主合取范式（CCNF，**$\prod$**）的存在唯一性**，打通恒等式/不等式机械化证明的通用算法。

4. **1.4 联结词的扩充与归约（Slides 60–66）**：枚举 $2^{2^n}$ 种 $n$ 元真值函数，引入与非（NAND，$\uparrow$）、或非（NOR，$\downarrow$）与异或（XOR，$\oplus$），结合 C 语言位运算与 `x ^= x & -x`（lowbit 消去计数）算法，严格证明全功能集与极小全功能集（如 $\{\neg,\land\}$、$\{\neg,\to\}$、$\{\downarrow\}$、$\{\uparrow\}$）。

5. **1.5 推理与形式证明方法（Slides 67–84）**：给出有效结论 $H_1,H_2,\dots,H_n \vdash C$ 的 7 种等价刻画，通过“球赛推理”贯穿演示不等式链法、真值表法、主范式法、真假值正反推演法，最终建立自然推理的形式证明序列（含 P 规则、T 规则、附加前提 CP 规则与归谬反证法）及其归纳可靠性证明。

:::note[引子：为什么需要形式化的符号逻辑？（Slides 5–6）]

讲义开篇展示了荷兰版画家埃舍尔（M. C. Escher）的名作《画手》（*Drawing Hands*）：左手正在画右手，而右手同时又在画左手——这种自指（Self-reference）结构直接引出了逻辑学中的经典**悖论（Paradox）**。

* **自然语言的局限**：自然语言陈述往往伴随着歧义与模糊性，而逻辑学研究的是关于“真（True）”与“假（False）”的普遍规律。

* **形式逻辑（符号逻辑）**：用精确的数学符号代替自然语言句子，是现代数理逻辑的根基。现代数理逻辑（Mathematical Logic）包含四大核心分支：**公理集合论（Axiomatic Set Theory）**、**证明论（Proof Theory）**、**模型论（Model Theory）**与**递归论（Recursion Theory / 可计算性理论）**。

## 一、命题符号化、形式文法与形式语义（Slides 4–22）

### 1.1 命题（Proposition）的定义与判别（Slides 7–8）

:::note[定义]

**有唯一真假值**的**陈述句（Declarative Sentence）**称为**命题（Proposition）**。

:::

* **真值（Truth Value）**：命题的真或假称为它的值（真值），一个命题要么为真（True / $1$ / $\mathbb{T}$），要么为假（False / $0$ / $\mathbb{F}$），二者必居其一且不可兼得（二值逻辑原则）。

我们可以通过具体例子直观理解哪些句子是命题、哪些不是（Slide 8）：

| 句子示例 | 是否为命题 | 细分类型与原因解析 |
| ----- | ----- | ----- |
| “糖是碳水化合物。” | **是** | **简单命题（原子命题）**：客观事实陈述句，真值为真 |
| “武汉大学是最美丽的大学。” | **是** | **简单命题**：讲义将其归为陈述句形式的简单命题 |
| “如果不下雨，就开运动会。” | **是** | **复合命题**：由“不下雨”和“开运动会”两个简单命题通过逻辑联结词组合而成 |
| “现在几点？” | **否** | **疑问句**：不是陈述句，没有真假值 |
| “请不要讲话！” | **否** | **祈使句**：表示请求或命令，没有真假值 |
| “$x + y \le 4$” | **否** | **开语句（含自由变量的命题函数）**：在未给变量 $x, y$ 指定具体数值前，无法确定唯一真假值 |
| “我正在说谎。” | **否** | **说谎者悖论（Liar Paradox）**：若该句为真，则“我在说谎”为真，推出该句为假；若该句为假，则“我没说谎”，推出该句为真。无法赋予唯一真假值，故不是命题 |

### 1.2 原子命题与五种常用逻辑联结词（Slides 9–13）

为了把复杂的复合命题拆解清楚，我们将**不能再分解的最小命题单位**称为**原子（Atom）**（Slide 9）：

1. **命题常元（Propositional Constants）**：值恒定不变的命题，记作 $\mathbb{T}$（恒真，True）与 $\mathbb{F}$（恒假，False）。

2. **命题变元（Propositional Variables）**：可以取 $\mathbb{T}$ 或 $\mathbb{F}$ 的符号，通常用大写英文字母 $P, Q, R, \dots$ 表示。

复合命题由原子命题通过逻辑联结词（Logical Connectives）组合而成（Slides 10–11）：

| 联结词名称 | 英文名称 | 符号表示 | 自然语言常见表述与逻辑含义 |
| ----- | ----- | ----- | ----- |
| **否定词** | Negation | $\neg P$ | “非 $P$”、“并非 $P$”、“$P$ 不成立” |
| **析取词** | Disjunction | $P \lor Q$ | “$P$ 或者 $Q$”（注意：逻辑上的“或”默认是**可兼或 Inclusive OR**，即 $P, Q$ 同时为真时 $P \lor Q$ 也为真） |
| **合取词** | Conjunction | $P \land Q$ | “$P$ 并且 $Q$”、“既 $P$ 又 $Q$”、“虽然 $P$ 但是 $Q$” |
| **蕴含词** | Implication | $P \to Q$ | “如果 $P$，则 $Q$”；“$P$ 是 $Q$ 的**充分条件**”；“$Q$ 是 $P$ 的**必要条件**”；“$P$ 是前提，$Q$ 是结论”；“当 $P$ 则 $Q$”；“**仅当** $Q$ **有** $P$（$P \text{ only if } Q$）” |
| **等值词** | Bicondition | $P \leftrightarrow Q$ | “$P$ 等值于 $Q$”；“$P$ 是 $Q$ 的**充分必要条件**”；“$P$ **当且仅当（iff）** $Q$” |

:::caution[避坑指南：形式蕴含 $P \to Q$ 的真假与自然语言因果关系的区别（Slides 11–12）]

初学者最容易在蕴含词 $P \to Q$ 上踩坑，必须牢记以下两点：

1. **“仅当（only if）”的方向**：

   * “**当** $P$ **时有** $Q$（$Q \text{ if } P$）”表示 $P$ 是充分条件，符号化为 $P \to Q$；

   * “$P$ **仅当** $Q$（$P \text{ only if } Q$）”表示 $Q$ 是 $P$ 的必要条件（没有 $Q$ 就一定没有 $P$，即 $\neg Q \to \neg P$），因此**依然符号化为** $P \to Q$**，绝不是** $Q \to P$！

2. **形式蕴含剥离了日常语义关联（Slide 12）**：

   在数理逻辑中，$P \to Q$ 称为**形式蕴含（Material Implication）**，它 completely 剥离了 $P$ 与 $Q$ 之间的物理或日常因果关系，**只取决于前提** $P$ **和结论** $Q$ **的真假值**：

   * **唯一为假的情况**：前提 $P$ 为真（$1$），但结论 $Q$ 为假（$0$）（即“承诺兑现的条件满足了，但结果却违约了”）；

   * **空真（Vacuously True）**：只要前提 $P$ 为假（$0$），无论结论 $Q$ 是真是假，$P \to Q$ **恒为真（**$1$**）**！

   * **讲义经典例句（Slide 12）**：

     * $\text{“If today is Friday, then } 2 + 3 = 5\text{”}$：因为后件 $2+3=5$ 恒为真，所以无论今天是不是星期五，该复合命题**恒为真（True）**。

     * $\text{“If today is Friday, then } 2 + 3 = 6\text{”}$：后件 $2+3=6$ 为假。因此**除了今天确实是星期五（前件真、后件假，命题为假）之外，在星期一至星期四、星期六、星期日，该命题全部为真（True, except for Friday）**！

:::

#### 课堂例题：复合命题符号化（Slide 13）

**题目**：将命题“**你可以上网，仅当你是计算机专业的学生或者你不是一年级的学生**”符号化。

**解析**：

1. 先提取最小原子命题（肯定陈述句）：

   * 令 $A$ 表示：“你可以上网”；

   * 令 $C$ 表示：“你是计算机专业的学生”；

   * 令 $F$ 表示：“你是一年级的学生”。

2. 分析联结词结构：句型为“$A$，**仅当（only if）**（$C$ 或者 非 $F$）”。根据“$P$ 仅当 $Q$”译为 $P \to Q$ 的规则，得到合式公式：

   $$

   A \to (C \lor \neg F)

   $$

### 1.3 合式公式（WFF）的形式文法与优先级约定（Slides 14–16）

随便把符号拼凑在一起（例如 $P \land \to Q ($）是没有意义的。为了像编程语言编译器检查语法一样严格界定哪些符号串是合法公式，我们给出合式公式（Well-Formed Formula，简称 WFF 或公式）的形式文法定义（Slide 14）：

1. **字母表（Alphabet）**：

   * 命题常元：$\mathbb{T}, \mathbb{F}$；

   * 命题变元：$P, Q, R, \dots$；

   * 逻辑联结词：$\neg, \lor, \land, \to, \leftrightarrow$；

   * 辅助符号：左括号 $($ 与右括号 $)$。

2. **WFF 的递归生成规则（Inductive Definition）**：

   * **① 基础条款（Base Clause）**：命题常元和命题变元是合式公式；

   * **② 归纳条款（Recursion Clause）**：若 $A, B$ 是合式公式，则 $(\neg A)$、$(A \lor B)$、$(A \land B)$、$(A \to B)$、$(A \leftrightarrow B)$ 也是合式公式；

   * **③ 极小性条款（Extremality Clause）**：只有**有限步**引用规则 ① 和 ② 生成的符号串才是合式公式。

#### 课堂例题：证明符号串是/不是合式公式（Slide 15）

* **正例**：证明 $(A \to (C \lor (\neg F)))$ 是合式公式：

  1. 由规则 ①，$A, C, F$ 是合式公式；

  2. 由 $F$ 是合式公式及规则 ②，$(\neg F)$ 是合式公式；

  3. 由 $C, (\neg F)$ 是合式公式及规则 ②，$(C \lor (\neg F))$ 是合式公式；

  4. 由 $A, (C \lor (\neg F))$ 是合式公式及规则 ②，$(A \to (C \lor (\neg F)))$ 是合式公式。

* **反例辨析**：

  * $(\to (C \lor \neg F))$ **不是**合式公式：因为规则 ② 中没有形如 $(\to A)$ 的一元生成规则；

  * $(A \Rightarrow (C \lor \neg F))$ **不是**合式公式：因为 $\Rightarrow$ 是描述两个公式之间“永真蕴含关系”的**元语言符号（Metasymbol）**，不属于对象语言的逻辑联结词字母表！

#### 括号简化与运算符优先级约定（Slide 16）

严格按递归定义写出的公式括号极多，为此讲义规定了三条**括号省略与结合律规则**（考试必考细节）：

1. **最外层括号可省**：如 $(A \to B)$ 简写为 $A \to B$；

2. **运算符优先级由高到低**依次为：

$$

\text{括号 } () \quad > \quad \neg \quad > \quad \land \quad > \quad \lor \quad > \quad \to \quad > \quad \leftrightarrow

$$

例如：$P \lor Q \land R$ 必须解释为 $P \lor (Q \land R)$，**绝不等于** $(P \lor Q) \land R$！

3. **同级二元运算符从左到右结合（左结合性，Left-associative）**：

:::caution[武大讲义特别约定：$\to$ 在本课程中默认左结合！]

在武汉大学姚昱老师的《离散数学》讲义（Slide 16）中明确规定：**同一二元运算符从左到右结合**！因此：

$$

P \to Q \to R \quad \text{解释为} \quad (P \to Q) \to R \quad \neq \quad P \to (Q \to R)

$$

（注：部分逻辑学或类型论教材将 $\to$ 约定为右结合，但在武大本课程作业与期末考试中，请严格遵循讲义 Slide 16 的**从左到右结合**规则！）

:::

### 1.4 合式公式的形式语义、真值表与 SAT 复杂度（Slides 17–22）

语法只管“写得对不对”，形式语义（Formal Semantics）则负责回答“公式的真假值如何计算”（Slides 17–18）：

* **指派（Assignment / Interpretation）**：设公式 $G(P_1, P_2, \dots, P_n)$ 包含 $n$ 个命题变元 $P_1, P_2, \dots, P_n$。给每个变元 $P_i$ 赋予一个确定的真假值 $x_i \in \{0, 1\}$（其中 $1$ 代表 $\mathbb{T}$，$0$ 代表 $\mathbb{F}$），所得的 $n$ 元零一序列称为公式 $G$ 的一个**指派**，记作：

$$

I = \langle x_1, x_2, \dots, x_n \rangle = x_1 x_2 \dots x_n

$$

含 $n$ 个变元的公式共有 $2^n$ 种不同的指派。讲义习惯按二进制数值下标标记指派，例如当 $n=2$ 时：$I_0 = 00, I_1 = 01, I_2 = 10, I_3 = 11$。

* **递归真值定义** $I(G)$**（Slide 18）**：在指派 $I = x_1 x_2 \dots x_n$ 下，公式 $G$ 的真值 $I(G)$ 递归定义如下：

  1. $I(\mathbb{T}) = 1,\quad I(\mathbb{F}) = 0,\quad I(P_i) = x_i \ (i = 1, 2, \dots, n)$；

  2. $I(\neg A) = \begin{cases} 1, & \text{if } I(A) = 0 \\ 0, & \text{if } I(A) = 1 \end{cases}$；

  3. $I(A \lor B) = \begin{cases} 0, & \text{if } I(A) = 0 \text{ and } I(B) = 0 \\ 1, & \text{otherwise} \end{cases}$；

  4. $I(A \land B) = \begin{cases} 1, & \text{if } I(A) = 1 \text{ and } I(B) = 1 \\ 0, & \text{otherwise} \end{cases}$；

  5. $I(A \to B) = \begin{cases} 0, & \text{if } I(A) = 1 \text{ and } I(B) = 0 \\ 1, & \text{otherwise} \end{cases}$；

  6. $I(A \leftrightarrow B) = \begin{cases} 1, & \text{if } I(A) = I(B) \\ 0, & \text{otherwise} \end{cases}$。

#### 课堂例题：构造公式的真值表（Slide 20）

求公式 $G = \neg((P \lor Q) \land P)$ 在所有指派下的真值表：

| 指派 $I_k$ | $P$ | $Q$ | $P \lor Q$ | $(P \lor Q) \land P$ | $G = \neg((P \lor Q) \land P)$ |
| ----- | ----- | ----- | ----- | ----- | ----- |
| $I_0 = 00$ | $0$ | $0$ | $0$ | $0$ | $1$ |
| $I_1 = 01$ | $0$ | $1$ | $1$ | $0$ | $1$ |
| $I_2 = 10$ | $1$ | $0$ | $1$ | $1$ | $0$ |
| $I_3 = 11$ | $1$ | $1$ | $1$ | $1$ | $0$ |

从语义角度看，每一个含 $n$ 个变元的合式公式 $G(P_1, \dots, P_n)$ 都唯一确定了一个$n$ 元真值函数（布尔函数，Boolean Function） $f_G: \{0, 1\}^n \to \{0, 1\}$（Slide 21）。仔细观察上表最后一列 $[1, 1, 0, 0]$，可以发现它的取值与 $\neg P$ 完全一致！

:::tip[算法视野：真值表法的指数爆炸与 SAT 问题（Slide 22）]

既然真值表能算出任何公式在所有指派下的真值，为什么我们还要学习复杂的代数恒等变换和自然推理？

讲义 Slide 22 给出了一个震撼的算力估算：假设一个公式含有 $n = 100$ 个命题变元，其指派总数为 $2^{100}$。即使我们使用一台每秒能验证 $1\text{ T} \approx 2^{40}$ 个指派（Flops）的超级计算机，穷举整张真值表也需要：

$$

\frac{2^{100}}{2^{40}} = 2^{60}\text{ 秒} \approx 3.6558901 \times 10^{10}\text{ 年（约 365.6 亿年，超过宇宙年龄的两倍！）}

$$

在理论计算机科学中，判断一个命题逻辑公式是否存在至少一个成真指派的问题称为 **SAT 问题（Boolean Satisfiability Problem，布尔可满足性问题）**，它是 Stephen Cook（1971）证明的人类历史上**第一个 NP-Complete（NP 完全）问题**！

:::

## 二、永真公式、逻辑等价/蕴含与对偶性（Slides 23–40）

### 2.1 合式公式的三类划分（Slide 24）

设 $G(P_1, P_2, \dots, P_n)$ 是合式公式，根据其在所有 $2^n$ 个指派下的真值分布，可分为三类：

1. **重言式 / 永真式（Tautology）**：对**任意**指派 $I$，都有 $I(G) = 1$（真值表最后一列全为 $1$）。例如：$G = \neg((P \lor Q) \land P) \leftrightarrow \neg P$。

2. **可满足式（Satisfiable Formula）**：**存在至少一个**指派 $I$，使得 $I(G) = 1$（真值表最后一列至少有一个 $1$）。显然，**所有永真式都是可满足式**。

3. **矛盾式 / 永假式（Contradiction / Invalid Formula）**：对**任意**指派 $I$，都有 $I(G) = 0$（真值表最后一列全为 $0$，即不可满足式 Unsatisfiable）。

### 2.2 逻辑等价（$\Leftrightarrow$）与基本恒等式表（Slides 25–26）

:::note[定义]

设 $F, G$ 是两个合式公式，若双条件公式 $(F) \leftrightarrow (G)$ 是永真式（即对任意指派 $I$，都有 $I(F) = I(G)$），则称 $F$ 与 $G$ **逻辑等价（Logically Equivalent，或逻辑恒等）**，记作 $F \Leftrightarrow G$（或 $F \equiv G$）。

:::

* **等价关系的性质**：逻辑等价 $\Leftrightarrow$ 满足**自反性**（$A \Leftrightarrow A$）、**对称性**（若 $A \Leftrightarrow B$ 则 $B \Leftrightarrow A$）和**传递性**（若 $A \Leftrightarrow B$ 且 $B \Leftrightarrow C$，则 $A \Leftrightarrow C$）。

讲义 Slide 26 汇总了贯穿整个离散数学的 **10 组核心逻辑恒等式（代数定律）**：

| 定律名称 | 逻辑恒等式（左式 $\Leftrightarrow$ 右式） | 对偶/配对形式或记忆要点 |
| ----- | ----- | ----- |
| **1. 双重否定律** | $\neg\neg P \Leftrightarrow P$ | 连续两个否定相互抵消 |
| **2. 幂等律** | $P \land P \Leftrightarrow P$ | $P \lor P \Leftrightarrow P$ |
| **3. 交换律** | $P \land Q \Leftrightarrow Q \land P$ | $P \lor Q \Leftrightarrow Q \lor P$ |
| **4. 结合律** | $(P \land Q) \land R \Leftrightarrow P \land (Q \land R)$ | $(P \lor Q) \lor R \Leftrightarrow P \lor (Q \lor R)$ |
| **5. 吸收律** | $(P \land Q) \lor P \Leftrightarrow P$ | $(P \lor Q) \land P \Leftrightarrow P$（外层与内层符号相反，消去 $Q$） |
| **6. 分配律** | $P \land (Q \lor R) \Leftrightarrow (P \land Q) \lor (P \land R)$ | $P \lor (Q \land R) \Leftrightarrow (P \lor Q) \land (P \lor R)$（注意 $\lor$ 对 $\land$ 也能分配！） |
| **7. 蕴含恒等式** | $P \to Q \Leftrightarrow \neg P \lor Q$ | 消去 $\to$ 的核心公式；同理 $P \leftrightarrow Q \Leftrightarrow (P \to Q) \land (Q \to P) \Leftrightarrow (P \land Q) \lor (\neg P \land \neg Q)$ |
| **8. De Morgan 律** | $\neg(P \land Q) \Leftrightarrow \neg P \lor \neg Q$ | $\neg(P \lor Q) \Leftrightarrow \neg P \land \neg Q$（否定内移，合取变析取、析取变合取） |
| **9. 归谬律** | $(P \to Q) \land (P \to \neg Q) \Leftrightarrow \neg P$ | 若 $P$ 既推出 $Q$ 又推出 $\neg Q$，则 $P$ 必为假 |
| **10. 排中律 / 矛盾律** | $P \lor \neg P \Leftrightarrow \mathbb{T}$（排中律） | $P \land \neg P \Leftrightarrow \mathbb{F}$（矛盾律）；另有零律 $P \lor \mathbb{T} \Leftrightarrow \mathbb{T}, P \land \mathbb{F} \Leftrightarrow \mathbb{F}$ 与同一律 $P \land \mathbb{T} \Leftrightarrow P, P \lor \mathbb{F} \Leftrightarrow P$ |

### 2.3 永真蕴含（$\Rightarrow$）与常用蕴含式表（Slides 27–28）

:::note[定义]

设 $F, G$ 是两个合式公式，若条件公式 $(F) \to (G)$ 是永真式，则称 $F$ **永真蕴含（Logically Implies）** $G$，记作 $F \Rightarrow G$。

:::

* **代数不等式视角**：在数值 $\{0, 1\}$ 上，$F \Rightarrow G$ 当且仅当对**任意**指派 $I$，都有 $I(F) \le I(G)$（即不可能出现 $I(F)=1$ 而 $I(G)=0$ 的情况）。因此，如果说 $\Leftrightarrow$ 对应算术中的**等式（**$=$**）**，那么 $\Rightarrow$ 就对应算术中的**小于等于不等式（**$\le$**）**！

* **永真蕴含的四大基本性质（Slide 27）**：

  1. **自反性**：$A \Rightarrow A$；

  2. **反对称性（双向蕴含即等价）**：若 $A \Rightarrow B$ 且 $B \Rightarrow A$，则 $A \Leftrightarrow B$；

  3. **传递性**：若 $A \Rightarrow B$ 且 $B \Rightarrow C$，则 $A \Rightarrow C$；

  4. **逆否性（Contrapositive）**：若 $A \Rightarrow B$，则 $\neg B \Rightarrow \neg A$。

讲义 Slide 28 列出了 **8 条必须烂熟于心的基础永真蕴含式**：

| 序号 | 名称 | 永真蕴含式（左式 $\Rightarrow$ 右式） | 直观理解 |
| ----- | ----- | ----- | ----- |
| 1 | **加法式（Addition）** | $P \Rightarrow P \lor Q$ | 已知 $P$ 为真，添上任意“或 $Q$”依然为真（放大结论） |
| 2 | **简化式（Simplification）** | $P \land Q \Rightarrow P$ | 已知 $P, Q$ 都为真，单独抽出 $P$ 必然为真（缩小结论） |
| 3 | **假言推理（Modus Ponens, MP）** | $(P \to Q) \land P \Rightarrow Q$ | 肯定前件式：若 $P$ 则 $Q$，且 $P$ 成立，故 $Q$ 成立 |
| 4 | **拒取式（Modus Tollens, MT）** | $(P \to Q) \land \neg Q \Rightarrow \neg P$ | 否定后件式：若 $P$ 则 $Q$，但 $Q$ 不成立，故 $P$ 不成立 |
| 5 | **析取三段论（Disjunctive Syllogism）** | $(P \lor Q) \land \neg P \Rightarrow Q$ | $P, Q$ 至少有一个成立，排除 $P$ 后必有 $Q$ |
| 6 | **前提三段论（Hypothetical Syllogism）** | $(P \to Q) \land (Q \to R) \Rightarrow (P \to R)$ | 蕴含链的传递性 |
| 7 | **单前提传递式** | $(P \to Q) \Rightarrow (Q \to R) \to (P \to R)$ | 上式的柯里化（Currying）等价形式 |
| 8 | **合取保序式** | $(P \to Q) \land (R \to S) \Rightarrow (P \land R) \to (Q \land S)$ | 两个蕴含式同向合取 |

#### 证明 $A \Leftrightarrow B$ 与 $A \Rightarrow B$ 的三种基本方法（Slide 29）

1. **真值表法**：列出 $A$ 和 $B$ 在所有指派下的真值，检验是否恒有 $I(A)=I(B)$ 或 $I(A) \le I(B)$。

2. **真假值假设推演法（针对** $A \Rightarrow B$ **最快捷）**：

   * **正向推演**：假设对于某指派有 $I(A) = 1$，利用联结词语义推出在此指派下必有 $I(B) = 1$；

   * **逆向反证**：假设对于某指派有 $I(B) = 0$，推出在此指派下必有 $I(A) = 0$。

   * **例（Slide 29）**：证明假言推理 $P \land (P \to Q) \Rightarrow Q$。

     *证法一（逆向）*：假设 $I(Q) = 0$。若 $I(P) = 0$，则 $I(P \land (P \to Q)) = 0$；若 $I(P) = 1$，则由 $I(Q)=0$ 知 $I(P \to Q) = 0$，故仍有 $I(P \land (P \to Q)) = 0$。因此当右式为 $0$ 时左式必为 $0$，得证！

     *证法二（正向）*：假设 $I(P \land (P \to Q)) = 1$，则必有 $I(P) = 1$ 且 $I(P \to Q) = 1$。由 $I(P)=1$ 及 $I(P \to Q)=1$ 的语义定义，只能有 $I(Q) = 1$，得证！

3. **代数恒等变换与不等变换法**：利用已知恒等式与蕴含式做符号推导（详见下节代入与替换规则）。

### 2.4 代入规则（Substitution）与替换规则（Replacement）（Slides 30–36）

在进行代数化简和符号证明时，我们每一步操作实际上都依赖两条严格的元定理——**代入规则**与**替换规则**：

1. **代入规则（Substitution Rule，全局变换，Slide 30）**：

   * **定理**：设 $G(P_1, \dots, P_i, \dots, P_n)$ 是一个**永真式**，$F$ 是任意合式公式。如果把 $G$ 中出现的**每一个**原子变元 $P_i$ **全部同时代换**为公式 $F$，所得的新公式记作 $G(F / P_i)$，则 $G(F / P_i)$ **仍然是永真式**！

   * **适用范围**：因为 $A \Leftrightarrow B$ 本质上是 $(A) \leftrightarrow (B)$ 永真，$A \Rightarrow B$ 本质上是 $(A) \to (B)$ 永真，所以**代入规则对恒等式** $\Leftrightarrow$ **和不等式** $\Rightarrow$ **均无条件成立**！

   * **核心要求**：必须是針對**原子变元**的**全局一致性代换**（公式中所有的 $P_i$ 必须一处不落地全部换成同一个 $F$）。

2. **替换规则（Replacement Rule，局部变换，Slides 31–32）**：

   * **定理**：设 $G$ 是一个合式公式，$A$ 是 $G$ 的一个**子公式（Subformula）**。如果已知 $A \Leftrightarrow B$，那么将 $G$ 中**某处或几处**出现的子公式 $A$ 替换为 $B$（不必全部替换），得到的新公式 $G'$ 与原公式逻辑等价，即 $G \Leftrightarrow G'$。

:::warning[期末核心陷阱：替换规则只能用于恒等式 $\Leftrightarrow$，绝不能对不等式 $\Rightarrow$ 随便局部替换！（Slide 32）]

为什么？用算术不等式打个比方：已知 $x = y$，任何包含 $x$ 的复杂函数 $f(x)$ 都可以把里面的 $x$ 局部替换成 $y$ 得到 $f(x) = f(y)$；但如果只知道 $x \le y$，把 $x$ 放进减号（如 $-x$）里，不等号方向就会反转（$-x \ge -y$）！

逻辑公式完全一样：

* 已知简化式 $P \land Q \Rightarrow P$ 成立；

* 如果我们在外层套一个否定词 $\neg(\cdot)$，试图对子公式局部应用不等式，就会得出 $\neg(P \land Q) \Rightarrow \neg P$ 的荒谬结论！事实上，取 $P=1, Q=0$，左式 $\neg(1 \land 0) = 1$，右式 $\neg 1 = 0$，$1 \not\le 0$！（因为否定词 $\neg$ 是反单调的，正确的方向是逆否律 $\neg P \Rightarrow \neg(P \land Q)$）。

:::

#### 课堂例题精讲：标注（代入）与（替换）的严格代数证明（Slides 33–35）

**例题 1（Slide 33）**：证明 $(P \to Q) \to (Q \lor R) \Leftrightarrow P \lor Q \lor R$。

**证明**（注意体会每一步是全局代入还是局部子公式替换）：

$$

\begin{aligned}

(P \to Q) \to (Q \lor R)

&\Leftrightarrow (\neg P \lor Q) \to (Q \lor R) && \text{（对 } P \to Q \Leftrightarrow \neg P \lor Q \text{ 应用局部}\mathbf{替换}\text{）} \\

&\Leftrightarrow \neg(\neg P \lor Q) \lor (Q \lor R) && \text{（对 } A \to B \Leftrightarrow \neg A \lor B \text{ 作全局}\mathbf{代入}\text{：} A=\neg P\lor Q, B=Q\lor R\text{）} \\

&\Leftrightarrow (\neg\neg P \land \neg Q) \lor (Q \lor R) && \text{（对 De Morgan 律作}\mathbf{代入}\text{后，在原式中局部}\mathbf{替换}\text{）} \\

&\Leftrightarrow (P \land \neg Q) \lor Q \lor R && \text{（由双重否定律 }\neg\neg P \Leftrightarrow P\text{ 局部}\mathbf{替换}\text{，结合律省括号）} \\

&\Leftrightarrow ((P \lor Q) \land (\neg Q \lor Q)) \lor R && \text{（分配律代入与局部}\mathbf{替换}\text{）} \\

&\Leftrightarrow ((P \lor Q) \land \mathbb{T}) \lor R && \text{（排中律 }\neg Q \lor Q \Leftrightarrow \mathbb{T}\text{ 局部}\mathbf{替换}\text{）} \\

&\Leftrightarrow P \lor Q \lor R && \text{（同一律 }(P \lor Q) \land \mathbb{T} \Leftrightarrow P \lor Q\text{ 局部}\mathbf{替换}\text{）}

\end{aligned}

$$

**例题 2（Slide 34）**：用恒等变换证明拒取式 $(P \to Q) \land \neg Q \Rightarrow \neg P$。

**思路**：根据永真蕴含的定义，$A \Rightarrow B$ 当且仅当 $A \to B \Leftrightarrow \mathbb{T}$，也当且仅当其否定 $\neg(A \to B) \Leftrightarrow \mathbb{F}$！

**证明**：

$$

\begin{aligned}

\neg\big((P \to Q) \land \neg Q \to \neg P\big)

&\Leftrightarrow \neg\big(\neg((P \to Q) \land \neg Q) \lor \neg P\big) && \text{（蕴含恒等式）} \\

&\Leftrightarrow (P \to Q) \land \neg Q \land P && \text{（De Morgan 律 + 双重否定律）} \\

&\Leftrightarrow (\neg P \lor Q) \land \neg Q \land P && \text{（蕴含恒等式）} \\

&\Leftrightarrow ((\neg P \land P) \lor (Q \land P)) \land \neg Q && \text{（交换律 + 分配律）} \\

&\Leftrightarrow (\mathbb{F} \lor (Q \land P)) \land \neg Q && \text{（矛盾律 }\neg P \land P \Leftrightarrow \mathbb{F}\text{）} \\

&\Leftrightarrow P \land (Q \land \neg Q) && \text{（同一律 + 交换律 + 结合律）} \\

&\Leftrightarrow P \land \mathbb{F} \Leftrightarrow \mathbb{F} && \text{（矛盾律 + 零律）}

\end{aligned}

$$

既然 $\neg((P \to Q) \land \neg Q \to \neg P) \Leftrightarrow \mathbb{F}$，两边取否定即知 $(P \to Q) \land \neg Q \to \neg P \Leftrightarrow \mathbb{T}$，故 $(P \to Q) \land \neg Q \Rightarrow \neg P$。

**例题 3（Slide 35）**：化简 $(P \to Q \lor \neg R) \land \neg P \land Q$。

**解析**：

$$

\begin{aligned}

(P \to Q \lor \neg R) \land \neg P \land Q

&\Leftrightarrow (\neg P \lor Q \lor \neg R) \land (\neg P \land Q) && \text{（蕴含恒等式）} \\

&\Leftrightarrow \big((\neg P \lor Q) \lor \neg R\big) \land (\neg P \land Q) && \text{（结合律）} \\

&\Leftrightarrow \big((\neg P \lor Q) \land (\neg P \land Q)\big) \lor (\neg R \land \neg P \land Q) && \text{（或直接观察吸收律！）}

\end{aligned}

$$

更巧妙的做法是直接把 $\neg P$ 看作整体 $A$，把 $Q \lor \neg R$ 看作整体 $B$：原式前两项为 $(\neg P \lor (Q \lor \neg R)) \land \neg P$，直接由**吸收律** $(A \lor B) \land A \Leftrightarrow A$ 一步化简为 $\neg P$，再与后面的 $\land Q$ 结合，瞬间得到最终最简结果 $\neg P \land Q$！

### 2.5 对偶性（Duality）与广义 De Morgan 定理（Slides 37–40）

仔细观察前面的恒等式表，你会发现所有定律都是“成双成对”出现的：把一条定律里的 $\land$ 和 $\lor$ 互换、$\mathbb{T}$ 和 $\mathbb{F}$ 互换，就能得到另一条定律。这就是**对偶原理（Principle of Duality）**：

* **对偶式（Dual Formula）的定义（Slide 37）**：设合式公式 $G$ 中**仅包含联结词** $\neg, \land, \lor$（若含 $\to, \leftrightarrow$，需先用恒等式将其消去）。将 $G$ 中的 $\land$ 换成 $\lor$、$\lor$ 换成 $\land$、常元 $\mathbb{T}$ 换成 $\mathbb{F}$、$\mathbb{F}$ 换成 $\mathbb{T}$，**同时保持原有的运算先后顺序（括号结构）不变**，所得的新公式称为 $G$ 的**对偶式**，记作 $G^*$。

* **求对偶式的优先级陷阱（Slide 37）**：

  求 $G = P \land Q \lor \neg R$ 的对偶式 $G^*$：

  * 因为原式中 $\land$ 优先级高于 $\lor$，所以原式隐含括号为 $G = (P \land Q) \lor \neg R$；

  * 互换 $\land$ 与 $\lor$ 时**必须保留隐含括号**：

    $$

    G^* = (P \lor Q) \land \neg R

    $$

  * **切记**：如果漏写括号写成 $P \lor Q \land \neg R$，按照优先级它会变成 $P \lor (Q \land \neg R)$，这就完全改变了运算结构，是错误的！

  * 显然，对偶运算满足对合性：$(A^*)^* = A$。

#### 定理 1：广义 De Morgan 定理及其结构归纳法证明（Slide 38）

**定理内容**：设 $G(P_1, P_2, \dots, P_n)$ 是仅含 $\neg, \land, \lor$ 的合式公式，则：

$$

\neg G(P_1, P_2, \dots, P_n) \Leftrightarrow G^*(\neg P_1, \neg P_2, \dots, \neg P_n)

$$

（口诀：**对整个公式取否定，等价于先求其对偶式，再将里面所有原子变元逐一取否定**！）

**证明（对公式** $G$ **中联结词的个数** $k$ **作数学归纳法 / 结构归纳法，Slide 38）**：

1. **归纳基础（**$k = 0$ **或** $1$**）**：

   * 当 $G = P_1$（或常元 $\mathbb{T}, \mathbb{F}$）时，$G^*(P_1) = P_1$，故 $\neg G(P_1) = \neg P_1 = G^*(\neg P_1)$，显然成立；

   * 当 $G = \neg P_1$ 时，$G^*(P_1) = \neg P_1$，故 $\neg G(P_1) \Leftrightarrow \neg\neg P_1 \Leftrightarrow G^*(\neg P_1)$；

   * 当 $G = P_1 \land P_2$ 时，$G^*(P_1, P_2) = P_1 \lor P_2$，由基础 De Morgan 律有 $\neg(P_1 \land P_2) \Leftrightarrow \neg P_1 \lor \neg P_2 \Leftrightarrow G^*(\neg P_1, \neg P_2)$；对 $G = P_1 \lor P_2$ 同理。

2. **归纳假设**：假设对于联结词个数小于 $k$ 的任意公式 $G_1, G_2$，定理均成立。

3. **归纳递推**：考虑含 $k$ 个联结词的公式 $G$，分三种情况：

   * **情形 1**：$G = \neg G_1$。由归纳假设，$\neg G_1(P_1, \dots, P_n) \Leftrightarrow G_1^*(\neg P_1, \dots, \neg P_n)$，两边再取否定并利用 $G^*(P_1, \dots, P_n) = \neg G_1^*(P_1, \dots, P_n)$ 即得 $\neg G(P_1, \dots, P_n) \Leftrightarrow G^*(\neg P_1, \dots, \neg P_n)$。

   * **情形 2**：$G = G_1 \land G_2$。此时 $G^* = G_1^* \lor G_2^*$。由基础 De Morgan 律与归纳假设：

     $$

     \begin{aligned}

     \neg G(P_1, \dots, P_n) &\Leftrightarrow \neg\big(G_1(P_1, \dots, P_n) \land G_2(P_1, \dots, P_n)\big) \\

     &\Leftrightarrow \neg G_1(P_1, \dots, P_n) \lor \neg G_2(P_1, \dots, P_n) \\

     &\Leftrightarrow G_1^*(\neg P_1, \dots, \neg P_n) \lor G_2^*(\neg P_1, \dots, \neg P_n) \\

     &\Leftrightarrow G^*(\neg P_1, \dots, \neg P_n)

     \end{aligned}

     $$

   * **情形 3**：$G = G_1 \lor G_2$。证明与情形 2 完全对偶。综上，由归纳原理知定理对一切仅含 $\neg, \land, \lor$ 的合式公式成立。$\blacksquare$

#### 定理 2 与定理 3：对偶原理保等价与反序保蕴含（Slides 39–40）

由广义 De Morgan 定理，立即可导出两条威力巨大的推论：

1. **对偶保逻辑等价（Slide 39）**：设 $F, G$ 仅含 $\neg, \land, \lor$，则：

$$

F(P_1, \dots, P_n) \Leftrightarrow G(P_1, \dots, P_n) \quad \text{当且仅当} \quad F^*(P_1, \dots, P_n) \Leftrightarrow G^*(P_1, \dots, P_n)

$$

*证明*：若 $F(P_1, \dots, P_n) \Leftrightarrow G(P_1, \dots, P_n)$，两边同时取否定得 $\neg F(P_1, \dots, P_n) \Leftrightarrow \neg G(P_1, \dots, P_n)$；由广义 De Morgan 定理得 $F^*(\neg P_1, \dots, \neg P_n) \Leftrightarrow G^*(\neg P_1, \dots, \neg P_n)$；最后对每个变元 $P_i$ 应用**代入规则**（将 $P_i$ 代入为 $\neg P_i$）并使用双重否定律，即得 $F^*(P_1, \dots, P_n) \Leftrightarrow G^*(P_1, \dots, P_n)$！

2. **对偶反转永真蕴含方向（Slide 40）**：设 $F, G$ 仅含 $\neg, \land, \lor$，则：

$$

F(P_1, \dots, P_n) \Rightarrow G(P_1, \dots, P_n) \quad \text{当且仅当} \quad G^*(P_1, \dots, P_n) \Rightarrow F^*(P_1, \dots, P_n)

$$

*证明*：$F \Rightarrow G \iff \neg G \Rightarrow \neg F$（逆否律）$\iff G^*(\neg P_1, \dots, \neg P_n) \Rightarrow F^*(\neg P_1, \dots, \neg P_n)$（广义 De Morgan 定理）$\iff G^*(P_1, \dots, P_n) \Rightarrow F^*(P_1, \dots, P_n)$（代入规则 $\neg P_i / P_i$）。例如：由 $P \land Q \Rightarrow P$ 两边取对偶并反向，立刻得到 $P \Rightarrow P \lor Q$！

## 三、范式（DNF/CNF）与主范式（CDNF/CCNF）（Slides 41–59）

同一个逻辑公式可以有无穷多种等价写法（例如 $P \to Q$、$\neg P \lor Q$、$\neg(P \land \neg Q)$）。为了给公式建立一个像多项式展开那样统一的“标准形态”，从而机械化地判断两个公式是否等价，我们引入**范式（Normal Form）**与**主范式（Canonical Normal Form）**。

### 3.1 文字、基本积/基本和与析取/合取范式（Slides 44–46）

1. **文字（Literal）**：命题常元、命题变元及其否定（如 $P, \neg P, Q, \neg Q$）统称为**文字**。

2. **基本积（Elementary Product / 简单合取式）与基本和（Elementary Sum / 简单析取式）**：

   * **基本积**：有限个文字构成的**合取式**，例如 $P$、$\neg P \land Q$、$P \land \neg P \land R$；

   * **基本和**：有限个文字构成的**析取式**，例如 $P$、$P \lor \neg Q$、$P \lor \neg Q \lor R$。

3. **析取范式（Disjunctive Normal Form, DNF，Slide 45）**：

   由有限个**基本积**构成的**析取式**：

   $$

   A_1 \lor A_2 \lor \dots \lor A_m \quad (\text{其中每个 } A_i \text{ 都是基本积})

   $$

   （类比初等代数中的“多项式展开”：把 $\land$ 看作乘法、$\lor$ 看作加法，DNF 就是**积之和 Sum of Products**）。

4. **合取范式（Conjunctive Normal Form, CNF，Slide 46）**：

   由有限个**基本和**构成的**合取式**：

   $$

   B_1 \land B_2 \land \dots \land B_m \quad (\text{其中每个 } B_j \text{ 都是基本和})

   $$

   （类比初等代数中的“因式分解”：CNF 就是**和之积 Product of Sums**）。

   *特例注意*：单个文字 $P$ 既是基本积也是基本和，因此它同时是 DNF 和 CNF；基本积 $P \land Q$ 既可以看作只有一项的 DNF，也可以看作由两个单文字基本和 $P$ 与 $Q$ 合取而成的 CNF！

#### 求任意公式的 DNF / CNF 的通用三步算法（Slide 45）

对于任意合式公式 $G$，必存在与之逻辑等价的析取范式和合取范式，构造步骤如下：

1. **第一步（消去** $\to$ **和** $\leftrightarrow$**）**：使用 $A \to B \Leftrightarrow \neg A \lor B$ 与 $A \leftrightarrow B \Leftrightarrow (\neg A \lor B) \land (A \lor \neg B)$（或 $(A \land B) \lor (\neg A \land \neg B)$），将公式转化为仅含 $\neg, \land, \lor$ 的公式；

2. **第二步（否定内移至原子变元前）**：反复使用 De Morgan 律 $\neg(A \land B) \Leftrightarrow \neg A \lor \neg B$、$\neg(A \lor B) \Leftrightarrow \neg A \land \neg B$ 和双重否定律 $\neg\neg A \Leftrightarrow A$，把所有 $\neg$ 全部移到紧挨着单个命题变元的位置（此中间形态在自动推理中也称否定范式 NNF）；

3. **第三步（使用分配律展开）**：

   * 若求 **DNF（外** $\lor$ **内** $\land$**）**：反复使用 $\land$ 对 $\lor$ 的分配律 $A \land (B \lor C) \Leftrightarrow (A \land B) \lor (A \land C)$；

   * 若求 **CNF（外** $\land$ **内** $\lor$**）**：反复使用 $\lor$ 对 $\land$ 的分配律 $A \lor (B \land C) \Leftrightarrow (A \lor B) \land (A \lor C)$。

### 3.2 极小项（Minterm）与主析取范式（CDNF）（Slides 47–56, 58）

普通析取范式（DNF）**不是唯一的**！例如 $P \land Q \lor R$ 与 $(P \land Q) \lor (P \land R) \lor (\neg P \land R)$ 都是同一个公式的 DNF。为了实现**唯一性**，我们要求每个基本积里都必须包含公式的所有 $n$ 个变元：

* **极小项（Minterm，Slides 47–48）**：设公式含 $n$ 个命题变元 $P_1, P_2, \dots, P_n$（按字典序固定排列）。如果一个基本积中，**每个变元** $P_k$ **或其否定** $\neg P_k$ **恰好出现一次且仅出现一次**（共 $n$ 个不同变元的文字相合取），则称该基本积为一个**极小项**。

* **极小项的二进制编码** $m_i$：

  将原变元 $P_k$ 记作二进制数字 $1$，否定文字 $\neg P_k$ 记作二进制数字 $0$，则 $n$ 个文字对应的 $n$ 位二进制数转成十进制下标 $i \in \{0, 1, \dots, 2^n - 1\}$，记该极小项为 $m_i$。

  以 $n = 3$（变元 $P, Q, R$）为例，共有 $2^3 = 8$ 个极小项（Slide 48）：

| 二进制指派 $I_i$ | 十进制下标 $i$ | 极小项符号 $m_i$ | 对应的基本积表达式（$1 \leftrightarrow \text{原变元}, 0 \leftrightarrow \text{否定}$） |
| ----- | ----- | ----- | ----- |
| $000$ | $0$ | $m_0$ | $\neg P \land \neg Q \land \neg R$ |
| $001$ | $1$ | $m_1$ | $\neg P \land \neg Q \land R$ |
| $010$ | $2$ | $m_2$ | $\neg P \land Q \land \neg R$ |
| $011$ | $3$ | $m_3$ | $\neg P \land Q \land R$ |
| $100$ | $4$ | $m_4$ | $P \land \neg Q \land \neg R$ |
| $101$ | $5$ | $m_5$ | $P \land \neg Q \land R$ |
| $110$ | $6$ | $m_6$ | $P \land Q \land \neg R$ |
| $111$ | $7$ | $m_7$ | $P \land Q \land R$（注：原课件 Slide 48 末行左列笔误印作 `110`，应为 `111`） |

* **极小项的四大核心性质（Slides 49, 58）**：

  1. **点光源唯一下标成真性**：极小项 $m_i$ **当且仅当在指派** $I_i$ **下真值为** $1$，在其余所有 $2^n - 1$ 个指派下真值全为 $0$！

  2. **数目确定**：$n$ 个变元恰好有 $2^n$ 个互不相同的极小项；

  3. **两两互斥（正交性）**：任意两个不同极小项的合取恒为假，即当 $i \neq j$ 时，$m_i \land m_j \Leftrightarrow \mathbb{F}$；

  4. **全体完备性**：所有 $2^n$ 个极小项的析取恒为真，即 $\bigvee_{i=0}^{2^n-1} m_i \Leftrightarrow \mathbb{T}$。

* **主析取范式（Canonical Disjunctive Normal Form, CDNF，Slide 50）**：

  如果一个析取范式中的**每一个基本积都是极小项**（且按 $m_i$ 下标升序排列、无重复项），则称之为该公式的**主析取范式（CDNF）**，常简记为求和符号 $\sum(i_1, i_2, \dots, i_k)$。

  * **存在唯一性定理**：任何含 $n$ 个变元的合式公式 $A$ 都存在**唯一**的主析取范式，且 $A$ 的主析取范式就是**使** $I_i(A) = 1$ **的那些成真指派** $I_i$ **所对应的极小项** $m_i$ **的析取**！

#### 求主析取范式（CDNF）的两种标准方法（Slides 52–54）

以讲义例题 $A = P \land Q \lor R$（变元为 $P, Q, R$）为例：

1. **方法一：恒等变换扩充法（补项法，Slides 52–53）**

   * 先化为普通 DNF：$A \Leftrightarrow (P \land Q) \lor R$；

   * 删去永假基本积（含 $X \land \neg X$ 的项）与重复基本积；

   * **补齐缺失变元**：若某个基本积缺少变元 $X$，则给它合取上 $\mathbb{T} \Leftrightarrow (X \lor \neg X)$ 并用分配律展开：

     * 第一项 $P \land Q$ 缺少 $R$：

       $$

       P \land Q \Leftrightarrow P \land Q \land (R \lor \neg R) \Leftrightarrow \underbrace{(P \land Q \land R)}_{m_7 (111)} \lor \underbrace{(P \land Q \land \neg R)}_{m_6 (110)}

       $$

     * 第二项 $R$ 缺少 $P$ 和 $Q$：

       $$

       \begin{aligned}

       R &\Leftrightarrow (P \lor \neg P) \land (Q \lor \neg Q) \land R \\

       &\Leftrightarrow \underbrace{(P \land Q \land R)}_{m_7 (111)} \lor \underbrace{(P \land \neg Q \land R)}_{m_5 (101)} \lor \underbrace{(\neg P \land Q \land R)}_{m_3 (011)} \lor \underbrace{(\neg P \land \neg Q \land R)}_{m_1 (001)}

       \end{aligned}

       $$

   * **合并同类极小项（利用幂等律** $m_7 \lor m_7 \Leftrightarrow m_7$**）并按序排列**：

     $$

     A \Leftrightarrow m_1 \lor m_3 \lor m_5 \lor m_6 \lor m_7 \Leftrightarrow \sum(1, 3, 5, 6, 7)

     $$

2. **方法二：真值表直接读取法（Slide 54）**

   列出 $P, Q, R$ 的 8 行真值表，直接找出使 $A = P \land Q \lor R$ 取值为 $1$ 的行：

   * 当 $R = 1$ 时，$A = 1$，对应指派 $I_1(001), I_3(011), I_5(101), I_7(111)$；

   * 当 $R = 0$ 时，需 $P=1, Q=1$ 才有 $A = 1$，对应指派 $I_6(110)$；

   * 汇总所有成真指派下标，直接写出 $A \Leftrightarrow \sum(1, 3, 5, 6, 7)$！

:::note[重要计数结论：$n$ 个变元能构造多少个互不等价的公式？（Slides 55–56）]

因为每个公式唯一对应一个主析取范式，而构造一个主析取范式等价于从 $2^n$ 个极小项 $\{m_0, m_1, \dots, m_{2^n-1}\}$ 中任选一个子集做析取（空集 $\sum(\varnothing)$ 对应矛盾式 $\mathbb{F}$，全集 $\sum(0, 1, \dots, 2^n-1)$ 对应永真式 $\mathbb{T}$）。因此，含 $n$ 个变元的互不等价的合式公式（即不同的主析取范式）总数恰好为 $2^{2^n}$ 个！

* 当 $n = 1$ 时，共有 $2^{2^1} = 4$ 个：$\sum(\varnothing) \Leftrightarrow \mathbb{F}$，$\sum(0) \Leftrightarrow \neg P$，$\sum(1) \Leftrightarrow P$，$\sum(0, 1) \Leftrightarrow \mathbb{T}$；

* 当 $n = 2$ 时，共有 $2^{2^2} = 16$ 个；

* 当 $n = 3$ 时，共有 $2^{2^3} = 256$ 个。

:::

### 3.3 极大项（Maxterm）与主合取范式（CCNF）（Slides 57–59）

与极小项和主析取范式完全对偶，我们可以定义**极大项**与**主合取范式**：

* **极大项（Maxterm，Slide 58）**：含 $n$ 个变元的基本和，其中每个变元或其否定恰好出现一次，记作 $M_i$。

* **极大项的编码与性质（极其重要，与极小项正好相反！）**：

  * 极大项 $M_i$ **当且仅当在指派** $I_i$ **下真值为** $0$**（假）**，在其余所有 $2^n - 1$ 个指派下真值全为 $1$！

  * 因此，在极大项 $M_i$ 中，二进制位 $0$ **对应原变元** $P_k$，二进制位 $1$ **对应否定文字** $\neg P_k$！（记忆技巧：为了让 $I_i$ 代入进去等于 $0$，看到位是 $1$ 就必须取 $\neg P_k$ 把它变成 $0$ 相析取）。

  * 性质：$M_i \equiv \neg m_i$；当 $i \neq j$ 时 $M_i \lor M_j \Leftrightarrow \mathbb{T}$；全体极大项合取 $\bigwedge_{i=0}^{2^n-1} M_i \Leftrightarrow \mathbb{F}$。

* **主合取范式（Canonical Conjunctive Normal Form, CCNF，Slides 57, 59）**：

  完全由极大项合取而成的合取范式，记作连乘符号 $\prod(j_1, j_2, \dots, j_s)$，其中下标恰好是使公式 $A$ 取值为 $0$**（成假指派）** 的指派序号！

* **CDNF 与 CCNF 的互补转换公式**：

  因为一个指派要么使公式 $A$ 为 $1$，要么使公式 $A$ 为 $0$，所以同一个公式的极小项下标集与极大项下标集**关于全集** $\{0, 1, \dots, 2^n-1\}$ **严格互补**！

  例如前面求得 $A = P \land Q \lor R \Leftrightarrow \sum(1, 3, 5, 6, 7)$，剩下的成假指派下标是 $\{0, 2, 4\}$，因此无需重新计算，直接可得其主合取范式（Slide 59）：

  $$

  \begin{aligned}

  A &\Leftrightarrow \prod(0, 2, 4) \Leftrightarrow M_0 \land M_2 \land M_4 \\

  &\Leftrightarrow (P \lor Q \lor R) \land (P \lor \neg Q \lor R) \land (\neg P \lor Q \lor R)

  \end{aligned}

  $$

  （若用补项法验证：$P \land Q \lor R \Leftrightarrow (P \lor R) \land (Q \lor R)$，给第一项补 $\land (Q \land \neg Q)$、给第二项补 $\land (P \land \neg P)$ 展开去重，同样得到 $M_0 \land M_2 \land M_4$）。

## 四、联结词的扩充与归约（全功能集）（Slides 60–66）

### 4.1 联结词的扩充与 C 语言位运算应用（Slides 62–64）

前面我们已经证明：$n$ 个变元共有 $2^{2^n}$ 个不同的真值函数。

* 当 $n = 1$ 时有 $4$ 种一元运算：恒假 $\mathbb{F}$、恒真 $\mathbb{T}$、恒等 $P$、否定 $\neg P$；

* 当 $n = 2$ 时有 $16$ 种二元运算，除了我们已经熟悉的 $\land, \lor, \to, \leftrightarrow$ 外，工程与数字电路中还经常使用另外三个二元联结词（Slide 62）：

| 联结词名称 | 符号 | 定义等价式 | 运算规则口诀 |
| ----- | ----- | ----- | ----- |
| **与非词（NAND / Sheffer 竖）** | $P \uparrow Q$ | $\neg(P \land Q)$ | 全 $1$ 出 $0$，有 $0$ 出 $1$ |
| **或非词（NOR / Peirce 箭头）** | $P \downarrow Q$ | $\neg(P \lor Q)$ | 全 $0$ 出 $1$，有 $1$ 出 $0$ |
| **异或词（XOR / 不可兼或）** | $P \oplus Q$ | $(P \land \neg Q) \lor (\neg P \land Q) \Leftrightarrow \neg(P \leftrightarrow Q)$ | 相异为 $1$，相同为 $0$（模 2 加法） |

#### 计算机系统衔接：C 语言位运算与二进制 $1$ 的个数统计（Slides 63–64）

在 C/C++ 语言中，命题逻辑运算直接对应整数的**按位逻辑运算（Bitwise Operators）**：`~`（按位非 $\neg$）、`&`（按位与 $\land$）、`|`（按位或 $\lor$）、`^`（按位异或 $\oplus$），以及移位运算 `<<`、`>>`。

讲义 Slide 64 给出了一个经典的位运算面试与算法竞赛名题——统计无符号长整型 `x` 的二进制表示中 $1$ 的个数（即 `popcount` / 汉明重量）：

```
int cardinal(unsigned long x)
{
    int count = 0;
    while (x > 0) {
        x ^= x & -x; // 核心技巧：x & -x 提取最低位的 1 (lowbit)，异或将其清零
        count++;
    }
    return count;
}
```

* **原理解析**：在二进制补码表示中，`-x` 等于 `~x + 1`。因此 `x & -x`（即树状数组 Fenwick Tree 中的 `lowbit(x)`）恰好保留 `x` 二进制最右侧的那个 `1` 及其后面的 `0`，其余高位全部置 `0`。再执行 `x ^= x & -x`（或 `x &= x - 1`），每一次循环都精准消去 `x` 中最低位的一个 `1`，循环次数恰好等于 `x` 中 `1` 的个数！

### 4.2 联结词的归约：全功能集与极小全功能集（Slides 65–66）

既然二元联结词有 16 个，多元联结词更是无穷无尽，我们最少只需要保留哪几个联结词，就能表达出宇宙间所有的真值函数？

* **全功能集（Functionally Complete Set of Connectives）**：如果一个联结词集合 $S$ 能够表示任意一个合式公式（即任意 $n$ 元真值函数），则称 $S$ 是**全功能集（功能完备集）**。

* **极小全功能集（Minimal Functionally Complete Set）**：如果全功能集 $S$ 中**删去任意一个联结词后都不再是全功能集**（即其中没有任何联结词可以被集合内其余联结词表示），则称 $S$ 为**极小全功能集**。

讲义 Slides 65–66 给出了全功能集的核心判定结论与证明：

1. **三元全功能集（非极小）**：$\{\neg, \land, \lor\}$ 是全功能集（因为任何公式都有只含 $\neg, \land, \lor$ 的主析取范式）。但它不是极小的，因为 $\lor$ 和 $\land$ 可以通过 De Morgan 律互相表示。

2. **三大经典二元极小全功能集**：

   * $\{\neg, \land\}$：因为 $P \lor Q \Leftrightarrow \neg(\neg P \land \neg Q)$；

   * $\{\neg, \lor\}$：因为 $P \land Q \Leftrightarrow \neg(\neg P \lor \neg Q)$；

   * $\{\neg, \to\}$：因为 $P \lor Q \Leftrightarrow \neg P \to Q$，进而 $P \land Q \Leftrightarrow \neg(P \to \neg Q)$。

3. **两大一元（单元素）极小全功能集——数字集成电路的基石（Slide 66）**：

   单独一个**或非词** $\{\downarrow\}$，或者单独一个**与非词** $\{\uparrow\}$，本身就是极小全功能集！（这就是为什么硬件芯片底层只需要造一种 NAND 门或 NOR 门就能拼出整个 CPU）：

   * **证明** $\{\downarrow\}$ **是全功能集（将** $\{\neg, \lor\}$ **或** $\{\neg, \to\}$ **归约到** $\downarrow$**）**：

     * 表示否定：$\neg P \Leftrightarrow \neg(P \lor P) \Leftrightarrow P \downarrow P$；

     * 表示析取：$P \lor Q \Leftrightarrow \neg\neg(P \lor Q) \Leftrightarrow \neg(P \downarrow Q) \Leftrightarrow (P \downarrow Q) \downarrow (P \downarrow Q)$；

     * 表示蕴含（Slide 66）：$P \to Q \Leftrightarrow \neg P \lor Q \Leftrightarrow \big((P \downarrow P) \downarrow Q\big) \downarrow \big((P \downarrow P) \downarrow Q\big)$。

   * **证明** $\{\uparrow\}$ **是全功能集（将** $\{\neg, \land\}$ **归约到** $\uparrow$**）**：

     * 表示否定：$\neg P \Leftrightarrow \neg(P \land P) \Leftrightarrow P \uparrow P$；

     * 表示合取：$P \land Q \Leftrightarrow \neg(P \uparrow Q) \Leftrightarrow (P \uparrow Q) \uparrow (P \uparrow Q)$。

4. **常见的非全功能集反例（考试高频判断题，Slide 65）**：

   * $\{\land, \lor\}$ **不是全功能集**：因为无论怎么组合 $\land$ 和 $\lor$，当所有变元都取 $1$ 时，公式结果永远是 $1$（保真性），**永远无法造出否定词** $\neg P$！

   * $\{\neg, \leftrightarrow\}$**（以及** $\{\neg, \oplus\}$**）不是全功能集**：讲义 Slide 65 明确指出，在两个变元 $P, Q$ 的全部 $16$ 种真值函数中，仅用 $\neg$ 和 $\leftrightarrow$ 无论如何嵌套，**最多只能表示出其中** $8$ **个公式**（因为它们的成真指派个数总是偶数，无法表示成真指派只有 $1$ 个的 $P \land Q$ 或 $3$ 个的 $P \lor Q$）！

## 五、推理理论与自然推理的形式证明（Slides 67–84）

### 5.1 有效结论（Valid Consequence）的 7 种等价刻画（Slide 68）

逻辑学的终极目标是从已知的前提出发推导出正确的结论。

:::note[定义]

设 $H_1, H_2, \dots, H_n$ 和 $C$ 是合式公式。如果对于**任意**使所有前提 $H_1, H_2, \dots, H_n$ 的真值同时为 $1$ 的指派 $I$，结论 $C$ 在该指派下的真值也必为 $1$，则称 $C$ 是前提集合 $\{H_1, H_2, \dots, H_n\}$ 的**有效结论（Valid Consequence）**，记作：

:::

$$

H_1, H_2, \dots, H_n \vdash C

$$

* **定理：有效结论的 7 种等价表述（Slide 68）**：

  以下 7 个命题互相等价，它们分别对应了后面不同的证明套路：

  1. $H_1, H_2, \dots, H_n \vdash C$（有效结论定义）；

  2. $(H_1 \land H_2 \land \dots \land H_n) \to C$ 是**永真式**；

  3. $(H_1 \land H_2 \land \dots \land H_n) \Rightarrow C$（前提的合取**永真蕴含**结论）；

  4. $\neg\big((H_1 \land H_2 \land \dots \land H_n) \to C\big)$ 是**矛盾式**；

  5. $H_1 \land H_2 \land \dots \land H_n \land \neg C$ 是**矛盾式**（**反证法/归谬法的理论依据**：把结论取否定加入前提，推出矛盾 $\mathbb{F}$）；

  6. $(H_1 \land H_2 \land \dots \land H_n \land \neg C) \to \mathbb{F}$ 是**永真式**；

  7. $(H_1 \land H_2 \land \dots \land H_n \land \neg C) \Rightarrow \mathbb{F}$。

### 5.2 贯穿案例：“球赛推理”的前四种非序列证法（Slides 69–71）

**问题描述（Slide 69）**：已知某球赛排班满足以下三条规则：

* 若甲队参加，则乙队或丙队也参加；

* 若乙队参加，则甲队不参加；

* 若丁队参加，则丙队不参加。

  试证明：**若甲队参加，则丁队不参加**。

**第一步：命题符号化**

令 $A, B, C, D$ 分别表示“甲、乙、丙、丁队参加”。则：

* 前提：$H_1 = A \to B \lor C$，$H_2 = B \to \neg A$，$H_3 = D \to \neg C$；

* 待证结论：$C_{\text{concl}} = A \to \neg D$。

  即需证明：$A \to B \lor C,\ B \to \neg A,\ D \to \neg C \vdash A \to \neg D$。

讲义在 Slides 69–71 先展示了四种基础证法：

1. **方法一：永真蕴含不等式链推导法（Slide 69）**：

   $$

   \begin{aligned}

   &(A \to B \lor C) \land (B \to \neg A) \land (D \to \neg C) \\

   \Leftrightarrow\ & (\neg A \lor B \lor C) \land (\neg B \lor \neg A) \land (\neg D \lor \neg C) && \text{（蕴含恒等式）} \\

   \Leftrightarrow\ & \big(\neg A \lor (B \land \neg B) \lor (C \land \neg B)\big) \land (\neg D \lor \neg C) && \text{（前两项对 }\neg A\text{ 提取分配律）} \\

   \Rightarrow\ & (\neg A \lor \mathbb{F} \lor C) \land (\neg D \lor \neg C) && \text{（因 }B \land \neg B \Leftrightarrow \mathbb{F}\text{ 且 }C \land \neg B \Rightarrow C\text{）} \\

   \Leftrightarrow\ & (A \to C) \land (C \to \neg D) && \text{（同一律 + 蕴含恒等式逆用）} \\

   \Rightarrow\ & A \to \neg D && \text{（前提三段论）}

   \end{aligned}

   $$

2. **方法二：真值表法 / 主范式法（Slide 70）**：

   列出 4 个变元 $A, B, C, D$ 的 16 行真值表，或求 $(H_1 \land H_2 \land H_3) \to (A \to \neg D)$ 的主合取范式（结果为空，即无成假指派）或主析取范式（包含全部 $m_0 \dots m_{15}$）。

3. **方法三：假设结论为假，反推前提必有假（Slide 70）**：

   假设结论 $I(A \to \neg D) = 0$，则必有 $I(A) = 1$ 且 $I(\neg D) = 0$（即 $I(D) = 1$）。

   * 若 $I(B) = 1$：因 $I(A) = 1$，故前提 $I(B \to \neg A) = 0$；

   * 若 $I(B) = 0$ 且 $I(C) = 1$：因 $I(D) = 1$，故前提 $I(D \to \neg C) = 0$；

   * 若 $I(B) = 0$ 且 $I(C) = 0$：因 $I(A) = 1$，故前提 $I(A \to B \lor C) = 0$。

     综上，只要结论为假，三个前提不可能同时为真，得证！

4. **方法四：假设前提全为真，正推结论必为真（Slide 71）**：

   假设 $I(A \to B \lor C) = 1$、$I(B \to \neg A) = 1$、$I(D \to \neg C) = 1$。

   * 若 $I(A) = 0$，则结论 $I(A \to \neg D) = 1$ 自动成立；

   * 若 $I(A) = 1$，由 $I(B \to \neg A) = 1$ 知必有 $I(B) = 0$；再由 $I(A \to B \lor C) = 1$ 及 $I(A)=1, I(B)=0$ 知必有 $I(C) = 1$；最后由 $I(D \to \neg C) = 1$ 及 $I(C)=1$ 知必有 $I(D) = 0$（即 $I(\neg D) = 1$），从而 $I(A \to \neg D) = 1$。得证！

### 5.3 自然推理的形式证明（证明序列、CP 规则与反证法）（Slides 72–82）

为了把人类直觉推理变成计算机可以逐行检验的严格格式，我们引入**自然推理系统（Natural Deduction）的形式证明序列（Proof Sequence，Slides 74–75）**：

* **证明序列的定义（Slide 74）**：

  设 $H_1, H_2, \dots, H_n$ 是前提集合。一个公式序列 $C_1, C_2, \dots, C_m$ 称为从 $H_1, \dots, H_n$ 出发的**形式证明序列**，如果对于序列中的每一行 $C_i\ (1 \le i \le m)$，都至少满足以下四条生成规则之一：

  1. **① 前提引入规则（Rule P）**：$C_i$ 是某个已知前提 $H_j\ (1 \le j \le n)$；

  2. **② 永真引入**：$C_i$ 是永真式 $\mathbb{T}$；

  3. **③ 恒等导出（Rule T - Equivalence）**：$C_i$ 与前面已证明的若干行公式 $C_{i_1}, C_{i_2}, \dots, C_{i_k}\ (i_1, \dots, i_k < i)$ 的合取逻辑等价，即 $C_{i_1} \land \dots \land C_{i_k} \Leftrightarrow C_i$；

  4. **④ 蕴含导出（Rule T - Inference Rule）**：$C_i$ 被前面已证明的若干行公式 $C_{i_1}, C_{i_2}, \dots, C_{i_k}\ (i_1, \dots, i_k < i)$ 的合取永真蕴含，即 $C_{i_1} \land \dots \land C_{i_k} \Rightarrow C_i$。

     若序列最后一行 $C_m$ 就是待证结论 $C$，则称该序列为 $H_1, \dots, H_n \vdash C$ 的一个**形式证明**。

* **定理：证明序列的可靠性与完备性（Slide 75）**：

  $H_1, H_2, \dots, H_n \vdash C$ 成立，**当且仅当**存在从 $H_1, \dots, H_n$ 到 $C$ 的形式证明序列。

  *可靠性证明（对序列长度* $m$ *作强数学归纳法，Slide 75）*：

  * 当 $m = 1$ 时，$C_1$ 只能是某个前提 $H_j$ 或 $\mathbb{T}$，显然 $H_1, \dots, H_n \vdash C_1$；

  * 假设对一切 $k < m$ 都有 $H_1, \dots, H_n \vdash C_k$。考察第 $m$ 步 $C_m$：若 $C_m$ 由 ① 或 ② 得到，显然成立；若 $C_m$ 由前面的 $C_{i_1}, \dots, C_{i_s}\ (i_r < m)$ 经 ③ 或 ④ 得到，则对任意使 $H_1, \dots, H_n$ 全为 $1$ 的指派 $I$，由归纳假设知 $I(C_{i_1}) = \dots = I(C_{i_s}) = 1$，从而 $I(C_{i_1} \land \dots \land C_{i_s}) = 1$，再由 $C_{i_1} \land \dots \land C_{i_s} \Rightarrow C_m$ 即得 $I(C_m) = 1$。故 $H_1, \dots, H_n \vdash C_m$！$\blacksquare$

#### 自然推理常用 10 大推理规则汇总表（Slides 76–78）

| 规则名称 | 分数线形式 $\dfrac{\text{前提}}{\text{结论}}$ | 对应的永真蕴含式 |
| ----- | ----- | ----- |
| **1. 加法式（Addition）** | $\dfrac{\alpha}{\alpha \lor \beta}$ | $P \Rightarrow P \lor Q$ |
| **2. 简化式（Simplification）** | $\dfrac{\alpha \land \beta}{\alpha}$ | $P \land Q \Rightarrow P$ |
| **3. 假言推理（Modus Ponens, MP）** | $\dfrac{\alpha \to \beta,\quad \alpha}{\beta}$ | $(P \to Q) \land P \Rightarrow Q$ |
| **4. 拒取式（Modus Tollens, MT）** | $\dfrac{\alpha \to \beta,\quad \neg\beta}{\neg\alpha}$ | $(P \to Q) \land \neg Q \Rightarrow \neg P$ |
| **5. 前提三段论（Hypothetical Syllogism）** | $\dfrac{\alpha \to \beta,\quad \beta \to \gamma}{\alpha \to \gamma}$ | $(P \to Q) \land (Q \to R) \Rightarrow (P \to R)$ |
| **6. 复合式（Composition）** | $\dfrac{\alpha \to \beta,\quad \alpha \to \gamma}{\alpha \to (\beta \land \gamma)}$ | $(P \to Q) \land (P \to R) \Rightarrow P \to (Q \land R)$ |
| **7. 合取式（Conjunction）** | $\dfrac{\alpha,\quad \beta}{\alpha \land \beta}$ | $P, Q \vdash P \land Q$ |
| **8. 析取三段论（Disjunctive Syllogism）** | $\dfrac{\alpha \lor \beta,\quad \neg\alpha}{\beta}$ | $(P \lor Q) \land \neg P \Rightarrow Q$ |
| **9. 构造性二难（Constructive Dilemma）** | $\dfrac{\alpha \to \beta,\quad \gamma \to \delta,\quad \alpha \lor \gamma}{\beta \lor \delta}$ | $(P \to Q) \land (R \to S) \land (P \lor R) \Rightarrow Q \lor S$ |
| **10. 破坏性二难（Destructive Dilemma）** | $\dfrac{\alpha \to \beta,\quad \gamma \to \delta,\quad \neg\beta \lor \neg\delta}{\neg\alpha \lor \neg\gamma}$ | $(P \to Q) \land (R \to S) \land (\neg Q \lor \neg S) \Rightarrow \neg P \lor \neg R$ |

#### 三种形式证明序列写法对比（以“球赛推理”为例，Slides 79–82）

**写法一：直接证明法（Slide 79）**

不引入额外前提，直接用恒等变换和三段论推导 $A \to B \lor C,\ B \to \neg A,\ D \to \neg C \vdash A \to \neg D$：

```
(1) B -> ~A             ; P (前提引入)
(2) A -> ~B             ; T, (1), 逆否律 (Contrapositive)
(3) A -> B v C          ; P (前提引入)
(4) A -> (~B) ^ (B v C) ; T, (2)(3), 复合式
(5) A -> (~B ^ B) v (~B ^ C) ; T, (4), 分配律
(6) A -> C              ; T, (5), 矛盾律、同一律与简化式 (~B ^ C => C)
(7) D -> ~C             ; P (前提引入)
(8) C -> ~D             ; T, (7), 逆否律
(9) A -> ~D             ; T, (6)(8), 前提三段论
```

**写法二：附加前提法 / CP 规则（Conditional Proof，Slides 80–81）**

* **理论依据（演绎定理 Deduction Theorem）**：因为 $(H_1 \land \dots \land H_n) \to (R \to C) \Leftrightarrow (H_1 \land \dots \land H_n \land R) \to C$，所以**当待证结论是蕴含式** $R \to C$ **时，可以直接把结论的前件** $R$ **作为“附加前提（CP）”加入前提集合，转而只需证明后件** $C$！

* **为什么 CP 规则最推荐？** 因为引入单个文字 $A$ 后，能够立刻配合假言推理（MP）和析取三段论把复杂的复合句拆碎，证明步骤极度丝滑（Slide 81）：

```
(1) A                   ; P (附加前提 Additional Premise)
(2) A -> B v C          ; P (前提引入)
(3) B v C               ; T, (1)(2), 假言推理 (MP)
(4) B -> ~A             ; P (前提引入)
(5) ~B                  ; T, (1)(4), 拒取式 (MT, 由 A 即 ~~A 与 B -> ~A 得 ~B)
(6) C                   ; T, (3)(5), 析取三段论
(7) D -> ~C             ; P (前提引入)
(8) ~D                  ; T, (6)(7), 拒取式 (MT)
(9) A -> ~D             ; CP, (1)(8), 附加前提规则得证
```

**写法三：反证法 / 归谬法（Proof by Contradiction，Slide 82）**

* **理论依据**：利用等价刻画第 5 条——将待证结论取否定 $\neg(A \to \neg D)$ 作为附加前提引入，推导出矛盾式 $\mathbb{F}$：

```
(1) ~(A -> ~D)          ; P (结论否定，反证法假设)
(2) A ^ D               ; T, (1), 蕴含否定恒等式 ~(P -> Q) <=> P ^ ~Q
(3) A                   ; T, (2), 简化式
(4) D                   ; T, (2), 简化式
(5) A -> B v C          ; P (前提引入)
(6) B v C               ; T, (3)(5), 假言推理 (MP)
(7) B -> ~A             ; P (前提引入)
(8) ~B                  ; T, (3)(7), 拒取式 (MT)
(9) C                   ; T, (6)(8), 析取三段论
(10) D -> ~C            ; P (前提引入)
(11) ~C                 ; T, (4)(10), 假言推理 (MP)
(12) F                  ; T, (9)(11), 合取式与矛盾律 (C ^ ~C <=> F)
```

## 六、课后自测

1. **运算符结合性与优先级**：写出 $P \lor Q \land \neg R \to S \to T$ 完全加括号后的形式。

   * 答案：:spoiler[$((P \lor (Q \land (\neg R))) \to S) \to T$（注意 $\land$ 高于 $\lor$，且 $\to$ 在本课程中从左到右结合！）]

2. **代入与替换辨析**：已知 $P \Rightarrow P \lor Q$，能否对公式 $(P \lor Q) \to R$ 中的子公式 $P \lor Q$ 局部反向替换或对 $\neg P$ 局部正向替换得到 $\neg P \Rightarrow \neg(P \lor Q)$？

   * 答案：:spoiler[不能！替换规则只对逻辑恒等式 $\Leftrightarrow$ 成立，对永真蕴含不等式 $\Rightarrow$ 不成立。事实上由逆否律应有 $\neg(P \lor Q) \Rightarrow \neg P$。]

3. **主范式互补关系**：设含 3 个变元 $P, Q, R$ 的公式 $G$ 的主析取范式为 $\sum(0, 2, 5, 7)$，求 $G$ 的主合取范式以及 $\neg G$ 的主析取范式。

   * 答案：:spoiler[$G$ 的主合取范式为互补下标 $\prod(1, 3, 4, 6)$；而 $\neg G$ 的成真指派恰为 $G$ 的成假指派，故 $\neg G$ 的主析取范式为 $\sum(1, 3, 4, 6)$！]

4. **全功能集判别**：判断 $\{\neg, \leftrightarrow\}$、$\{\land, \lor, \to\}$、$\{\uparrow\}$ 中哪些是全功能集？

   * 答案：:spoiler[只有 $\{\uparrow\}$ 是全功能集（且为极小全功能集）。$\{\neg, \leftrightarrow\}$ 在二元下只能表出 8 种函数；$\{\land, \lor, \to\}$ 具有保真性（当变元全为 $1$ 时结果恒为 $1$），无法表出 $\neg P$。]
