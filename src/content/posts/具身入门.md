## 第一周

### 我认为的具身智能

:::note[我的理解]
机器人通过收集外部信息，经过内部处理，输出动作与物理世界交互，具身智能主要在处理信息上，我觉得机器人是通过训练出来的模型处理数据，得到最可能的结果。
:::

### 术语补充

| 术语 | 解释 | 通俗理解 |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | ----------------------------------- |
| observation                                                    | 智能体在当前时刻通过传感器**实际接收到**的局部信息。                                                                     | 自己能“看”到的东西                          |
| state                                                          | 环境在当前时刻的**完整、客观物理真值**，包含了决定环境下一时刻演变的所有必要信息（具备马尔可夫性）                                              | 自己相关的所有信息，相比于observation，多了自身看不到的东西 |
| action                                                         | 智能体根据当前策略向底层控制器发出的**控制指令**                                                                       | 输出的动作                               |
| policy（策略）                                                     | 智能体的“大脑”或决策函数，负责将当前观测（或状态）映射为具体的动作「模型」                                                           | 可以类比成一个函数                           |
| trajectory（轨迹）                                                 | 智能体从任务开始到结束（一个 Episode）所经历的**状态/观测与动作的时间序列**                                                     | 记录，可能会数据集聚合                         |
| demonstration（演示 / 专家轨迹）                                       | 一次完整的任务执行记录，通常包含观测、动作与时间戳                                                                        | 专家轨迹，一般作为数据集                        |
| rollout（展开 / 策略推演）                                             | 将当前策略 $\pi$ 部署到环境中，让它**实际闭环运行（Closed-loop execution）一轮或多轮以生成轨迹的过程**                              | 类似一种测试                              |
| （深）batch（批次）                                                   | 单次模型参数更新（梯度下降）时，从数据集或经验池中抽取并**同时输入给神经网络的一小批数据样本**                                                | 单次少量数据                              |
| （深）epoch（轮次）                                                   | 在训练过程中，整个训练数据集的所有样本被模型**完整遍历（从头到尾学完）一遍**的过程                                                      | 遍历所有专家集合                            |
| episode（回合）                                                    | 智能体在环境中从**初始状态开始，直到触发终止条件**的完整交互周期。                                                              | 跑完一回合会产生一条trajectory                |
| ACT(Action Chunking with Transformers)（基于 Transformer 的动作分块策略） | 一种结合了 **CVAE（条件变分自编码器）** 与 **Transformer** 的模仿学习策略网络，通过一次性预测未来连续 $k$ 步的动作序列（动作分块）来解决复合误差与多模态分布问题 | 做未来规划                               |
| CVAE(Conditional Variational Autoencoder)（条件变分自编码器）            | 一种基于概率分布的**生成模型**，通过引入隐变量（Latent Variable $z$），在给定条件（如当前观测 $o_t$）下建模复杂、多模态的数据分布                  | （待补充）                               |
| Transformer                                                    | 一种基于**自注意力机制（Self-Attention）**的神经网络架构，擅长捕捉长序列数据内部以及多模态输入之间的全局依赖关系。                               | （待补充）                               |
