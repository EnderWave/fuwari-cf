## 1. 概率的基本概念（Lecture 1）

  

### 1.1 随机试验、样本空间与随机事件

  

在工程与科学问题中，许多过程即便在**相同条件**下进行，其结果也无法事先唯一确定（例如：明天 8:00 武汉是否下雨、设备未来 24 小时内是否故障、同一零件重复测量的微小读数波动、大语言模型下一个生成的 Token）。面对这类不确定性，数学通过三个层次来建模：**从历史数据中统计规律 $\to$ 用概率度量可能性 $\to$ 结合影响作出最优决策**。

  

:::note[定义 1.1：随机试验与样本空间]

- **随机试验（Random Experiment, $E$）**：满足以下三个条件的过程：

  1. **可重复性**：可以在相同条件下重复进行；

  2. **结果明确性**：所有可能出现的结果范围事先明确；

  3. **不可预知性**：每次试验前不能唯一确定具体出现哪一个结果。

- **样本点（Sample Point, $\omega$）**：一次随机试验的一个可能结果。

- **样本空间（Sample Space, $\Omega$）**：试验 $E$ 的全部样本点组成的集合，记作 $\Omega = \{\omega \mid \omega \text{ 是 } E \text{ 的一个可能结果}\}$。每次试验恰得到一个 $\omega \in \Omega$。

:::

  

:::warning[样本空间必须与研究问题匹配]

同一个物理动作（如掷一枚六面骰子），**记录规则不同，样本空间就不同**：

- 记录具体点数：$\Omega_1 = \{1, 2, 3, 4, 5, 6\}$（完备、唯一，能回答“是否掷出 6”等一切点数问题）；

- 只记录奇偶：$\Omega_2 = \{\text{奇数}, \text{偶数}\}$（无法回答“是否掷出 6”）；

- 只记录是否大于 3：$\Omega_3 = \{\le 3, > 3\}$（只能回答阈值问题）；

- 若写成 $\Omega' = \{1, 2, 3, 4, 5\}$ 则**不完备**（遗漏了结果 6）。

  

**检验标准**：① 是否覆盖全部可能结果（完备性）？② 一次试验是否只落入唯一一个样本点（互斥性）？③ 是否保留了回答研究问题所需的信息？

:::

  

- **随机事件（Random Event）**：样本空间 $\Omega$ 中满足某个条件的一组结果，即 **$\Omega$ 的一个子集** $A \subseteq \Omega$。当且仅当本次试验结果 $\omega \in A$ 时，称**事件 $A$ 发生**。

  

| 事件运算 / 关系 | 集合表示 | 事件含义（自然语言） | 掷骰子示例（设 $A=\{2,4,6\}, B=\{4,5,6\}$） |

| :--- | :--- | :--- | :--- |

| **并事件** | $A \cup B$ | $A$ 与 $B$ **至少一个发生** | $A \cup B = \{2, 4, 5, 6\}$（偶数或 $>3$） |

| **交事件** | $A \cap B$（或 $AB$） | $A$ 与 $B$ **同时发生** | $A \cap B = \{4, 6\}$（偶数且 $>3$） |

| **差事件** | $A - B$ | **$A$ 发生，但 $B$ 不发生** | $A - B = \{2\}$（偶数但不大于 3） |

| **补事件（对立）** | $A^c = \Omega - A$ | **$A$ 不发生**（始终相对于 $\Omega$ 定义） | $A^c = \{1, 3, 5\}$（出现奇数） |

| **包含关系** | $D \subset B$ | **$D$ 发生时，$B$ 一定发生** | $D = \{6\} \subset B$ |

| **互斥（互不相容）** | $A \cap B = \emptyset$ | $A$ 与 $B$ **不能同时发生** | $\{2\} \cap \{5\} = \emptyset$ |

| **对立事件** | $A \cap B = \emptyset$ 且 $A \cup B = \Omega$ | 互斥，且**合起来覆盖整个样本空间** | $A$ 与 $A^c$ |

| **必然 / 不可能事件** | $\Omega$ / $\emptyset$ | 每次试验必发生 / 绝不发生 | 点数 $<7$（$\Omega$）/ 点数 $=7$（$\emptyset$） |

  

事件运算遵守集合代数规律：**交换律**（$A\cup B = B\cup A, A\cap B = B\cap A$）、**结合律**（$(A\cup B)\cup C = A\cup (B\cup C)$）与**分配律**（$A\cap(B\cup C) = (A\cap B)\cup(A\cap C)$）。

  

### 1.2 概率定义与基本计算规则

  

:::important[柯尔莫哥洛夫概率公理（三大基本规则）]

1. **非负性**：对任意事件 $A$，$P(A) \ge 0$；

2. **规范性**：$P(\Omega) = 1$；

3. **可加性**：若 $A \cap B = \emptyset$（互斥），则 $P(A \cup B) = P(A) + P(B)$（推广至可数无穷个两两互斥事件即为可数可加性）。

:::

  

由上述三条公理，可以直接推导出四条核心计算规则：

1. **补事件概率**：因 $A \cap A^c = \emptyset$ 且 $A \cup A^c = \Omega$，故 $P(A) + P(A^c) = P(\Omega) = 1 \implies P(A^c) = 1 - P(A)$。

2. **不可能事件概率为 0**：因 $\Omega = \Omega \cup \emptyset$ 且互斥，故 $1 = P(\Omega) = P(\Omega) + P(\emptyset) \implies P(\emptyset) = 0$。

3. **单调性（事件越大，概率不会更小）**：若 $A \subset B$，则 $B = A \cup (B - A)$ 且二者互斥，由非负性 $P(B - A) \ge 0$ 得：

   $$

   P(B) = P(A) + P(B - A) \ge P(A)

   $$

4. **加法公式（一般事件求并）**：当 $A, B$ 重叠时，直接相加会把交集 $A \cap B$ 计算两次，因此必须减去一次交集概率：

   $$

   P(A \cup B) = P(A) + P(B) - P(A \cap B)

   $$

  

:::caution[古典概型（计数公式）的前提]

当样本空间 $\Omega$ **有限且所有样本点等可能**时，事件概率可转化为计数问题：

$$

P(A) = \frac{|A|}{|\Omega|} = \frac{A \text{ 包含的有利结果数}}{\Omega \text{ 的全部可能结果数}}

$$

**警惕误区**：“能列出所有结果”不代表它们具有相同概率！例如对于质地不均匀的**偏骰子**，虽然 $\Omega=\{1,2,3,4,5,6\}$，但各点概率不同，此时绝不能直接用 $|A|/|\Omega|$ 数个数计算。

:::

  

### 1.3 独立性：互不影响的概率关系

  

多次试验的结果需要同时记录每一次的结果。例如连续掷两次公平骰子，样本空间为有序对集合 $\Omega = \{(i,j) : i,j \in \{1,\dots,6\}\}$，共 $6 \times 6 = 36$ 个等可能样本点。

设 $A = \{\text{第一次为偶数}\}$（含 $3 \times 6 = 18$ 个样本点，$P(A) = 1/2$），$B = \{\text{第二次} > 3\}$（含 $6 \times 3 = 18$ 个样本点，$P(B) = 1/2$）。交事件 $A \cap B$ 包含 $3 \times 3 = 9$ 个结果，$P(A \cap B) = 9/36 = 1/4 = P(A)P(B)$。

  

:::note[定义 1.2：事件独立性]

若两个事件 $A$ 和 $B$ 满足：

$$

P(A \cap B) = P(A)P(B)

$$

则称事件 $A$ 与 $B$ **相互独立（Independent）**。

:::

  

:::warning[核心辨析：互不相容（互斥） $\neq$ 独立]

这两种关系都在描述事件怎样一起发生，但物理与数学含义截然相反：

- **互不相容（互斥，$A \cap B = \emptyset$）**：表示两个事件**不能同时发生**，此时 $P(A \cap B) = 0$。一旦 $A$ 发生，$B$ 发生的概率立刻变为 $0$（影响极大！）。

- **独立（$P(A \cap B) = P(A)P(B)$）**：表示一个事件发生与否**完全不改变**另一个事件发生的概率。

- **思考题**：互不相容的两个事件，可能独立吗？

  :spoiler[**答案**：当 $P(A) > 0$ 且 $P(B) > 0$ 时，互不相容的两个事件**绝不可能独立**（因为 $P(A\cap B) = 0 \neq P(A)P(B)$）。只有当至少有一个事件概率为 $0$（如空集 $\emptyset$）时，才同时满足 $P(A\cap B)=0$ 与 $P(A)P(B)=0$。]

:::

  

:::tip[解题技巧：“至少一次发生”通常先算补事件]

求“掷三次骰子，至少出现一次 6”的概率：若直接正向分类，需拆分为“恰 1 次、恰 2 次、3 次都是 6”并小心避免重复；而其补事件是“三次都不是 6”，由独立性立得：

$$

P(\text{至少一次 } 6) = 1 - P(\text{三次都不是 } 6) = 1 - \left(\frac{5}{6}\right)^3 = \frac{91}{216}

$$

**课堂练习**：某抽奖活动每次中奖概率为 $0.2$，各次抽奖相互独立，连续抽 3 次，至少中奖 1 次的概率是多少？

:spoiler[**解析**：$P(\text{至少中奖 1 次}) = 1 - (1 - 0.2)^3 = 1 - 0.8^3 = 1 - 0.512 = 0.488$。]

:::

  

#### AI 实例：神经网络中的 Dropout

  

训练神经网络时，两个神经元 $N_1, N_2$ 分别以 $0.2$ 的概率被随机丢弃（Dropout），且二者是否被丢弃相互独立。设 $A=\{N_1 \text{ 被丢弃}\}, B=\{N_2 \text{ 被丢弃}\}$，则 $P(A)=P(B)=0.2$：

1. **两个神经元同时被丢弃的概率**：由独立性，$P(A \cap B) = P(A)P(B) = 0.2 \times 0.2 = 0.04$；

2. **至少有一个神经元被丢弃的概率**：由加法公式（或补事件 $1 - 0.8^2$），$P(A \cup B) = P(A) + P(B) - P(A \cap B) = 0.2 + 0.2 - 0.04 = 0.36$。

  

### 1.4 条件概率与乘法公式

  

当已知某个新信息（事件 $B$ 发生）后，讨论范围从整个样本空间 $\Omega$ **缩小到 $B$ 内部**，此时需要在 $B$ 内部对同时属于 $A$ 的部分 $A \cap B$ 重新归一化：

  

:::important[定义 1.3：条件概率与乘法公式]

- **条件概率（Conditional Probability）**：当 $P(B) > 0$ 时，在已知 $B$ 发生的条件下 $A$ 发生的概率为：

  $$

  P(A \mid B) = \frac{P(A \cap B)}{P(B)}

  $$

- **乘法公式（Multiplication Rule）**：将上式两边同乘 $P(B)$，即可将条件概率还原为联合（同时发生）概率：

  $$

  P(A \cap B) = P(A \mid B)P(B) = P(B \mid A)P(A)

  $$

- **独立的条件概率刻画**：当 $P(B)>0$ 时，$A$ 与 $B$ 独立 $\iff P(A \mid B) = P(A)$（即条件信息 $B$ 没有提供关于 $A$ 的任何额外信息）。

:::

  

- **注意区分 $P(A \mid B)$ 与 $P(B \mid A)$**：竖线“$\mid$”右边是已知信息（新的分母/讨论范围）。例如掷骰子设 $A=\{6\}, B=\{2,4,6\}$（故 $A \subset B$）：

  - 已知偶数的条件下掷出 6：$P(A \mid B) = \frac{P(\{6\})}{P(\{2,4,6\})} = \frac{1/6}{3/6} = \frac{1}{3}$；

  - 已知掷出 6 的条件下是偶数：$P(B \mid A) = \frac{P(\{6\})}{P(\{6\})} = 1$。

  

**质检抽样算例**：一批产品共 100 件（一等品 60 件、二等品 30 件、不合格品 10 件，故合格品共 $60+30=90$ 件）。从中连续随机抽取 2 件，**不放回**：

1. 已知第一次抽到合格品，它是一等品的概率：$P(\text{一等品} \mid \text{合格品}) = \frac{60}{90} = \frac{2}{3}$；

2. 已知第一次抽到不合格品，第二次仍抽到不合格品的概率：剩下 99 件中含 9 件不合格品，故 $P(\text{第二次不合格} \mid \text{第一次不合格}) = \frac{9}{99} = \frac{1}{11}$；

3. 连续两次都抽到不合格品的概率：由乘法公式，$P(A \cap B) = P(A)P(B \mid A) = \frac{10}{100} \times \frac{9}{99} = \frac{1}{110}$。

  

### 1.5 全概率公式与 Bayes 公式

  

:::important[定理 1.1：全概率公式与 Bayes 公式]

设 $B_1, B_2, \dots, B_n$ 是样本空间 $\Omega$ 的一组**划分（完备事件组）**，即两两互斥 $B_i \cap B_j = \emptyset\ (i \neq j)$，且 $\bigcup_{i=1}^n B_i = \Omega$，$P(B_i) > 0$。对目标事件 $A$：

1. **全概率公式（由因推果，加权合并）**：

   $$

   P(A) = \sum_{i=1}^n P(B_i)P(A \mid B_i)

   $$

2. **Bayes 公式（由果溯因，观测后更新）**：当观察到新证据 $A$（$P(A)>0$）发生后，第 $k$ 种原因 $B_k$ 的后验概率为：

   $$

   P(B_k \mid A) = \frac{P(B_k)P(A \mid B_k)}{P(A)} = \frac{P(B_k)P(A \mid B_k)}{\sum_{i=1}^n P(B_i)P(A \mid B_i)}

   $$

:::

  

:::tip[先验、似然与后验的直觉]

$$

\underbrace{P(B_k)}_{\text{先验概率 (Prior)}} \xrightarrow[\text{似然 } P(A \mid B_k)]{\text{观察到新证据 } A} \underbrace{P(B_k \mid A)}_{\text{后验概率 (Posterior)}}

$$

- **先验 $P(B_k)$**：观察结果前已有的概率判断；

- **似然 $P(A \mid B_k)$**：说明“如果是原因 $B_k$，产生当前证据 $A$ 有多容易”；

- **后验 $P(B_k \mid A)$**：说明“看到证据 $A$ 之后，哪种原因更可信”。**Bayes 公式完成的是条件概率的方向转换！**

:::

  

#### 经典算例与 AI 应用

  

1. **公平骰子 vs 偏骰子**：盒中有公平骰子 $F$（$P(6\mid F)=1/6$）和偏骰子 $L$（$P(6\mid L)=1/2$），随机抽一枚（先验 $P(F)=P(L)=1/2$），掷一次得结果 $6$。

   - **全概率算分母**：$P(6) = P(F)P(6\mid F) + P(L)P(6\mid L) = \frac{1}{2}\times\frac{1}{6} + \frac{1}{2}\times\frac{1}{2} = \frac{1}{3}$；

   - **Bayes 算后验**：$P(L\mid 6) = \frac{P(L)P(6\mid L)}{P(6)} = \frac{1/4}{1/3} = \frac{3}{4}$（看到 6 后，抽到偏骰子的概率从 $1/2$ 更新为 $3/4$）。

2. **AI 垃圾邮件识别**：邮箱中 $20\%$ 是垃圾邮件（$P(S)=0.2, P(S^c)=0.8$）。垃圾邮件被 AI 标为“可疑”（事件 $A$）的概率 $P(A\mid S)=0.8$；普通邮件被误标为“可疑”的概率 $P(A\mid S^c)=0.1$。

   - 收到一封被 AI 标为“可疑”的邮件，全概率 $P(A) = 0.2 \times 0.8 + 0.8 \times 0.1 = 0.24$；

   - 真正是垃圾邮件的后验概率：$P(S \mid A) = \frac{0.2 \times 0.8}{0.24} = \frac{2}{3} \approx 66.7\%$。

  

#### 名题剖析：Monty Hall（三门问题）

  

**题目**：三扇门中一扇后有奖品，两扇为空（等概率 $1/3$）。你先固定选 1 号门。**主持人知道奖品在哪里**，并会从另外两扇门中打开一扇空门（不妨设打开了 3 号门）。你应该坚持 1 号门，还是换到 2 号门？

  

- **视角一：直接全局分析**

  - “坚持 1 号门获胜” $\iff$ 奖品本来就在 1 号门，概率为 $1/3$；

  - “换门获胜” $\iff$ 奖品本来不在 1 号门（只要奖品在 2 号或 3 号门，主持人必打开另一扇空门，换门必中！），故 $P(\text{换门获胜}) = 1 - 1/3 = 2/3$。

- **视角二：严格 Bayes 更新**

  - 设 $A_i = \{\text{奖品在 } i \text{ 号门}\}$（先验 $P(A_1)=P(A_2)=P(A_3)=1/3$），事件 $B = \{\text{主持人打开 3 号门}\}$。

  - **关键（主持人规则给出似然）**：

    - 若奖品在 1 号门（$A_1$），主持人可在 2、3 号门中等可能任开一扇：$P(B \mid A_1) = 1/2$；

    - 若奖品在 2 号门（$A_2$），主持人不能选你挑的 1 号门，也不能开有奖的 2 号门，**只能被迫打开 3 号门**：$P(B \mid A_2) = 1$；

    - 若奖品在 3 号门（$A_3$），主持人绝不会打开 3 号门：$P(B \mid A_3) = 0$。

  - 由全概率公式：$P(B) = \frac{1}{2}\times\frac{1}{3} + 1\times\frac{1}{3} + 0\times\frac{1}{3} = \frac{1}{2}$。

  - 由 Bayes 公式：

    $$

    P(A_1 \mid B) = \frac{(1/2)(1/3)}{1/2} = \frac{1}{3}, \qquad P(A_2 \mid B) = \frac{1 \times (1/3)}{1/2} = \frac{2}{3}

    $$

  - **核心洞察**：主持人打开哪扇门**不是随机噪声**，它强烈依赖奖品位置，因此把原本属于 3 号门的 $1/3$ 概率浓缩转移到了 2 号门上！

  

## 2. 随机变量与一维概率分布（Lecture 2.1）

  

### 2.1 随机变量、逆像与累积分布函数（CDF）

  

原始随机试验的结果形式各异（如服务器日志文本、两枚骰子的点数对），但我们真正关心的往往只是其中一个**数值特征**。

  

:::note[定义 2.1：随机变量与逆像]

- **随机变量（Random Variable）**：定义在样本空间 $\Omega$ 上的实值函数 $X: \Omega \to \mathbb{R}$。对每个随机结果 $\omega \in \Omega$，给出一个实数 $X(\omega)$。**函数 $X$ 本身是确定的映射规则，随机的是它接收到的输入 $\omega$。**

- **逆像（Preimage）**：数轴上的集合 $A \subseteq \mathbb{R}$ 在样本空间中对应的事件为：

  $$

  \{X \in A\} = X^{-1}(A) = \{\omega \in \Omega : X(\omega) \in A\}, \qquad P(X \in A) = P(X^{-1}(A))

  $$

  *注：$X^{-1}(A)$ 表示逆像集合，不是反函数！*

- **示性变量（Indicator Variable / 指示函数）**：将任意事件 $A$ 编码为 0–1 随机变量：

  $$

  I_A(\omega) = \begin{cases} 1, & \text{若 } \omega \in A \\ 0, & \text{若 } \omega \notin A \end{cases} \implies P(A) = P(I_A = 1), \quad I_A \sim \text{Bernoulli}(P(A))

  $$

:::

  

为了避免对数轴上无穷多个集合 $A$ 逐一计算 $P(X \in A)$，我们只需记录最简单的半直线族 $A = (-\infty, x]$：

  

:::important[定义 2.5 & 定理 2.7–2.8：累积分布函数（CDF）及其充要刻画]

- **累积分布函数（CDF）**：$F_X: \mathbb{R} \to [0,1]$，定义为 $F_X(x) = P(X \le x),\ \forall x \in \mathbb{R}$。

- **区间概率恢复**：对任意 $a < b$，$P(a < X \le b) = F_X(b) - F_X(a)$（只用减法！）。

- **Theorem 2.7（分布唯一性）**：若两个随机变量 $X, Y$ 的 CDF 处处相等（$\forall x \in \mathbb{R}, F_X(x) = F_Y(x)$），则它们对一切可测集合 $A$ 的概率都相同：$P(X \in A) = P(Y \in A)$。

- **Theorem 2.8（CDF 的三条充要条件）**：函数 $F: \mathbb{R} \to [0,1]$ 是某个随机变量的 CDF，**当且仅当**同时满足：

  1. **单调不减**：$x_1 < x_2 \implies F(x_1) \le F(x_2)$；

  2. **两端归一**：$\lim_{x \to -\infty} F(x) = 0$，$\lim_{x \to +\infty} F(x) = 1$；

  3. **右连续**：$F(x) = F(x^+)$。在任意点 $x$ 处，左极限为 $F(x^-) = P(X < x)$，**跳跃高度恰为单点概率**：

     $$

     P(X = x) = F(x) - F(x^-)

     $$

:::

  

### 2.2 离散型随机变量与六大常用分布

  

- **离散型随机变量**：可能取值只有**有限个**或**可列无限个**（如 $x_1, x_2, \dots$，关键在于取值之间有间隔、能一个一个“数”出来，未必是整数，如 $0.5, 1.5, 2.5$）。

- **概率质量函数（PMF）**：$f_X(x) = p_X(x) = P(X = x)$（不在取值集合里的实数点处 PMF 定义为 $0$）。

  - **PMF 充要条件**：① **非负性** $f(x) \ge 0$；② **归一性** $\sum_x f(x) = 1$。

  

| 分布名称与记号 | 产生机制（问题类型） | PMF $P(X = x)$ | 取值范围 | 关键性质与联系 |

| :--- | :--- | :--- | :--- | :--- |

| **点质量分布** $X \sim \delta_a$ | 结果恒定为常数 $a$（完全无随机性） | $f(a) = 1$，其余为 $0$ | $\{a\}$ | 常量是随机变量的退化特例 |

| **离散均匀** $\text{Discrete Uniform}$ | 有限 $k$ 个结果，完全等可能 | $f(x) = \frac{1}{k}$ | $\{1, 2, \dots, k\}$ | 公平六面骰子：$k=6, f(x)=1/6$ |

| **伯努利分布** $\text{Bernoulli}(p)$ | 单次试验：成功（1）/ 失败（0） | $p^x(1-p)^{1-x}$ | $\{0, 1\}$ | 示性变量 $I_A \sim \text{Bernoulli}(P(A))$ |

| **二项分布** $\text{Binomial}(n,p)$ | **固定 $n$ 次**独立重复试验中成功的次数 | $\binom{n}{k} p^k (1-p)^{n-k}$ | $\{0, 1, \dots, n\}$ | $n$ 个 i.i.d. $\text{Bernoulli}(p)$ 之和；同参数 $p$ 独立可加：$B(n_1,p)+B(n_2,p)\sim B(n_1+n_2,p)$ |

| **几何分布** $\text{Geometric}(p)$ | **固定成功 1 次**，等到首次成功所需的尝试次数 | $p(1-p)^{k-1}$ | $\{1, 2, 3, \dots\}$ | 前 $k-1$ 次失败、第 $k$ 次成功；等比级数求和为 $1$ |

| **泊松分布** $\text{Poisson}(\lambda)$ | 单位时间/空间内**稀有事件**发生的次数（$\lambda > 0$） | $e^{-\lambda} \frac{\lambda^k}{k!}$ | $\{0, 1, 2, \dots\}$ | 独立可加性：$\text{Poisson}(\lambda_1)+\text{Poisson}(\lambda_2)\sim \text{Poisson}(\lambda_1+\lambda_2)$ |

  

:::tip[选分布的核心准则]

选分布看的不是“数据长什么样”，而是**“这个数是怎样产生的（生成机制）”**。例如二项分布必须严格满足四条前提：① 次数 $n$ 固定；② 各次独立；③ 每次仅两种结果；④ 成功概率同为 $p$。

在生成式 AI（LLM）中，预测下一个词（Token）就是一个离散随机变量，词表上 Softmax 输出的概率向量就是它的 PMF！

:::

  

### 2.3 连续型随机变量与七大常用分布

  

同一台服务器，问“一分钟内来了**多少个**请求”产生离散变量（$\text{Poisson}(\lambda)$）；换个问法，问“到下一个请求到达还要等**多久**”则取值填满区间，产生**连续型随机变量**。

  

:::important[连续型随机变量的三大核心铁律]

1. **单点概率必为 0，且“概率为 0 $\neq$ 不可能事件”**：

   - 在 $[0,5]$ 分钟等公交车，恰好在 $X = 3.000\dots$ 分钟到车完全可能发生，但事先押中这一个点的概率 $P(X=3)=0$（若每点有正概率 $\varepsilon>0$，无穷多点相加必发散）。

   - **重要推论**：连续型随机变量写区间概率时**不必纠结端点开闭**：

     $$

     P(a \le X \le b) = P(a < X \le b) = P(a \le X < b) = P(a < X < b)

     $$

2. **概率密度函数（PDF, $f_X(x)$）：密度本身不是概率，面积才是概率！**

   - 类比粗细不均匀的铁丝：单点质量为 0，线密度 $f(x)$ 是“每单位长度上的概率”：$P(x \le X \le x+\Delta x) \approx f(x)\Delta x$。

   - 区间概率是密度曲线下的面积：$P(a < X < b) = \int_a^b f_X(x)\,dx$，且 $f_X(x) = F_X'(x)$。

3. **PDF 的充要条件与“密度可以大于 1”**：

   - 充要条件：① **非负** $f(x) \ge 0$；② **总面积为 1** $\int_{-\infty}^{+\infty} f(x)\,dx = 1$。

   - **误区警示**：**并不要求 $f(x) \le 1$！** 例如 $X \sim \text{Uniform}(0, 0.5)$ 在区间内的密度处处为 $f(x) = 2 > 1$，但总面积 $2 \times 0.5 = 1$。$f(x)$ 高只代表附近概率更集中。

:::

  

| 分布名称与记号 | 产生机制（物理/统计背景） | 概率密度函数 PDF $f(x)$ | 支持集 | 核心性质与联系 |

| :--- | :--- | :--- | :--- | :--- |

| **均匀分布** $\text{Uniform}(a,b)$ | 在区间 $[a,b]$ 内完全无偏好 | $\frac{1}{b-a}$ | $[a, b]$ | 概率只取决于区间长度：$P(c \le X \le d) = \frac{d-c}{b-a}$ |

| **正态分布** $N(\mu, \sigma^2)$ | 围绕中心 $\mu$ 的随机波动（测量误差、噪声） | $\frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$ | $\mathbb{R}$ | ① 标准化 $Z=\frac{X-\mu}{\sigma}\sim N(0,1)$，$P(a<X<b)=\Phi(\frac{b-\mu}{\sigma})-\Phi(\frac{a-\mu}{\sigma})$；<br>② **独立相加仍正态**：$\sum X_i \sim N(\sum \mu_i, \sum \sigma_i^2)$ |

| **指数分布** $\text{Exp}(\beta)$ 或 $\text{Exp}(\lambda)$ | 到下一个事件发生还要**等多久** | 尺度参数 $\beta$：$\frac{1}{\beta}e^{-x/\beta}$<br>率参数 $\lambda$：$\lambda e^{-\lambda x}$ | $(0, +\infty)$ | $\beta = 1/\lambda$ 为平均等待时间；与 $\text{Poisson}(\lambda)$ 配对，且 $\text{Exp}(\beta)=\text{Gamma}(1,\beta)$ |

| **伽马分布** $\text{Gamma}(\alpha, \beta)$ | 等到**第 $\alpha$ 个事件**发生的总时间 | $\frac{x^{\alpha-1}e^{-x/\beta}}{\beta^\alpha \Gamma(\alpha)}$ | $(0, +\infty)$ | 同尺度 $\beta$ 独立可加：$\sum X_i \sim \text{Gamma}(\sum \alpha_i, \beta)$ |

| **贝塔分布** $\text{Beta}(\alpha, \beta)$ | 对 $(0,1)$ 之间的**未知比例/概率本身**建模 | $\frac{\Gamma(\alpha+\beta)}{\Gamma(\alpha)\Gamma(\beta)} x^{\alpha-1}(1-x)^{\beta-1}$ | $(0, 1)$ | $\alpha=\beta=1$ 时退化为 $U(0,1)$；点击率、合格率建模 |

| **$t$ 分布与柯西分布** $t_\nu$ / $\text{Cauchy}$ | 正态派生，比正态**尾巴更厚**（易出极端值） | $\text{Cauchy} = t_1$: $\frac{1}{\pi(1+x^2)}$ | $\mathbb{R}$ | 自由度 $\nu \to \infty$ 时 $t_\nu \to N(0,1)$；$\text{Cauchy}$ 连均值都不存在 |

| **卡方分布** $\chi^2_p$ | $p$ 个独立标准正态 $Z_i \sim N(0,1)$ 的**平方和** | $\frac{x^{p/2-1}e^{-x/2}}{\Gamma(p/2)2^{p/2}}$ | $(0, +\infty)$ | $\sum_{i=1}^p Z_i^2 \sim \chi^2_p = \text{Gamma}(p/2, \text{scale}=2)$ |

  

## 3. 期望与方差（Lecture 2.2）

  

### 3.1 概括分布的位置：众数、中位数与数学期望

  

要把一整条分布压缩成一个代表性的“中心”数值，有三个候选：

1. **众数（Mode）**：$\text{Mode}(X) \in \arg\max_x p_X(x)$（或 $\arg\max_x f_X(x)$），可能不止一个；

2. **中位数（Median）**：把概率对半分的点 $m$，满足 $P(X \le m) \ge 1/2$ 且 $P(X \ge m) \ge 1/2$（连续严格递增时 $m = F_X^{-1}(1/2)$）；

3. **均值 / 数学期望（Mean / Expectation, $E[X]$）**：按概率加权的平均，即力学上**分布的重心**。

  

:::important[定义 2.6：数学期望（Expectation）与存在性前提]

- **离散型**：$E[X] = \sum_x x\, p_X(x)$（要求 $\sum_x |x| p_X(x) < \infty$）；

- **连续型**：$E[X] = \int_{-\infty}^{\infty} x\, f_X(x)\,dx$（**前提**：必须绝对可积 $\int_{-\infty}^{\infty} |x| f_X(x)\,dx < \infty$，否则称**期望不存在**！）。

:::

  

:::caution[期望的三个深刻认知（拒绝直觉陷阱）]

1. **期望是概括量与长期平均，不必是可能取值**：掷一枚公平骰子 $E[X] = 3.5$，永远掷不出 $3.5$；但在大数次重复下（如赌场做庄、保险定价、蒙特卡洛模拟），样本平均会稳稳收敛到 $E[X]$。

2. **反直觉案例 ①（SSR 抽卡）**：某游戏 SSR 概率 $p = 0.006$，首次出货抽数 $X \sim \text{Geom}(0.006)$，期望抽数为 $E[X] = 1/0.006 \approx 166.7$ 次。但即使抽满 167 次，未出货概率仍高达：

   $$

   P(X > 167) = (1 - 0.006)^{167} \approx e^{-1} \approx 36.6\%

   $$

   “期望次数”绝不代表“大多数人都能在这个次数内成功”！

3. **反直觉案例 ②（双倍或减半博弈）**：初始本金 $c$，每局独立以 $1/2$ 概率翻倍（$\times 2$）、$1/2$ 概率减半（$\times 1/2$）。$n$ 局后本金 $X_n = c\prod_{i=1}^n R_i$，期望为 $E[X_n] = c\left(\frac{1}{2}\times 2 + \frac{1}{2}\times \frac{1}{2}\right)^n = c\left(\frac{5}{4}\right)^n \to \infty$！但实际上 $\log_2(X_n/c)$ 对称随机游走，**中位数始终停留在初始本金 $c$ 附近**——期望被极少数全胜的极端大值显著拉高了。

4. **重尾分布与 Cauchy 分布**：

   - **Cauchy 分布**：$f(x) = \frac{1}{\pi(1+x^2)}$ 虽关于 $0$ 完全对称，但 $\int_{-\infty}^\infty |x|f(x)\,dx = \infty$，故 **$E[X]$ 不存在**（不能因为对称就说期望为 0！）。

   - **重尾数据**：当存在极端大值（如 99 人收入 20 万、1 人收入 2000 万，均值 39.8 万高于 99% 的人，而中位数仍为 20 万；或网络请求时延、金融收益）时，均值对极端值极敏感，工程界普遍改报**中位数（P50）或 P99 分位数**。

:::

  

### 3.2 随机变量函数的期望（LOTUS）与线性性

  

:::important[定理 3.6（LOTUS）与期望的线性性]

1. **无意识统计学家定理（LOTUS）**：求 $Y = g(X)$ 的期望时，**无需先求 $g(X)$ 的分布**，直接用 $X$ 的分布对 $g(x)$ 加权即可：

   $$

   E[g(X)] = \sum_x g(x)p_X(x) \quad (\text{离散}), \qquad E[g(X)] = \int_{-\infty}^{\infty} g(x)f_X(x)\,dx \quad (\text{连续})

   $$

2. **期望的线性性（无需独立！）**：对任意常数 $a_i, b$ 及**任意**随机变量 $X_1, \dots, X_n$（**哪怕它们之间强烈相关、完全不独立**），恒有：

   $$

   E[aX + b] = aE[X] + b, \qquad E\left[\sum_{i=1}^n a_i X_i\right] = \sum_{i=1}^n a_i E[X_i]

   $$

:::

  

**为什么“可以无条件相加”是均值最核心的优势？**

因为它允许我们把极其复杂的随机变量**拆成若干个简单随机变量（尤其是 0–1 示性变量）之和**，无需推导总和的分布就能秒算期望！

- **用法 1（二项分布均值）**：将 $X \sim \text{Binomial}(n,p)$ 拆成 $X = \sum_{i=1}^n X_i$，其中 $X_i \sim \text{Bernoulli}(p)$，$E[X_i] = p \implies E[X] = np$。

- **用法 2（帽子问题 / 随机排列不动点个数）**：$n$ 个人把帽子丢进筐里再随机各取一顶，求拿对自己帽子的人数 $X$ 的期望。

  令示性变量 $I_i = 1$ 表示第 $i$ 个人拿对自己的帽子，否则为 $0$。虽然 $I_1, \dots, I_n$ **并不独立**（比如前 $n-1$ 人都拿对，第 $n$ 人必拿对），但每个人拿对的概率都是 $P(I_i = 1) = 1/n$。由线性性：

  $$

  E[X] = E\left[\sum_{i=1}^n I_i\right] = \sum_{i=1}^n E[I_i] = n \times \frac{1}{n} = 1

  $$

- **用法 3（折木棍问题）**：单位长度棍子在 $X \sim \text{Uniform}(0,1)$ 处折断，较长一段长度 $Y = \max(X, 1-X)$ 的期望：

  $$

  E[Y] = \int_0^{1/2} (1-x)\,dx + \int_{1/2}^1 x\,dx = \frac{3}{8} + \frac{3}{8} = \frac{3}{4}

  $$

  

### 3.3 方差、标准差与最优常数预测

  

当两条上学路线平均耗时都是 $30$ 分钟（路线 A 取 $28, 30, 32$；路线 B 取 $20, 30, 40$，概率均为 $0.25, 0.5, 0.25$）时，为了刻画波动与风险：

- 若用 $E[X-\mu]$：正负抵消恒为 $0$（出局）；

- 若用绝对偏离 $E[|X-\mu|]$：在 $x=\mu$ 处不可微，且相加无干净公式；

- 因此选用**平方偏离 $E[(X-\mu)^2]$**（处处可微、展开好算、独立可加），再开根号把单位还原。

  

:::important[定义 2.7：方差、标准差及其核心性质]

- **定义式与计算式**（计算式通常比定义式快得多）：

  $$

  \text{Var}(X) = \sigma^2 = E[(X - \mu)^2] = E[X^2] - \mu^2, \qquad \text{SD}(X) = \sigma = \sqrt{\text{Var}(X)}

  $$

- **最优常数预测性质**：对任意常数 $c$，均方误差可分解为：

  $$

  E[(X - c)^2] = \text{Var}(X) + (E[X] - c)^2

  $$

  因此，**均值 $c = E[X]$ 是使均方误差（MSE）最小的唯一最优常数预测**，且最小均方误差恰好就是 $\text{Var}(X)$！

- **方差的三条运算性质**（前两条无条件成立，**第三条要求独立**）：

  1. $\text{Var}(c) = 0$（方差为 0 $\iff X$ 几乎必然为常数）；

  2. **平移不变，缩放平方**：$\text{Var}(aX + b) = a^2 \text{Var}(X)$，$\text{SD}(aX + b) = |a|\text{SD}(X)$；

  3. **独立可加性**：若 $X$ 与 $Y$ **相互独立**，则 $\text{Var}(X + Y) = \text{Var}(X) + \text{Var}(Y)$。

:::

  

:::tip[经典推导与常见分布均值方差汇总]

- **标准正态 $Z \sim N(0,1)$ 方差的三行推导**：利用标准正态密度 $\varphi(z) = \frac{1}{\sqrt{2\pi}}e^{-z^2/2}$ 的导数恒等式 $\varphi'(z) = -z\varphi(z)$ 及分部积分：

  $$

  E[Z^2] = \int_{-\infty}^\infty z \cdot z\varphi(z)\,dz = \int_{-\infty}^\infty z(-\varphi'(z))\,dz = \Big[-z\varphi(z)\Big]_{-\infty}^\infty + \int_{-\infty}^\infty \varphi(z)\,dz = 0 + 1 = 1

  $$

  故 $\text{Var}(Z) = 1 - 0^2 = 1$，进而对一般正态 $X = \mu + \sigma Z \sim N(\mu, \sigma^2)$ 有 $\text{Var}(X) = \sigma^2$。

- **Poisson$(\lambda)$ 方差推导技巧**：先算二阶下降阶乘矩 $E[X(X-1)] = \sum_{k=2}^\infty k(k-1)e^{-\lambda}\frac{\lambda^k}{k!} = \lambda^2 e^{-\lambda}\sum_{j=0}^\infty \frac{\lambda^j}{j!} = \lambda^2$，展开得 $E[X^2] = \lambda^2 + E[X] = \lambda^2 + \lambda$，故 $\text{Var}(X) = \lambda^2 + \lambda - \lambda^2 = \lambda$。**均值与方差相等（都等于 $\lambda$）是识别 Poisson 分布最显著的特征！**

:::

  

| 分布类型 | 分布记号 | 均值 $E[X]$ | 方差 $\text{Var}(X)$ | 备注与工程直觉 |

| :--- | :--- | :--- | :--- | :--- |

| **离散型** | $\text{Bernoulli}(p)$ | $p$ | $p(1-p)$ | $p=0$ 或 $1$ 时方差为 $0$，$p=1/2$ 时方差最大（$1/4$） |

| **离散型** | $\text{Binomial}(n, p)$ | $np$ | $np(1-p)$ | 由 $n$ 个独立 $\text{Bernoulli}(p)$ 的方差直接相加得到 |

| **离散型** | $\text{Geometric}(p)$ | $\frac{1}{p}$ | $\frac{1-p}{p^2}$ | $p$ 很小时方差 $(1-p)/p^2$ 极大（抽卡“非酋”体验的根源） |

| **离散型** | $\text{Poisson}(\lambda)$ | $\lambda$ | $\lambda$ | 样本均值与样本方差接近常是 Poisson 信号 |

| **离散型** | 公平六面骰子 $U\{1..6\}$ | $3.5$ | $\frac{35}{12} \approx 2.92$ | $E[X^2] = \frac{91}{6}$，两枚独立骰子和的方差为 $\frac{35}{6} \approx 5.83$ |

| **连续型** | $\text{Uniform}(a, b)$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ | 方差只与区间长度 $b-a$ 有关，与位置无关 |

| **连续型** | $\text{Normal}(\mu, \sigma^2)$ | $\mu$ | $\sigma^2$ | 均值定位置，标准差定尺度 |

| **连续型** | $\text{Exp}(\beta)$（尺度 $\beta$） | $\beta$（或 $1/\lambda$） | $\beta^2$（或 $1/\lambda^2$） | 分部积分即得 $E[X]=\beta, E[X^2]=2\beta^2$ |

| **连续型** | $\text{Gamma}(\alpha, \beta)$ | $\alpha\beta$ | $\alpha\beta^2$ | $\alpha$ 个独立 $\text{Exp}(\beta)$ 之和 |

| **连续型** | $\text{Beta}(\alpha, \beta)$ | $\frac{\alpha}{\alpha+\beta}$ | $\frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}$ | 均值即 $\alpha$ 占 $\alpha+\beta$ 的权重比例 |

| **连续型** | $\chi^2(p)$ | $p$ | $2p$ | $\text{Gamma}(p/2, 2)$ 的特例 |

| **连续型** | $t(\nu)$ | $0\ (\nu > 1)$ | $\frac{\nu}{\nu - 2}\ (\nu > 2)$ | $\nu=1$（Cauchy）均值不存在；$1<\nu\le 2$ 方差无穷大 |

  

**课堂练习（混合分布方差计算）**：先抛一枚均匀硬币，若正面则 $X \sim U(0,1)$，若反面则 $X \sim U(3,4)$。求 $E[X]$ 与 $\text{SD}(X)$。

:spoiler[**解析**：正反面各占 $1/2$。在 $U(0,1)$ 下 $E[X_1]=0.5, E[X_1^2]=\int_0^1 x^2dx = 1/3$；在 $U(3,4)$ 下 $E[X_2]=3.5, E[X_2^2] = \text{Var}(X_2) + 3.5^2 = \frac{1}{12} + \frac{49}{4} = \frac{37}{3}$。

故总体 $E[X] = \frac{1}{2}(0.5) + \frac{1}{2}(3.5) = 2$；总体 $E[X^2] = \frac{1}{2}\left(\frac{1}{3}\right) + \frac{1}{2}\left(\frac{37}{3}\right) = \frac{19}{3}$。

因此 $\text{Var}(X) = E[X^2] - (E[X])^2 = \frac{19}{3} - 4 = \frac{7}{3}$，$\text{SD}(X) = \sqrt{7/3} \approx 1.53$。]

  

## 4. 多个随机变量与相关关系（Lecture 2.3）

  

### 4.1 联合分布、边缘分布与非矩形区域积分

  

只知道两个变量各自的边缘分布（如 $E[X], \text{Var}(X), E[Y], \text{Var}(Y)$），会完全丢失它们**“怎样一起变化”**（正相关、负相关或无关）的信息。我们将定义在**同一个样本空间 $\Omega$** 上的多个随机变量打包为**随机向量** $(X,Y): \Omega \to \mathbb{R}^2$。

  

1. **联合分布与联合密度**：

   - **离散型联合 PMF**：$p_{X,Y}(x,y) = P(X=x, Y=y)$（列联表中所有格子概率之和为 1）。

   - **连续型联合 PDF**：曲面 $f_{X,Y}(x,y) \ge 0$ 满足全平面积分 $\iint_{\mathbb{R}^2} f_{X,Y}(x,y)\,dx\,dy = 1$，平面区域 $A$ 的概率是**曲面下的体积** $P((X,Y)\in A) = \iint_A f_{X,Y}(x,y)\,dx\,dy$。

   - **联合分布函数（CDF）**：$F_{X,Y}(x,y) = P(X \le x, Y \le y)$。在连续型下，$f_{X,Y}(x,y) = \frac{\partial^2 F_{X,Y}(x,y)}{\partial x \partial y}$；**矩形区域概率的四点公式**：

     $$

     P(a < X \le b, c < Y \le d) = F(b,d) - F(a,d) - F(b,c) + F(a,c)

     $$

2. **边缘分布（Marginal Distribution）：把不关心的变量“加掉”或“积掉”**

   $$

   p_X(x) = \sum_y p_{X,Y}(x,y) \quad (\text{行和}), \qquad f_X(x) = \int_{-\infty}^{\infty} f_{X,Y}(x,y)\,dy

   $$

  

:::warning[核心算例与高频考点：“先来后来”与三角形支持集积分定限]

**问题**：两人在 $[0,1]$ 内独立均匀到达（$X_1, X_2 \stackrel{\text{iid}}{\sim} \text{Uniform}(0,1)$）。记后到者时刻 $X = \max(X_1, X_2)$，先到者时刻 $Y = \min(X_1, X_2)$。

- **求联合密度**：由于恒有 $Y < X$，点 $(X,Y)$ 只可能落在**三角形区域 $0 < y < x < 1$** 内。

  - *几何直觉*：原本 $(X_1,X_2)$ 在单位正方形上密度为 $1$，取 $\max/\min$ 相当于把正方形沿对角线 $y=x$ 对折，两种次序叠到同一个三角形上，故密度加倍为 $f_{X,Y}(x,y) = 2\ (0 < y < x < 1)$。

  - *代数推导*：当 $0 < y < x < 1$ 时，$F_{X,Y}(x,y) = P(\text{两个都} \le x) - P(\text{两个都落在 } (y,x]) = x^2 - (x-y)^2$，求混合偏导 $\frac{\partial^2 F}{\partial x \partial y} = 2$。

- **求边缘密度（积分限必须从图上读，内层限含外层变量！）**：

  - 固定 $x$，纵向扫描 $y$ 从 $0$ 到 $x$（**上限是 $x$，绝不是 $1$！**）：$f_X(x) = \int_0^x 2\,dy = 2x,\ (0 < x < 1)$；

  - 固定 $y$，横向扫描 $x$ 从 $y$ 到 $1$（**下限是 $y$，绝不是 $0$！**）：$f_Y(y) = \int_y^1 2\,dx = 2(1-y),\ (0 < y < 1)$。

- **求事件概率 $P(X + Y \le 1)$**：直线 $x+y=1$ 与支持集 $0<y<x<1$ 的交集为顶点 $(0,0), (1,0), (1/2, 1/2)$ 的三角形：

  - *先 $x$ 后 $y$（水平扫描，一段到底）*：$\int_0^{1/2} \int_y^{1-y} 2\,dx\,dy = \int_0^{1/2} 2(1-2y)\,dy = \frac{1}{2}$；

  - *先 $y$ 后 $x$（竖直扫描，必须在 $x=1/2$ 分两段）*：$\int_0^{1/2}\int_0^x 2\,dy\,dx + \int_{1/2}^1\int_0^{1-x} 2\,dy\,dx = \frac{1}{4} + \frac{1}{4} = \frac{1}{2}$。

:::

  

### 4.2 独立性的充要判据：密度能拆 + 支持集是直积

  

:::important[定理 2.9：随机变量独立的充要判据]

$X \perp\!\!\!\perp Y \iff P(X \in A, Y \in B) = P(X \in A)P(Y \in B)$（对任意集合 $A, B$）$\iff f_{X,Y}(x,y) = f_X(x)f_Y(y)$。

在实战中，判断连续型变量 $X, Y$ 独立必须**同时满足以下两个条件，缺一不可**：

1. **函数表达式能拆**：$f_{X,Y}(x,y)$ 能分解为纯 $x$ 函数与纯 $y$ 函数的乘积 $g(x)h(y)$；

2. **支持集是直积（矩形/区间叉积）**：允许取值的区域满足 $x$ 的范围与 $y$ 的范围互不牵连（不能出现 $0 < y < x < 1$ 这类边界相互依赖的三角形或圆域！）。

:::

  

- **反例警示**：在三角形区域 $0 < x < y < 1$ 上，联合密度 $f(x,y) = 8xy$（或 $f(x,y)=2$），虽然代数式能拆成 $8x \cdot y$，但**支持集是三角形而非直积**（已知 $X=x$ 会直接改变 $Y \in (x,1)$ 的取值范围），故 **$X$ 与 $Y$ 绝不独立**！

- **独立带来的两大简化**：① 独立可传递给任意函数：$X \perp\!\!\!\perp Y \implies g(X) \perp\!\!\!\perp h(Y)$；② **乘积的期望可拆**：$X \perp\!\!\!\perp Y \implies E[XY] = E[X]E[Y]$，从而和的方差交叉项消失 $\text{Var}(X+Y)=\text{Var}(X)+\text{Var}(Y)$。

  

### 4.3 协方差与相关系数

  

为了量化两个变量**线性关联的方向与强弱**，引入协方差与无量纲的相关系数：

  

:::important[定义 2.8：协方差（Covariance）与相关系数（Correlation）]

1. **协方差定义式与计算式**：

   $$

   \text{Cov}(X, Y) = E\big[(X - E[X])(Y - E[Y])\big] = E[XY] - E[X]E[Y]

   $$

   - **双线性性质**：$\text{Cov}(aX+b, cY+d) = ac\,\text{Cov}(X,Y)$；$\text{Cov}(X, Y+Z) = \text{Cov}(X,Y) + \text{Cov}(X,Z)$。

   - **和的方差通式**：

     $$

     \text{Var}(aX + bY) = a^2\text{Var}(X) + b^2\text{Var}(Y) + 2ab\,\text{Cov}(X,Y)

     $$

2. **相关系数（除以两个标准差消除量纲）**：当 $0 < \sigma_X, \sigma_Y < \infty$ 时，

   $$

   \rho(X, Y) = \frac{\text{Cov}(X, Y)}{\sigma_X \sigma_Y} \in [-1, 1]

   $$

   - **平移与缩放不变性（仅受正负号影响）**：$\rho(aX+b, cY+d) = \text{sgn}(ac)\rho(X,Y)\ (a,c\neq 0)$。

   - **Cauchy–Schwarz 证明与取等号充要条件**：对中心化变量 $U = X-E[X], V = Y-E[Y]$ 应用不等式 $|E[UV]|^2 \le E[U^2]E[V^2] = \sigma_X^2 \sigma_Y^2$ 即得 $|\rho| \le 1$；且

     $$

     |\rho(X, Y)| = 1 \iff Y = aX + b \ \text{几乎处处成立}\ (a \neq 0)

     $$

:::

  

:::caution[核心逻辑链：独立 $\implies$ 不相关，但反之一般不成立！]

- 若 $X \perp\!\!\!\perp Y$，则 $E[XY]=E[X]E[Y] \implies \text{Cov}(X,Y) = 0 \implies \rho(X,Y) = 0$（且 $\text{Var}(X+Y)=\text{Var}(X)+\text{Var}(Y)$）。

- **但 $\text{Cov}(X,Y) = 0$（或 $\text{Var}(X+Y)=\text{Var}(X)+\text{Var}(Y)$）只能说明没有线性关系，推不出独立！**

  - **必背经典反例**：设 $X \sim \text{Uniform}(-1, 1)$，令 $Y = X^2$。由奇函数对称性，$E[X] = 0$，$E[XY] = E[X^3] = 0$，故 $\text{Cov}(X,Y) = 0 - 0 = 0$（零相关）。但 $Y$ 完全由 $X$ 决定，二者显然不独立！

  - *注：零相关能推出独立的重要例外是 **(X,Y) 服从联合正态分布**（见第 5 节）。*

:::

  

**工程算例（两个传感器取平均降噪）**：已知两路测量误差 $E[X]=E[Y]=0$，$\sigma_X = 2, \sigma_Y = 3$，相关系数 $\rho_{X,Y} = 1/2$，融合均值 $Z = \frac{X+Y}{2}$。

- 先反解协方差：$\text{Cov}(X,Y) = \rho_{X,Y}\sigma_X\sigma_Y = \frac{1}{2}\times 2\times 3 = 3$；

- 融合误差方差：$\text{Var}(Z) = \frac{1}{4}\big(\text{Var}(X) + \text{Var}(Y) + 2\text{Cov}(X,Y)\big) = \frac{1}{4}(4 + 9 + 6) = \frac{19}{4} \implies \text{SD}(Z) = \frac{\sqrt{19}}{2} \approx 2.18$；

- 若两路误差独立（$\rho=0$），则 $\text{SD}(Z) = \frac{\sqrt{4+9}}{2} = \frac{\sqrt{13}}{2} \approx 1.80 < 2.18$。**结论：正相关的误差会削弱“取平均”的降噪效果！**

  

**课堂自测（5 道经典判断题）**：

1. 若 $\text{Cov}(X,Y) = 0$，则 $X$ 与 $Y$ 独立。

2. 若 $\text{Var}(X+Y) = \text{Var}(X) + \text{Var}(Y)$，则 $X$ 与 $Y$ 独立。

3. 身高的单位从厘米换成米，身高与体重的协方差不变。

4. $\rho(X, 5 - 2Y) = -\rho(X, Y)$。

5. 密度 $f(x,y) = 8xy\ (0 < x < y < 1)$ 可以写成 $8x \cdot y$，所以 $X$ 与 $Y$ 独立。

:spoiler[**答案与理由**：① **错**（反例 $X\sim U(-1,1), Y=X^2$）；② **错**（只能推出 $\text{Cov}(X,Y)=0$ 即不相关）；③ **错**（身高乘 $1/100$，协方差缩小为原来的 $1/100$，不变的是无量纲的相关系数 $\rho$）；④ **对**（$Y$ 前系数 $-2 < 0$，翻转符号，大小不变）；⑤ **错**（支持集 $0<x<y<1$ 是三角形而非直积，不独立）。]

  

## 5. 条件分布、条件期望与多维预测（Lecture 2.4 & 2.4+）

  

### 5.1 条件分布：取一行 / 切一刀，再归一化

  

以 AI 服务响应时间为例：请求类型 $X$ 分为“简单请求”（占 $0.6$，耗时 $Y$ 取 $1\text{s}, 3\text{s}$ 联合概率各 $0.30$）和“复杂请求”（占 $0.4$，耗时 $Y$ 取 $3\text{s}, 7\text{s}$ 联合概率各 $0.20$）。

  

- **离散条件 PMF（取一行，除以行和归一化）**：

  $$

  p_{Y\mid X}(y \mid x) = \frac{p_{X,Y}(x,y)}{p_X(x)}, \qquad p_X(x) > 0

  $$

  例如复杂请求下 $P(Y=3\mid X=\text{复杂}) = \frac{0.20}{0.40} = \frac{1}{2}$，$P(Y=7\mid X=\text{复杂}) = \frac{1}{2}$。

- **连续条件 PDF（沿 $X=x$ 切一刀，除以切片总面积归一化）**：

  $$

  f_{Y\mid X}(y \mid x) = \frac{f_{X,Y}(x,y)}{f_X(x)}, \qquad f_X(x) > 0 \implies \text{链式分解：} f_{X,Y}(x,y) = f_{Y\mid X}(y\mid x)f_X(x)

  $$

  - **为什么单点概率 $P(X=x)=0$ 还能条件化？** 因为连续条件密度处理的是窄带 $x < X < x+\varepsilon$ 在 $\varepsilon \to 0$ 时分子分母同约去宽度 $\varepsilon$ 后的**局部密度之比**，而非单点概率之商！

  - **先来后来算例**：已知 $f_{X,Y}(x,y)=2\ (0<y<x<1)$ 且边缘 $f_X(x)=2x$，则给定后到者时刻 $X=x$ 时，先到者时刻的条件密度为 $f_{Y\mid X}(y\mid x) = \frac{2}{2x} = \frac{1}{x}\ (0 < y < x)$，即 **$Y \mid X=x \sim \text{Uniform}(0, x)$**！

- **独立的三个等价刻画**：$X \perp\!\!\!\perp Y \iff f_{Y\mid X}(y\mid x) = f_Y(y) \iff f_{X,Y}(x,y) = f_X(x)f_Y(y)$（独立 = 条件分布根本不随条件改变）。

  

### 5.2 条件期望、条件方差与三个核心对象的区分

  

:::important[务必分清的三个数学对象：$\mathbb{E}[Y]$ vs $m(x)$ vs $m(X)$]

| 记号 | 数学本质 | 在 AI 响应时间算例中的具体表现 |

| :--- | :--- | :--- |

| **$\mathbb{E}[Y]$** | **一个常数（实数）** | 不用任何类型信息时的总体平均：$\mathbb{E}[Y] = 0.3\times 1 + 0.5\times 3 + 0.2\times 7 = 3.2\text{ 秒}$ |

| **$m(x) = \mathbb{E}[Y \mid X = x]$** | **关于自变量 $x$ 的确定性函数** | 填入具体类型输出该组均值：$m(\text{简单}) = 2\text{ 秒}$，$m(\text{复杂}) = 5\text{ 秒}$（或在先来后来例中 $m(x) = x/2$） |

| **$m(X) = \mathbb{E}[Y \mid X]$** | **一个随机变量（$X$ 的函数）** | 把随机的 $X$ 代入函数 $m(\cdot)$，结果随 $X$ 随机变化：以 $0.6$ 概率取 $2$，以 $0.4$ 概率取 $5$ |

:::

  

同理，**条件方差** $v(x) = \text{Var}(Y \mid X=x) = \mathbb{E}[(Y - m(x))^2 \mid X=x] = \mathbb{E}[Y^2 \mid X=x] - m(x)^2$ 是关于 $x$ 的函数（本例中 $v(\text{简单}) = \frac{1}{2}(1^2+3^2)-2^2 = 1$，$v(\text{复杂}) = \frac{1}{2}(3^2+7^2)-5^2 = 4$）；而 **$v(X) = \text{Var}(Y \mid X)$ 是随机变量**（以 $0.6$ 概率取 $1$，以 $0.4$ 概率取 $4$）。

  

- **条件期望的三条核心性质**：

  1. **线性性**：$\mathbb{E}[aY + bZ \mid X] = a\mathbb{E}[Y \mid X] + b\mathbb{E}[Z \mid X]$；

  2. **已知因子可提出（Taking out what is known）**：$\mathbb{E}[h(X)Y \mid X] = h(X)\mathbb{E}[Y \mid X]$（已知 $X$ 时，$h(X)$ 视为常数）；

  3. **残差条件均值为 0**：$\mathbb{E}[Y - m(X) \mid X] = 0$。

  

### 5.3 全期望公式、全方差公式与最佳均方预测（MSE）

  

:::important[定理 2.10：全期望公式、全方差公式（Eve's Law）与最佳均方预测]

1. **全期望公式（重期望定律 / Law of Iterated Expectations）**：

   $$

   \mathbb{E}[Y] = \mathbb{E}\big[\mathbb{E}[Y \mid X]\big] = \sum_x m(x)p_X(x) \quad \left(\text{或 } \int m(x)f_X(x)\,dx\right)

   $$

   *易错提醒：组均值必须按各组真实概率加权（$0.6\times 2 + 0.4\times 5 = 3.2$），绝不能把两组均值简单算术平均 $(2+5)/2 = 3.5$！*

2. **全方差公式（Law of Total Variance / 方差分解公式）**：将总偏差拆为 $\underbrace{(Y - m(X))}_{\text{组内偏差}} + \underbrace{(m(X) - \mathbb{E}[Y])}_{\text{组间偏差}}$，平方取期望后交叉项因 $\mathbb{E}[(m(X)-\mathbb{E}[Y])\mathbb{E}[Y-m(X)\mid X]] = 0$ 而严格消失，得：

   $$

   \text{Var}(Y) = \underbrace{\mathbb{E}\big[\text{Var}(Y \mid X)\big]}_{\text{组内平均波动 (Unexplained)}} + \underbrace{\text{Var}\big(\mathbb{E}[Y \mid X]\big)}_{\text{组间中心波动 (Explained)}}

   $$

   - 在 AI 请求算例中：$\mathbb{E}[v(X)] = 0.6\times 1 + 0.4\times 4 = 2.20$，$\text{Var}(m(X)) = 0.6(2-3.2)^2 + 0.4(5-3.2)^2 = 2.16$，总方差 $\text{Var}(Y) = 2.20 + 2.16 = 4.36\text{ 秒}^2$。

3. **条件均值是最佳均方预测（MSE 最优性）**：对任意预测函数 $g(X)$，均方误差可正交分解为：

   $$

   \mathbb{E}\big[(Y - g(X))^2\big] = \mathbb{E}\big[\text{Var}(Y \mid X)\big] + \mathbb{E}\big[(m(X) - g(X))^2\big] \ge \mathbb{E}\big[\text{Var}(Y \mid X)\big]

   $$

   当且仅当 **$g(X) = m(X) = \mathbb{E}[Y \mid X]$** 时取到最小均方误差 $\mathbb{E}[\text{Var}(Y \mid X)]$！利用特征 $X$ 所降低的均方误差恰好等于组间方差 $\text{Var}(m(X))$。这也是机器学习中用 MSE 训练回归模型的理论根基。

:::

  

:::caution[易错辨析：信息越多，剩余波动“平均不增 $\neq$ 处处不增”]

全方差公式保证的是**平均条件方差不超过总体方差**：$\mathbb{E}[\text{Var}(Y \mid X)] = \text{Var}(Y) - \text{Var}(\mathbb{E}[Y \mid X]) \le \text{Var}(Y)$。

但**某个具体条件值 $X=x$ 下的条件方差完全可能比总体方差更大！**

例如在“先来后来”算例中，$Y \mid X=x \sim \text{Uniform}(0,x)$，$\text{Var}(Y\mid X=x) = \frac{x^2}{12}$。总体方差 $\text{Var}(Y) = \frac{1}{18} \approx 0.0556$，平均条件方差 $\mathbb{E}[\text{Var}(Y\mid X)] = \frac{\mathbb{E}[X^2]}{12} = \frac{1/2}{12} = \frac{1}{24} \le \frac{1}{18}$；但当观测到 $X = 0.9$ 时，$\text{Var}(Y \mid X=0.9) = \frac{0.81}{12} = 0.0675 > \frac{1}{18}$！

:::

  

#### 经典题型训练（分层模型与递归条件期望）

  

1. **骰子决定抛硬币次数**：先掷公平骰子得点数 $N$（$\mathbb{E}[N]=7/2, \text{Var}(N)=35/12$），再抛 $N$ 枚均匀硬币得正面数 $Y \mid N=n \sim \text{Bin}(n, 1/2)$。

   - 条件量：$\mathbb{E}[Y \mid N] = N/2$，$\text{Var}(Y \mid N) = N/4$；

   - 全期望：$\mathbb{E}[Y] = \mathbb{E}[N/2] = 7/4$；

   - 全方差：$\text{Var}(Y) = \mathbb{E}[N/4] + \text{Var}(N/2) = \frac{7}{8} + \frac{1}{4}\times\frac{35}{12} = \frac{42 + 35}{48} = \frac{77}{48}$。

2. **批次成功率本身随机（Beta-Binomial 边缘化与增广方差）**：每批 10 个任务，批次成功率 $Q \sim \text{Uniform}(0,1)$（$\mathbb{E}[Q]=1/2, \text{Var}(Q)=1/12, \mathbb{E}[Q^2]=1/3$），给定 $Q=q$ 时成功次数 $Y \mid Q=q \sim \text{Binomial}(10, q)$。

   - **边缘分布**：对 $q$ 积分并利用积分公式 $\int_0^1 q^a(1-q)^b\,dq = \frac{a!b!}{(a+b+1)!}$：

     $$

     P(Y = k) = \int_0^1 \binom{10}{k} q^k (1-q)^{10-k}\,dq = \frac{10!}{k!(10-k)!} \frac{k!(10-k)!}{11!} = \frac{1}{11}, \quad k = 0, 1, \dots, 10

     $$

     分布从钟形变成了 $\{0,\dots,10\}$ 上的**离散均匀分布**！

   - **均值与方差**：$\mathbb{E}[Y] = \mathbb{E}[10Q] = 5$；

     $$

     \text{Var}(Y) = \mathbb{E}[10Q(1-Q)] + \text{Var}(10Q) = 10\left(\frac{1}{2} - \frac{1}{3}\right) + 100 \times \frac{1}{12} = \frac{5}{3} + \frac{25}{3} = 10

     $$

     若固定 $q=1/2$，方差仅为 $10\times 0.5\times 0.5 = 2.5$；成功率的不确定性使方差暴增为 **4 倍**！

3. **迷宫里的小老鼠（条件期望建立递归方程）**：三扇门 A（2 分钟直接出迷宫）、B（4 分钟绕回中心）、C（6 分钟绕回中心）。

   - **无记性老鼠**（每次等可能 $1/3$ 选门）：以第一次选的门为条件列全期望方程：

     $$

     \mathbb{E}[T] = \frac{1}{3}\times 2 + \frac{1}{3}(4 + \mathbb{E}[T]) + \frac{1}{3}(6 + \mathbb{E}[T]) = 4 + \frac{2}{3}\mathbb{E}[T] \implies \mathbb{E}[T] = 12\text{ 分钟}

     $$

   - **有记性老鼠**（不重复走已选错门）：可能路径为 A（2分钟，概率 $1/3$）、B$\to$A（$4+2=6$分钟，概率 $\frac{1}{3}\times\frac{1}{2}=\frac{1}{6}$）、C$\to$A（$6+2=8$分钟，概率 $1/6$）、B$\to$C$\to$A（$4+6+2=12$分钟，概率 $1/6$）、C$\to$B$\to$A（12分钟，概率 $1/6$），平均耗时 $\mathbb{E}[T] = \frac{2}{3} + \frac{6+8+12+12}{6} = 7\text{ 分钟}$。

  

### 5.4 多维信息、协方差矩阵与多元正态预测（2.4+）

  

在一张 $n \times d$ 的数据表中，**行与行之间（样本 $\mathbf{X}^{(1)},\dots,\mathbf{X}^{(n)}$）**通常假设 i.i.d.；而**同一行内（特征分量 $X_1,\dots,X_d$）**通常相互关联，由均值向量 $\boldsymbol{\mu} = \mathbb{E}[\mathbf{X}]$ 和**协方差矩阵 $\Sigma$** 刻画：

  

:::important[协方差矩阵 $\Sigma$ 的定义与核心性质]

1. **定义与相关矩阵**：

   $$

   \Sigma = \text{Cov}(\mathbf{X}) = \mathbb{E}\big[(\mathbf{X} - \boldsymbol{\mu})(\mathbf{X} - \boldsymbol{\mu})^\top\big], \qquad \Sigma_{ij} = \text{Cov}(X_i, X_j)

   $$

   对角线 $\Sigma_{ii} = \text{Var}(X_i)$ 是各分量方差，非对角线是协方差。令标准差对角阵 $D = \text{diag}(\text{SD}(X_1),\dots,\text{SD}(X_d))$，则**相关矩阵** $R = D^{-1}\Sigma D^{-1}$（对角线全为 $1$，$R_{ij} = \rho_{X_i,X_j}$）。

2. **对称半正定性（为什么 $\Sigma \succeq 0$？）**：对任意常数向量 $\mathbf{a} \in \mathbb{R}^d$，线性组合 $\mathbf{a}^\top \mathbf{X}$ 的方差非负：

   $$

   \text{Var}(\mathbf{a}^\top \mathbf{X}) = \mathbf{a}^\top \Sigma \mathbf{a} = \sum_{i,j} a_i a_j \Sigma_{ij} \ge 0

   $$

3. **仿射变换律**：$\mathbb{E}[A\mathbf{X} + \mathbf{b}] = A\boldsymbol{\mu} + \mathbf{b}$，$\text{Cov}(A\mathbf{X} + \mathbf{b}) = A\Sigma A^\top$。

4. **奇异性（何时不可逆？）**：若存在非零向量 $\mathbf{a}$ 使 $\mathbf{a}^\top \mathbf{X}$ 几乎处处为常数，则 $\mathbf{a}^\top \Sigma \mathbf{a} = 0$，此时 $\Sigma$ **奇异（不可逆，半正定而非正定）**。

   - **典型例子：多项分布 $\text{Multinomial}(n, \mathbf{p})$**：$n$ 次独立试验落入 $k$ 个类别的计数向量 $\mathbf{N} = (N_1,\dots,N_k)^\top$，PMF 为 $\frac{n!}{n_1!\cdots n_k!}p_1^{n_1}\cdots p_k^{n_k}$。其均值与协方差矩阵为：

     $$

     \mathbb{E}[\mathbf{N}] = n\mathbf{p}, \qquad \text{Cov}(\mathbf{N}) = n\big[\text{diag}(\mathbf{p}) - \mathbf{p}\mathbf{p}^\top\big] \quad (\text{即 } \text{Var}(N_i)=np_i(1-p_i),\ \text{Cov}(N_i,N_j)=-np_ip_j < 0)

     $$

     因总数固定 $\sum_{i=1}^k N_i = n$，取 $\mathbf{a}=(1,\dots,1)^\top$ 有 $\text{Var}(\mathbf{a}^\top \mathbf{N}) = \text{Var}(n) = 0$（矩阵每行元素之和均为 0），故多项分布的协方差矩阵必奇异！

:::

  

#### 多元正态分布与条件正态预测（高斯过程/卡尔曼滤波基石）

  

当 $\Sigma \succ 0$（正定）时，$d$ 维正态分布 $\mathbf{X} \sim N(\boldsymbol{\mu}, \Sigma)$ 的联合密度为：

$$

f(\mathbf{x}) = \frac{1}{(2\pi)^{d/2}\det(\Sigma)^{1/2}} \exp\left\{-\frac{1}{2}(\mathbf{x} - \boldsymbol{\mu})^\top \Sigma^{-1} (\mathbf{x} - \boldsymbol{\mu})\right\}

$$

其等高线 $(\mathbf{x}-\boldsymbol{\mu})^\top \Sigma^{-1}(\mathbf{x}-\boldsymbol{\mu}) = c$ 是一族以 $\boldsymbol{\mu}$ 为中心的椭圆（当 $\rho=0$ 时长短轴与坐标轴对齐；$\rho \neq 0$ 时椭圆倾斜）。

  

:::important[多元正态的四大黄金性质]

1. **线性组合与边缘分布仍是正态**：若 $\mathbf{X} \sim N(\boldsymbol{\mu}, \Sigma)$，则 $\mathbf{a}^\top \mathbf{X} \sim N(\mathbf{a}^\top \boldsymbol{\mu}, \mathbf{a}^\top \Sigma \mathbf{a})$。

2. **联合正态下：不相关 $\iff$ 独立**！

   $$

   (X, Y) \text{ 联合正态} \implies \big(\text{Cov}(X,Y) = 0 \iff X \perp\!\!\!\perp Y\big)

   $$

   *易错警示：必须满足 **(X,Y) 联合正态**！仅知道 $X \sim N(0,1)$ 和 $Y \sim N(0,1)$ 分别正态是不够的。经典反例：令 $S = \pm 1$ 等概率且与 $X \sim N(0,1)$ 独立，取 $Y = SX$，则 $Y \sim N(0,1)$ 且 $\text{Cov}(X,Y)=0$，但 $|Y|=|X|$，且 $X+Y$ 有 $1/2$ 概率等于 $0$（非正态），故 $(X,Y)$ 不是联合正态，也不独立！*

3. **二元正态的条件分布公式（固定 $X=x$ 预测 $Y$）**：

   设 $\begin{pmatrix} X \\ Y \end{pmatrix} \sim N\left(\begin{pmatrix} \mu_X \\ \mu_Y \end{pmatrix}, \begin{pmatrix} \sigma_X^2 & \rho\sigma_X\sigma_Y \\ \rho\sigma_X\sigma_Y & \sigma_Y^2 \end{pmatrix}\right)$，则：

   $$

   Y \mid X = x \sim N\left(\mu_Y + \rho\frac{\sigma_Y}{\sigma_X}(x - \mu_X),\ \sigma_Y^2(1 - \rho^2)\right)

   $$

   - **条件均值关于 $x$ 严格线性**，斜率为 $\rho\frac{\sigma_Y}{\sigma_X}$；

   - **条件方差 $\sigma_Y^2(1-\rho^2)$ 是不依赖 $x$ 的常数**！已知 $X$ 后解释了 $Y$ 原方差的 **$\rho^2$ 比例**，剩余方差占 **$1 - \rho^2$ 比例**。

4. **一般分块条件正态公式**：设 $\begin{pmatrix} \mathbf{X}_a \\ \mathbf{X}_b \end{pmatrix} \sim N\left(\begin{pmatrix} \boldsymbol{\mu}_a \\ \boldsymbol{\mu}_b \end{pmatrix}, \begin{pmatrix} \Sigma_{aa} & \Sigma_{ab} \\ \Sigma_{ba} & \Sigma_{bb} \end{pmatrix}\right)$（$\Sigma_{aa}$ 可逆），则观测到 $\mathbf{X}_a = \mathbf{x}_a$ 后未观测特征 $\mathbf{X}_b$ 的条件分布仍为正态：

   $$

   \mathbb{E}[\mathbf{X}_b \mid \mathbf{X}_a = \mathbf{x}_a] = \boldsymbol{\mu}_b + \Sigma_{ba}\Sigma_{aa}^{-1}(\mathbf{x}_a - \boldsymbol{\mu}_a), \qquad \text{Cov}(\mathbf{X}_b \mid \mathbf{X}_a = \mathbf{x}_a) = \Sigma_{bb} - \Sigma_{ba}\Sigma_{aa}^{-1}\Sigma_{ab}

   $$

:::

  

**课堂练习（机器人传感器读数预测）**：机器人有两个已标准化的传感器读数 $(X,Y)$ 服从联合正态，$\mu_X=\mu_Y=0, \sigma_X=\sigma_Y=1, \rho_{X,Y}=0.8$。当观测到 $X=1$ 时，求 $Y$ 的条件分布、最佳预测值 $\mathbb{E}[Y\mid X=1]$、条件标准差以及被解释的方差比例。

:spoiler[**解析**：直接套用二元正态条件分布公式：$Y \mid X=x \sim N(0.8x, 1 - 0.8^2) = N(0.8x, 0.36)$。

当 $X=1$ 时，最佳预测值 $\mathbb{E}[Y\mid X=1] = 0.8$，条件标准差 $\text{SD}(Y\mid X=1) = \sqrt{0.36} = 0.6$。剩余方差占原方差的 $1-\rho^2 = 36\%$，即条件均值解释了 $Y$ 方差的 $\rho^2 = 64\%$。]

### 6.1 随机变量函数的分布：六大变换场景全解

  

| 变换场景 | 核心方法与公式 | 关键注意事项与经典算例 |

| :--- | :--- | :--- |

| **1. 离散型变换** $Y = r(X)$ | **把所有原像的概率相加**：<br>$P(Y = y) = \sum_{x: r(x) = y} P(X = x)$ | 非一一对应时多个 $x$ 会落到同一个 $y$（如 $Y=X^2$ 时 $x=\pm 1$ 概率相加） |

| **6. i.i.d. 极值（串联/并联）** | **先写 CDF 最省事**：<br>最大值（并联）：$F_{\max}(z) = [F(z)]^n,\ f_{\max}(z)=n[F(z)]^{n-1}f(z)$<br>最小值（串联）：$F_{\min}(z) = 1 - [1-F(z)]^n,\ f_{\min}(z)=n[1-F(z)]^{n-1}f(z)$ | **灯串寿命算例**：10 个灯泡寿命 i.i.d. 服从均值 1000 小时的指数分布（$F(t)=1-e^{-t/1000}$）。<br>① **串联**（坏一个全灭）：$P(T_{\min}>t)=e^{-10t/1000}=e^{-t/100}$，即 $T_{\min}\sim \text{Exp}(\text{均值 } 100\text{h})$，亮过 1000h 概率仅 $e^{-10}\approx 0.00005$；<br>② **并联**（全坏才灭）：$P(T_{\max}>1000) = 1 - (1-e^{-1})^{10} \approx 0.99$！ |

### 6.2 矩、中心矩与统计量的无偏性（为什么样本方差除以 $n-1$？）

  

:::note[定义 2.9：原点矩、中心矩与高阶矩存在性]

- **$k$ 阶原点矩**：$m_k = E[X^k]$（相对 $0$ 的幂次平均，$m_1 = \mu$）；

- **$k$ 阶中心矩**：$c_k = E[(X - \mu)^k]$（相对均值 $\mu$ 的幂次平均，$c_1 = 0$，$c_2 = \text{Var}(X) = m_2 - m_1^2$）。

- **高阶矩作用**：当两个分布均值和方差完全相同时（如仪器 A 取 $\pm 1$ 各 $1/2$；仪器 B 取 $\pm 2$ 各 $1/8$、取 $0$ 为 $3/4$，二者均有 $E=0, \text{Var}=1$），**四阶矩 $E[X^4]$**（$E[A^4]=1 < E[B^4]=4$）能有效区分重尾与大误差风险。

- **高阶矩有限 $\implies$ 低阶矩有限**：由不等式 $|x|^j \le 1 + |x|^k\ (0 < j < k)$，若 $E[|X|^k] < \infty$，则必有 $E[|X|^j] < \infty$。

:::

  

#### 统计量与样本方差除以 $n-1$ 的严格证明

  

设总体均值为 $\mu$、方差为 $\sigma^2 < \infty$，独立同分布抽样 $X_1, \dots, X_n \stackrel{\text{iid}}{\sim} F$。**统计量**是只由样本计算、不含未知参数的随机变量：

- **样本均值**：$\bar{X}_n = \frac{1}{n}\sum_{i=1}^n X_i$，满足 $E[\bar{X}_n] = \mu$，$\text{Var}(\bar{X}_n) = \frac{\sigma^2}{n}$，$\text{SD}(\bar{X}_n) = \frac{\sigma}{\sqrt{n}}$（**标准差减半需要 4 倍样本量！**）。

- **样本方差**：$S_n^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X}_n)^2\ (n \ge 2)$。

  

:::important[必考推导：为什么样本方差 $S_n^2$ 分母除以 $n-1$ 才是无偏估计？]

1. **第一步（分解离差平方和）**：在 $X_i - \mu$ 中插入样本均值 $\bar{X}_n$，展开平方和：

   $$

   \sum_{i=1}^n (X_i - \mu)^2 = \sum_{i=1}^n \big[(X_i - \bar{X}_n) + (\bar{X}_n - \mu)\big]^2 = \sum_{i=1}^n (X_i - \bar{X}_n)^2 + n(\bar{X}_n - \mu)^2

   $$

   *注：交叉项 $2(\bar{X}_n - \mu)\sum_{i=1}^n (X_i - \bar{X}_n) = 0$ 自动消失！*

2. **第二步（移项并两边取期望）**：利用 $E[(X_i - \mu)^2] = \sigma^2$ 以及 $E[(\bar{X}_n - \mu)^2] = \text{Var}(\bar{X}_n) = \frac{\sigma^2}{n}$，得：

   $$

   E\left[\sum_{i=1}^n (X_i - \bar{X}_n)^2\right] = n\sigma^2 - nE\big[(\bar{X}_n - \mu)^2\big] = n\sigma^2 - n \cdot \frac{\sigma^2}{n} = (n - 1)\sigma^2

   $$

3. **第三步（得出结论）**：用样本自身的平均值 $\bar{X}_n$ 代替真实均值 $\mu$ 作中心，会让离差平方和的期望恰好少掉一个 $\sigma^2$。因此：

   $$

   E[S_n^2] = E\left[\frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X}_n)^2\right] = \sigma^2 \quad (\text{无偏}), \qquad E\left[\frac{1}{n}\sum_{i=1}^n (X_i - \bar{X}_n)^2\right] = \frac{n-1}{n}\sigma^2 \quad (\text{偏小})

   $$

- **思考题**：已知 $E[S_n^2] = \sigma^2$，是否必有 $E[S_n] = \sigma$？

  :spoiler[**答案**：**不是！** 因为开平方是非线性（严格凹）函数，由 $\text{Var}(S_n) = E[S_n^2] - (E[S_n])^2 \ge 0$（或 Jensen 不等式）可知 $E[S_n] \le \sqrt{E[S_n^2]} = \sigma$，即样本标准差 $S_n$ 通常是 $\sigma$ 的有偏（偏小）估计。]

:::

  

### 6.3 矩母函数（MGF）：求矩与识别分布的代数利器

  

:::important[定义 2.10 & 核心定理：矩母函数（Moment Generating Function, MGF）]

1. **定义与存在条件**：$M_X(t) = E[e^{tX}]$。

   - **存在性要求**：必须存在 $\delta > 0$，使得对 **$0$ 的某个双侧开邻域 $|t| < \delta$** 内所有 $t$ 都有 $M_X(t) < \infty$（注意：$M_X(0) = E[1] = 1$ 恒成立，只看 $t=0$ 一点有限不算 MGF 存在！）。

2. **求导生矩性质**：若 $M_X(t)$ 在 $0$ 的开邻域内有限，则 $X$ 的**所有阶绝对矩均有限**，且在 $t=0$ 处求 $k$ 阶导数即可把 $X^k$ 从指数上“拿下来”：

   $$

   M_X^{(k)}(t) = E[X^k e^{tX}] \implies E[X^k] = M_X^{(k)}(0), \qquad E[X] = M_X'(0), \quad \text{Var}(X) = M_X''(0) - [M_X'(0)]^2

   $$

3. **仿射变换与独立和相乘性质**（把繁琐的卷积积分变成代数乘法！）：

   - **仿射变换**：$M_{aX+b}(t) = E[e^{t(aX+b)}] = e^{bt}M_X(at)$；

   - **独立和**：若 $X_1, \dots, X_n$ **相互独立**，则：

     $$

     M_{X_1 + \cdots + X_n}(t) = \prod_{i=1}^n M_{X_i}(t)

     $$

4. **MGF 唯一性定理**：若 $M_X(t)$ 与 $M_Y(t)$ 在**同一个 $0$ 的开邻域 $|t| < \delta$ 内有限且处处相等**，则 $X$ 与 $Y$ 必同分布（$X \stackrel{d}{=} Y$）。

:::

  

| 分布名称与记号 | 矩母函数 $M_X(t) = E[e^{tX}]$ | 有限范围 | 利用 MGF 唯一性定理秒推的可加性结论 |

| :--- | :--- | :--- | :--- |

| $\text{Bernoulli}(p)$ | $1 - p + pe^t$ | $t \in \mathbb{R}$ | $n$ 个 i.i.d. 相乘得 $(1-p+pe^t)^n \implies \text{Binomial}(n,p)$ |

| $\text{Binomial}(n, p)$ | $(1 - p + pe^t)^n$ | $t \in \mathbb{R}$ | 同参数 $p$ 独立相加：$M_{X+Y}(t) = (1-p+pe^t)^{n_1+n_2} \sim \text{Bin}(n_1+n_2, p)$ |

| $\text{Poisson}(\lambda)$ | $\exp\big\{\lambda(e^t - 1)\big\}$ | $t \in \mathbb{R}$ | 独立相加：$e^{\lambda_1(e^t-1)}e^{\lambda_2(e^t-1)} = e^{(\lambda_1+\lambda_2)(e^t-1)} \sim \text{Poisson}(\lambda_1+\lambda_2)$ |

| $\text{Normal}(\mu, \sigma^2)$ | $\exp\left(\mu t + \frac{\sigma^2 t^2}{2}\right)$ | $t \in \mathbb{R}$ | 标准正态 $M_Z(t)=e^{t^2/2}=1+\frac{t^2}{2}+\frac{t^4}{8}+\cdots \implies E[Z^2]=1, E[Z^4]=3$ |

| $\text{Exp}(\lambda)$（率参数 $\lambda$） | $\frac{\lambda}{\lambda - t} = \left(1 - \frac{t}{\lambda}\right)^{-1}$ | $t < \lambda$ | 两个独立 $\text{Exp}(\lambda)$ 相加：$M_T(t) = (1 - t/\lambda)^{-2} \sim \text{Gamma}(\alpha=2, \beta=1/\lambda)$ |

| $\text{Gamma}(\alpha, \beta)$（尺度 $\beta$） | $(1 - \beta t)^{-\alpha}$ | $t < \frac{1}{\beta}$ | 同尺度 $\beta$ 独立相加：$\prod (1-\beta t)^{-\alpha_i} = (1-\beta t)^{-\sum \alpha_i} \sim \text{Gamma}(\sum \alpha_i, \beta)$ |

| $\chi^2_k$ | $(1 - 2t)^{-k/2}$ | $t < \frac{1}{2}$ | 恰为 $\text{Gamma}(\alpha=k/2, \beta=2)$；独立卡方相加 $\chi^2_{k_1} + \chi^2_{k_2} \sim \chi^2_{k_1+k_2}$ |

  

:::caution[压轴高阶辨析：所有阶矩都存在，MGF 也一定存在吗？]

**不一定！“所有阶矩有限”推不出“MGF 在 0 的邻域内有限”。**

- **经典反例：对数正态分布（Log-normal）**：设 $Z \sim N(0,1)$，令 $X = e^Z$。

  - **每一阶矩都有限**：对任意正整数 $k$，$E[X^k] = E[e^{kZ}] = M_Z(k) = e^{k^2/2} < \infty$；

  - **但 MGF 在 $0$ 的开邻域内不存在**：对任意 $t > 0$，

    $$

    M_X(t) = E[e^{tX}] = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty} \exp\left(te^z - \frac{z^2}{2}\right)\,dz = \infty

    $$

    因为当 $z \to +\infty$ 时，指数项 $te^z$ 的增长速度远超 $-z^2/2$，导致右尾积分发散！因此唯一性定理不能随意简化为“任何分布都由全部矩唯一确定”。

:::

  

**课堂练习（MGF 与四阶矩识别分布）**：设备等概率处于两种状态：$B$ 以各 $1/2$ 概率取 $-1, 1$；$Z \sim N(0,1)$ 且与 $B$ 独立。总误差 $W = B + Z$。求 $M_W(t)$、均值和方差，并判断 $W$ 是否服从正态分布。

:spoiler[**解析**：

1. $M_B(t) = \frac{1}{2}e^{-t} + \frac{1}{2}e^t = \cosh(t)$，$M_Z(t) = e^{t^2/2}$。由独立性：

   $$

   M_W(t) = M_B(t)M_Z(t) = \frac{e^{-t} + e^t}{2} e^{t^2/2}

   $$

2. 均值与方差：$E[W] = E[B] + E[Z] = 0 + 0 = 0$；$\text{Var}(W) = \text{Var}(B) + \text{Var}(Z) = 1 + 1 = 2$。

3. **判断是否为正态**：若 $W$ 服从正态分布，则必为 $V \sim N(0, 2)$，其四阶矩应为 $E[V^4] = 3\sigma^4 = 3 \times 2^2 = 12$（或看 MGF 应为 $e^{t^2}$）。但实际展开四阶矩（奇数次交叉项因对称与独立期望为 0）：

   $$

   E[W^4] = E[(B+Z)^4] = E[B^4] + 6E[B^2]E[Z^2] + E[Z^4] = 1 + 6(1)(1) + 3 = 10 \neq 12

   $$

   因此 **$W$ 不服从正态分布**！]

  

## 7. Python 仿真验证：Monty Hall、Cauchy 均值发散与二元正态预测

  

下面的脚本使用 NumPy 对本笔记中的三个核心反直觉结论进行快速蒙特卡洛验证：

  

```python title="prob_stat_simulations.py" {9-12,18-21,28-31}

import numpy as np

  

rng = np.random.default_rng(2026)

N = 100_000

  

# 1. Monty Hall 三门问题：验证坚持 vs 换门胜率

prize = rng.integers(0, 3, size=N)

choice = np.zeros(N, dtype=int)  # 固定先选 0 号门

stay_win = np.mean(prize == choice)

switch_win = np.mean(prize != choice)  # 只要奖品不在 0 号门，换门必赢

print(f"[Monty Hall] 坚持胜率: {stay_win:.4f} (理论 0.3333) | 换门胜率: {switch_win:.4f} (理论 0.6667)")

  

# 2. 正态分布 vs Cauchy 分布：验证样本均值是否收敛

normal_samples = rng.standard_normal((4, N))

cauchy_samples = rng.standard_cauchy((4, N))

print("[Sample Mean @ N=100k] N(0,1) 四条轨迹均值:", np.round(normal_samples.mean(axis=1), 4))

print("[Sample Mean @ N=100k] Cauchy 四条轨迹均值:", np.round(cauchy_samples.mean(axis=1), 2))

  

# 3. 二元正态条件分布：验证观测到 X=1 时 Y 的条件均值与剩余方差

cov_mat = [[1.0, 0.8], [0.8, 1.0]]

xy = rng.multivariate_normal([0.0, 0.0], cov_mat, size=N * 5)

mask = np.abs(xy[:, 0] - 1.0) < 0.02  # 取 X=1 附近的窄带切片

y_given_x1 = xy[mask, 1]

print(f"[Bivariate Normal] E[Y|X=1]: {y_given_x1.mean():.4f} (理论 0.8) | Var(Y|X=1): {y_given_x1.var():.4f} (理论 0.36)")

```
