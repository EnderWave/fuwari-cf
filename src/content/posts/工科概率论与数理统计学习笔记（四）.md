## 一、参数估计：矩估计（MOM）与极大似然估计（MLE）（4.1 节）

### 1.1 参数统计模型与三个概念

* **概率 vs. 统计**：

  * **概率论（参数** $\to$ **数据规律）**：已知总体分布与参数（如 $X \sim N(5, 2^2)$），计算事件发生的概率（如 $P(X \le 7) = \Phi(1)$）；

  * **数理统计（数据** $\to$ **参数取值）**：已知观测样本 $X_1, \dots, X_n \stackrel{\text{iid}}{\sim} N(\mu, \sigma^2)$ 的具体读数 $x_1, \dots, x_n$，反推未知参数 $\mu, \sigma^2$ 是多少。

* **参数统计模型定义**：设总体分布族为 $\mathcal{P} = \{P_\theta : \theta \in \Theta\}$，样本 $X_1, \dots, X_n \stackrel{\text{iid}}{\sim} P_\theta$，其中 $\theta$ 是**未知但固定**的参数，$\Theta$ 是参数空间（允许 $\theta$ 取值的范围）。

| 概念 | 数学记号 | 本质属性 | 正态均值算例（$X_1, \dots, X_n \stackrel{\text{iid}}{\sim} N(\mu, 1)$） |
| ----- | ----- | ----- | ----- |
| **参数（Parameter）** | $\theta$ | **固定的未知常数**（不随抽样改变） | 总体真实均值 $\mu$ |
| **估计量（Estimator）** | $\hat{\theta} = g(X_1, \dots, X_n)$ | **随机变量**（只依赖样本 $X_i$、绝不能含未知参数；随重抽样改变） | $\bar{X}$ 和 $\bar{X} + 1$ 都是估计量（但优劣不同） |
| **估计值（Estimate）** | $g(x_1, \dots, x_n)$ | **确定的数值**（将本次观测数据代入估计量算出的一个数） | 本次算出的样本均值具体数值 $\bar{x} = 5.0$ |

### 1.2 矩估计法（Method of Moments, MOM）

1. **核心思想（从大数定律出发）**：

   由辛钦大数定律，样本一阶矩依概率收敛于总体理论均值：$\bar{X}_n \xrightarrow{P} E_\theta[X] = m_1(\theta)$。因此用**样本矩代替理论矩**，联立方程反解出参数！

2. **一般定义与三步标准流程**：

   记总体 $j$ 阶理论原点矩为 $m_j(\theta) = E_\theta[X^j]$，样本 $j$ 阶原点矩为 $\hat{m}_j = \frac{1}{n}\sum_{i=1}^n X_i^j$。当未知参数有 $k$ 个分量 $\theta = (\theta_1, \dots, \theta_k)$ 时：

   * **第 1 步（写理论矩）**：用未知参数 $\theta$ 表出前 $k$ 阶理论矩 $m_1(\theta) = E_\theta[X],\, m_2(\theta) = E_\theta[X^2], \dots$；

   * **第 2 步（令其等于样本矩）**：建立 $k$ 个矩估计方程 $m_j(\hat{\theta}) = \hat{m}_j\ (j = 1, \dots, k)$；

   * **第 3 步（解方程并代数据）**：反解出矩估计量 $\hat{\theta}$，再代入具体观测值 $x_1, \dots, x_n$ 得到矩估计值。

#### 五大常考分布的矩估计汇总表（Slides 10–15）

| 总体模型 $P_\theta$ | 理论矩表达式 | 矩估计量 $\hat{\theta}_{\text{MoM}}$ | 课件典型算例与数值结果 |
| ----- | ----- | ----- | ----- |
| **泊松分布** $\text{Poisson}(\lambda)$ | $E_\lambda[X] = \lambda$ | $\hat{\lambda} = \bar{X}$ | 5 分钟来电数 $3,7,4,6,5 \implies \hat{\lambda} = \bar{x} = 5$ |
| **指数分布** $\text{Exp}(\lambda)$**（率参数）** | $E_\lambda[X] = \frac{1}{\lambda}$ | $\hat{\lambda} = \frac{1}{\bar{X}}$ | 4 只元件寿命 $0.6, 1.4, 0.8, 1.2 \implies \bar{x}=1 \implies \hat{\lambda} = 1$ |
| **几何分布** $\text{Geom}(p)$ | $E_p[X] = \frac{1}{p}$ | $\hat{p} = \frac{1}{\bar{X}}$ | 5 轮首次命中次数 $1,2,1,3,1 \implies \bar{x}=\frac{8}{5} \implies \hat{p} = \frac{5}{8} = 0.625$ |
| **均匀分布** $U(0, \theta)$ | $E_\theta[X] = \frac{\theta}{2}$ | $\hat{\theta} = 2\bar{X}$ | 3 次公交等车时间 $2,5,8 \implies \bar{x}=5 \implies \hat{\theta} = 10$ |
| **正态分布** $N(\mu, \sigma^2)$ | $E[X] = \mu$, $E[X^2] = \mu^2 + \sigma^2$ | $\hat{\mu} = \bar{X}$, $\hat{\sigma}^2 = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2$ | 5 个零件直径 $9.9, 10.0, 10.1, 10.2, 9.8 \implies \hat{\mu}=10.0,\ \hat{\sigma}^2=0.02$ |

*（注：双参数正态矩估计中，由* $\hat{\mu}^2 + \hat{\sigma}^2 = \frac{1}{n}\sum_{i=1}^n X_i^2$ *解得* $\hat{\sigma}^2 = \frac{1}{n}\sum_{i=1}^n X_i^2 - \bar{X}^2 = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2$*，分母为* $n$ *而非* $n-1$*。）*

### 1.3 极大似然估计（Maximum Likelihood Estimation, MLE）

1. **似然函数定义（Slides 16–20）**：

   设 $X_1, \dots, X_n \stackrel{\text{iid}}{\sim} f(x; \theta)\ (\theta \in \Theta)$，已观测到样本数据 $x = (x_1, \dots, x_n)$。因为样本相互独立，联合质量/密度函数为各分量乘积。**固定观测数据** $x$**，将联合分布看成候选参数** $\theta$ **的函数**，称为**似然函数（Likelihood Function）**：

   $$

   L(\theta) = L(\theta; x) = \prod_{i=1}^n f(x_i; \theta), \qquad \hat{\theta}_{\text{MLE}} \in \arg\max_{\theta \in \Theta} L(\theta; x)

   $$

:::caution[三个极易混淆的概念雷区]
2. **似然函数不是参数的概率分布**：例如抛 10 次硬币出现 8 正 2 反，$L(0.8) = \binom{10}{8}(0.8)^8(0.2)^2 \approx 0.302$ 表示“**若** $p=0.8$**，观测到 8 正 2 反的概率为 0.302**”，绝不是“$p=0.8$ 为真的概率是 0.302”！$L(p)$ 只是给每个候选参数 $p$ 打分，对 $p$ 积分并不等于 $1$。

3. **连续型似然是联合密度而非概率**：当 $X_i$ 为连续型随机变量时，$L(\theta)$ 是联合概率密度，单个点概率恒为 $0$。

4. $\arg\max$ **返回的是横轴参数位置而非纵轴峰值**：上例中峰值高度 $0.302$ 是最大似然值，而横轴坐标 $\hat{p}_{\text{MLE}} = 0.8$ 才是极大似然估计！

:::

5. **求解 MLE 的标准四步法（Slides 21–22）**：

   * **第 1 步（写似然）**：写出 $L(\theta) = \prod_{i=1}^n f(x_i; \theta)$，并明确参数空间 $\Theta$ 及支撑集约束；

   * **第 2 步（取对数）**：在 $L(\theta) > 0$ 处计算对数似然函数 $\ell(\theta) \triangleq \ln L(\theta) = \sum_{i=1}^n \ln f(x_i; \theta)$（因为 $\ln$ 严格单调递增，不改变极大值点位置，且把连乘变成求和以便求导）；

   * **第 3 步（求驻点）**：解似然方程 $\ell'(\theta) = 0$（多参数时令各偏导数 $\frac{\partial \ell}{\partial \theta_j} = 0$）；

   * **第 4 步（验二阶与查边界）**：验证二阶导数 $\ell''(\theta) < 0$（凹函数唯一内部极大点），并核查参数空间边界情形（或当 $L(\theta)$ 单调时直接取边界端点，如 $U(0, \theta)$）。

#### 四大经典模型的 MLE 完整推导（Slides 23–27）

1. **Bernoulli 次品率模型** $X_i \stackrel{\text{iid}}{\sim} \text{Bernoulli}(p),\ p \in [0, 1]$：

   记 $k = \sum_{i=1}^n x_i$ 为次品总数。当 $0 < k < n$ 时：

   * 似然与对数似然：$L(p) = p^k(1 - p)^{n-k} \implies \ell(p) = k\ln p + (n - k)\ln(1 - p)$；

   * 一阶与二阶导数：$\ell'(p) = \frac{k}{p} - \frac{n - k}{1 - p} = 0 \implies \hat{p} = \frac{k}{n}$；且 $\ell''(p) = -\frac{k}{p^2} - \frac{n-k}{(1-p)^2} < 0$；

   * 边界核查：当 $k = 0$ 时 $L(p) = (1-p)^n$ 在 $[0, 1]$ 上严格递减，最大点为 $\hat{p} = 0 = \frac{0}{n}$；当 $k = n$ 时 $L(p) = p^n$ 严格递增，最大点为 $\hat{p} = 1 = \frac{n}{n}$。故对一切 $k \in \{0, \dots, n\}$，恒有 $\hat{p}_{\text{MLE}} = \frac{k}{n} = \bar{X}$。

2. **Poisson 来电率模型** $X_i \stackrel{\text{iid}}{\sim} \text{Poisson}(\lambda),\ \lambda > 0$：

   $$

   L(\lambda) = \prod_{i=1}^n \frac{e^{-\lambda} \lambda^{x_i}}{x_i!} \implies \ell(\lambda) = -n\lambda + \left(\sum_{i=1}^n x_i\right)\ln\lambda - \sum_{i=1}^n \ln(x_i!)

   $$

   求导令 $\ell'(\lambda) = -n + \frac{\sum_{i=1}^n x_i}{\lambda} = 0 \implies \mathbf{\hat{\lambda}_{\text{MLE}} = \bar{X}}$（且 $\ell''(\lambda) = -\frac{\sum x_i}{\lambda^2} < 0$）。

3. **指数寿命模型** $X_i \stackrel{\text{iid}}{\sim} \text{Exp}(\lambda),\ \lambda > 0$：

   $$

   L(\lambda) = \prod_{i=1}^n \lambda e^{-\lambda x_i} = \lambda^n e^{-\lambda \sum_{i=1}^n x_i} \implies \ell(\lambda) = n\ln\lambda - \lambda\sum_{i=1}^n x_i

   $$

   求导令 $\ell'(\lambda) = \frac{n}{\lambda} - \sum_{i=1}^n x_i = 0 \implies \mathbf{\hat{\lambda}_{\text{MLE}} = \frac{n}{\sum_{i=1}^n X_i} = \frac{1}{\bar{X}}}$（且 $\ell''(\lambda) = -\frac{n}{\lambda^2} < 0$）。

4. **双参数正态模型** $X_i \stackrel{\text{iid}}{\sim} N(\mu, \sigma^2),\ \mu \in \mathbb{R},\ v = \sigma^2 > 0$：

   对数似然函数为：

   $$

   \ell(\mu, v) = -\frac{n}{2}\ln(2\pi) - \frac{n}{2}\ln v - \frac{1}{2v}\sum_{i=1}^n (x_i - \mu)^2

   $$

   分别对 $\mu$ 和 $v = \sigma^2$ 求偏导：

   $$

   \begin{cases} \frac{\partial \ell}{\partial \mu} = \frac{1}{v}\sum_{i=1}^n (x_i - \mu) = 0 \implies \mathbf{\hat{\mu}_{\text{MLE}} = \bar{x}} \\ \frac{\partial \ell}{\partial v} = -\frac{n}{2v} + \frac{1}{2v^2}\sum_{i=1}^n (x_i - \bar{x})^2 = 0 \implies \mathbf{\hat{v}_{\text{MLE}} = \hat{\sigma}_{\text{MLE}}^2 = \frac{1}{n}\sum_{i=1}^n (x_i - \bar{x})^2} \end{cases}

   $$

### 1.4 分组 Logistic 分类回归与三类统计建模范式（Slides 29–34）

1. **两组 Logistic 回归的参数估计**：

   设 $Y_i \in \{0, 1\}$ 为垃圾邮件标签，$X_i \in \{0, 1\}$ 表示是否含可疑提示词。给定 $X_i = x$ 时 $Y_i \sim \text{Bernoulli}(p(x))$，其中：

   $$

   p(x) = P(Y = 1 \mid X = x) = \sigma(\beta_0 + \beta_1 x), \qquad \sigma(t) = \frac{e^t}{1 + e^t} \iff \text{logit}(p) \triangleq \ln\frac{p}{1 - p} = \beta_0 + \beta_1 x

   $$

   记 $X=0$ 组有 $n_0$ 封邮件、其中 $k_0$ 封垃圾邮件（样本比例 $\hat{p}_0 = \bar{Y}_0 = \frac{k_0}{n_0}$）；$X=1$ 组有 $n_1$ 封邮件、其中 $k_1$ 封垃圾邮件（样本比例 $\hat{p}_1 = \bar{Y}_1 = \frac{k_1}{n_1}$）。

   * **分组条件矩估计（Slide 30）**：令分组条件理论均值等于组内样本比例：

     $$

     \begin{cases} E[Y \mid X=0] = p_0 = \sigma(\beta_0) = \hat{p}_0 \\ E[Y \mid X=1] = p_1 = \sigma(\beta_0 + \beta_1) = \hat{p}_1 \end{cases} \implies \begin{cases} \hat{\beta}_0 = \text{logit}(\hat{p}_0) \\ \hat{\beta}_1 = \text{logit}(\hat{p}_1) - \text{logit}(\hat{p}_0) = \ln\frac{\hat{p}_1/(1-\hat{p}_1)}{\hat{p}_0/(1-\hat{p}_0)} \end{cases}

     $$

   * **极大似然估计（Slides 31–32）**：因为映射 $(\beta_0, \beta_1) \mapsto (p_0, p_1)$ 是 $\mathbb{R}^2 \to (0, 1)^2$ 的**双射（一一对应）**，直接对对数似然 $\ell(p_0, p_1) = k_0 \ln p_0 + (n_0 - k_0)\ln(1 - p_0) + k_1 \ln p_1 + (n_1 - k_1)\ln(1 - p_1)$ 求偏导得 $\hat{p}_{0,\text{MLE}} = \frac{k_0}{n_0},\ \hat{p}_{1,\text{MLE}} = \frac{k_1}{n_1}$，回代即得与分组矩估计完全相同的 $\hat{\beta}_{0,\text{MLE}}, \hat{\beta}_{1,\text{MLE}}$！（如课件数据 $n_0=4, k_0=1 \implies \hat{p}_0=1/4$；$n_1=4, k_1=3 \implies \hat{p}_1=3/4$，解得 $\hat{\beta}_0 = -\ln 3,\ \hat{\beta}_1 = 2\ln 3$。）

2. **线性 Logistic 的单调性限制与参数/半参数/非参数建模对比（Slides 33–34）**：

   * 因 $\sigma'(t) = \sigma(t)(1 - \sigma(t)) > 0$，线性模型 $x \mapsto \sigma(\beta_0 + \beta_1 x)$ 只能严格单调递增（$\beta_1 > 0$）、严格单调递减（$\beta_1 < 0$）或为常数（$\beta_1 = 0$），无法拟合“先升后降”的非单调规律；若加入二次项 $\sigma(\beta_0 + \beta_1 x + \beta_2 x^2)$，则仍属于三维**参数模型**且能表达非单调关系。

   * **三类建模范式权衡**：

     1. **参数模型** $\sigma(\beta_0 + \beta_1 x + \beta_2 z)\ (\beta \in \mathbb{R}^3)$：函数形状完全由有限维参数决定，易估计、易解释，但模型设定错误会产生系统偏差；

     2. **半参数模型** $\sigma(\beta_0 + \beta_1 x + g(z))$（有限维目标参数 $\beta$ + 无限维未知干扰函数 $g$）：兼顾核心变量的可解释性与协变量的灵活性；

     3. **非参数模型** $h(x, z) \in [0, 1]$：对函数形状不设限，最灵活，但需要大得多的数据量。

## 二、估计量的评价：误差、相合性与渐近分布（4.2 节）

### 2.1 偏差（Bias）、标准误（SE）与均方误差分解（MSE，Theorem 6.9）

评价一个估计量 $T_n = T_n(X_1, \dots, X_n)$ 的好坏，绝不能看某一次样本算出的数字碰巧离真值有多近，而要看**在重复抽样下，估计量** $T_n$ **的抽样分布**！

1. **评价指标定义（Slides 38–40）**：

   * **偏差（Bias，衡量抽样分布中心是否瞄准真值）**：

     $$

     \text{Bias}_\theta(T_n) \triangleq E_\theta[T_n] - \theta

     $$

     若对所有 $\theta \in \Theta$ 均有 $\text{Bias}_\theta(T_n) = 0$（即 $E_\theta[T_n] = \theta$），则称 $T_n$ 为 $\theta$ 的**无偏估计量（Unbiased Estimator）**。

   * **标准误（Standard Error, SE，衡量估计量在重复抽样中的波动大小）**：

     $$

     \text{SE}_\theta(T_n) \triangleq \sqrt{\text{Var}_\theta(T_n)}

     $$

     *（注意区分：*$\text{SE}_\theta(T_n)$ *常含未知参数* $\theta$*，是理论量；将估计值* $\hat{\theta}$ *代入得到的* $\widehat{\text{SE}}$ *才是数据算出的**估计标准误**！）*

   * **均方误差（Mean Squared Error, MSE）与均方根误差（RMSE）**：

     $$

     \text{MSE}_\theta(T_n) \triangleq E_\theta\big[(T_n - \theta)^2\big], \qquad \text{RMSE}_\theta(T_n) \triangleq \sqrt{\text{MSE}_\theta(T_n)}

     $$

:::important[Theorem 6.9（MSE 偏差-方差分解定理，Slide 40）]
记 $m_n = E_\theta[T_n]$，则对任意平方可积估计量 $T_n$，恒有：

$$

\text{MSE}_\theta(T_n) = \text{Var}_\theta(T_n) + \big(\text{Bias}_\theta(T_n)\big)^2 = \text{SE}_\theta(T_n)^2 + \text{Bias}_\theta(T_n)^2

$$

:::

**证明（利用中心化交叉项为零）**：

将误差拆分为“随机波动项”与“系统偏差常数项”：$T_n - \theta = (T_n - m_n) + (m_n - \theta)$。平方后取期望：

$$

\begin{aligned} E_\theta\big[(T_n - \theta)^2\big] &= E_\theta\big[(T_n - m_n)^2\big] + 2(m_n - \theta) E_\theta[T_n - m_n] + (m_n - \theta)^2 \\ &= \text{Var}_\theta(T_n) + 0 + \big(\text{Bias}_\theta(T_n)\big)^2 \quad (\text{因 } E_\theta[T_n - m_n] = m_n - m_n = 0) \quad \blacksquare \end{aligned}

$$

### 2.2 例题对比：均匀分布 $U(0, \theta)$ 三种估计量的 MSE 与有偏收缩（Slides 41–48）

设 $X_1, \dots, X_n \stackrel{\text{iid}}{\sim} U(0, \theta)\ (\theta > 0)$，已知单个样本 $E_\theta[X_1] = \frac{\theta}{2},\ \text{Var}_\theta(X_1) = \frac{\theta^2}{12}$。对比以下三个估计量：

1. **矩估计量** $T_n = 2\bar{X}_n$：

   * $E_\theta[2\bar{X}_n] = 2 \cdot \frac{\theta}{2} = \theta \implies \text{Bias}_\theta(2\bar{X}_n) = 0$（无偏）；

   * $\text{Var}_\theta(2\bar{X}_n) = 4 \cdot \frac{\text{Var}_\theta(X_1)}{n} = \frac{\theta^2}{3n} \implies \mathbf{\text{MSE}_\theta(2\bar{X}_n) = \frac{\theta^2}{3n} = O(n^{-1})}$。

2. **极大似然估计量** $M_n = \max_{1 \le i \le n} X_i$**（完整五步推导，Slides 43–44）**：

   * **分布函数**：事件 $\{M_n \le m\} = \bigcap_{i=1}^n \{X_i \le m\}$，由独立同分布得 $F_{M_n}(m) = \left(\frac{m}{\theta}\right)^n\ (0 \le m \le \theta)$；

   * **概率密度**：求导得 $f_{M_n}(m) = \frac{n m^{n-1}}{\theta^n}\ (0 < m < \theta)$；

   * **一阶矩与二阶矩**：

     $$

     E_\theta[M_n] = \int_0^\theta m \frac{n m^{n-1}}{\theta^n} dm = \frac{n}{n+1}\theta, \qquad E_\theta[M_n^2] = \int_0^\theta m^2 \frac{n m^{n-1}}{\theta^n} dm = \frac{n}{n+2}\theta^2

     $$

   * **Bias、Var 与 MSE**：

     $$

     \text{Bias}_\theta(M_n) = \frac{n}{n+1}\theta - \theta = -\frac{\theta}{n+1}, \qquad \text{Var}_\theta(M_n) = \frac{n}{n+2}\theta^2 - \left(\frac{n}{n+1}\theta\right)^2 = \frac{n\theta^2}{(n+1)^2(n+2)}

     $$

     $$

     \mathbf{\text{MSE}_\theta(M_n)} = \frac{n\theta^2}{(n+1)^2(n+2)} + \frac{\theta^2}{(n+1)^2} = \mathbf{\frac{2\theta^2}{(n+1)(n+2)} = O(n^{-2})}

     $$

   * **与矩估计对比**：$\text{MSE}_\theta(2\bar{X}_n) - \text{MSE}_\theta(M_n) = \frac{\theta^2(n-1)(n-2)}{3n(n+1)(n+2)}$。当 $n \ge 3$ 时，**有偏估计** $M_n$ **的 MSE 严格更小**（因为它的方差是 $O(n^{-2})$ 量级，远小于 $2\bar{X}_n$ 的 $O(n^{-1})$！）。

3. **无偏修正估计量** $\tilde{\theta}_n = \frac{n+1}{n} M_n$**（Slide 45）**：

   * $E_\theta[\tilde{\theta}_n] = \frac{n+1}{n} \cdot \frac{n}{n+1}\theta = \theta \implies \text{Bias}_\theta(\tilde{\theta}_n) = 0$（消除了系统偏差）；

   * $\mathbf{\text{MSE}_\theta(\tilde{\theta}_n)} = \text{Var}_\theta(\tilde{\theta}_n) = \left(\frac{n+1}{n}\right)^2 \frac{n\theta^2}{(n+1)^2(n+2)} = \mathbf{\frac{\theta^2}{n(n+2)}}$。当 $n > 1$ 时，$\frac{\theta^2}{n(n+2)} < \frac{2\theta^2}{(n+1)(n+2)}$，比 $M_n$ 和 $2\bar{X}_n$ 都更小！

4. **正态均值的有偏收缩权衡（Slides 46–48）**：

   设 $X_1, \dots, X_4 \stackrel{\text{iid}}{\sim} N(\mu, 1)$，对比无偏估计 $T_1 = \bar{X}$（$\text{MSE}_\mu(T_1) = \frac{1}{4} = 0.25$）与有偏收缩估计 $T_2 = \frac{4}{5}\bar{X}$（$\text{Bias}_\mu(T_2) = -\frac{1}{5}\mu,\ \text{Var}_\mu(T_2) = \frac{4}{25},\ \text{MSE}_\mu(T_2) = \frac{\mu^2 + 4}{25}$）。

   解 $\frac{\mu^2 + 4}{25} < \frac{1}{4} \iff \mathbf{|\mu| < \frac{3}{2}}$：当真实 $|\mu| < 1.5$ 时，收缩降低的方差超过引入的偏差平方，净收益为正；反之当 $|\mu| > 1.5$ 时不划算。

### 2.3 相合性（Consistency）、渐近正态性与非正态极限（Slides 49–67）

1. **相合性的定义与充分条件（Theorem 6.10，Slides 49–52）**：

   * **定义**：若对固定的 $\theta$，当 $n \to \infty$ 时估计量序列依概率收敛于真值：

     $$

     T_n \xrightarrow{P} \theta \iff \forall \varepsilon > 0, \quad \lim_{n \to \infty} P_\theta(|T_n - \theta| > \varepsilon) = 0

     $$

     则称 $\{T_n\}$ 是 $\theta$ 的**相合估计量（Consistent Estimator）**。

   * **Theorem 6.10（MSE 判据）**：若 $\text{Bias}_\theta(T_n) \to 0$ 且 $\text{SE}_\theta(T_n) \to 0$（即 $\text{MSE}_\theta(T_n) \to 0$），对非负随机变量 $(T_n - \theta)^2$ 应用 Markov 不等式：

     $$

     P_\theta(|T_n - \theta| > \varepsilon) = P_\theta\big((T_n - \theta)^2 > \varepsilon^2\big) \le \frac{E_\theta[(T_n - \theta)^2]}{\varepsilon^2} = \frac{\text{MSE}_\theta(T_n)}{\varepsilon^2} \to 0 \implies T_n \xrightarrow{P} \theta

     $$

     *（这是相合的**充分但不必要**条件。典型应用：正态方差 MLE* $\hat{v}_n = \frac{1}{n}\sum (X_i - \bar{X})^2$ *满足* $\text{Bias}_v(\hat{v}_n) = -\frac{v}{n} \to 0$ *且* $\text{Var}_v(\hat{v}_n) = \frac{2(n-1)}{n^2}v^2 \to 0$*，故**虽然对每个有限*** $n$ ***有偏，但当*** $n \to \infty$ ***时仍然相合**！）*

2. **渐近正态性与 Slutsky 替换（Slide 56）**：

   若存在渐近方差 $0 < V(\theta) < \infty$ 使得 $\sqrt{n}(T_n - \theta) \xrightarrow{d} N(0, V(\theta))$，则称 $T_n$ 具有**渐近正态性**。若进一步有相合方差估计 $\hat{V}_n \xrightarrow{P} V(\theta) > 0$，由 **Slutsky 定理** 可将未知的 $V(\theta)$ 替换为可由数据计算的统计量：

   $$

   \frac{\sqrt{n}(T_n - \theta)}{\sqrt{\hat{V}_n}} \xrightarrow{d} N(0, 1)

   $$

3. **四个极具代表性的极限分布案例对比（Slides 57–67）**：

| 估计量与统计模型 | 相合性证明依据 | 误差收敛尺度 $a_n$ | 归一化后的非退化极限分布 | 说明 |
| ----- | ----- | ----- | ----- | ----- |
| $2\bar{X}_n$（$X_i \stackrel{\text{iid}}{\sim} U(0, \theta)$） | 大数定律（LLN） | $\sqrt{n}$ | $\sqrt{n}(2\bar{X}_n - \theta) \xrightarrow{d} N\left(0, \frac{\theta^2}{3}\right)$ | 大量独立观测求和由 **CLT** 主导，对称正态极限 |
| $M_n = \max X_i$（$X_i \stackrel{\text{iid}}{\sim} U(0, \theta)$） | $\text{MSE}(M_n) = O(n^{-2}) \to 0$ | $n$ | $W_n = \frac{n(\theta - M_n)}{\theta} \xrightarrow{d} \text{Exp}(1)$ | 由最靠近右端点的极值决定，$\sqrt{n}$ 放大退化为 $0$，$n$ **倍放大呈单侧指数极限** |
| **Logistic 系数** $\hat{\beta}_1$（每组 $m$ 个） | LLN + 连续映射定理 | $\sqrt{m}$ | $\sqrt{m}(\hat{\beta}_1 - \beta_1) \xrightarrow{d} N\left(0, \frac{1}{p_0(1-p_0)} + \frac{1}{p_1(1-p_1)}\right)$ | 每组比例由 CLT + **一阶 Delta 方法**（$\text{logit}'(p) = \frac{1}{p(1-p)}$），两组独立方差相加 |
| **样本均值平方** $\bar{X}_n^2$（$X_i \stackrel{\text{iid}}{\sim} N(\mu, \sigma^2)$） | LLN + 连续映射定理 | $\mu \neq 0$ 时为 $\sqrt{n}$；$\mu = 0$ 时为 $n$ | $\mu \neq 0$: $\sqrt{n}(\bar{X}_n^2 - \mu^2) \xrightarrow{d} N(0, 4\mu^2\sigma^2)$；$\mu = 0$: $\frac{n\bar{X}_n^2}{\sigma^2} \sim \chi_1^2$ | $\bar{X}_n^2 - \mu^2 = 2\mu(\bar{X}_n - \mu) + (\bar{X}_n - \mu)^2$：**当** $\mu = 0$ **时一阶导数** $g'(0) = 0$**，一阶项消失，由平方项主导呈** $\chi_1^2$ **分布！** |

:::note[定理（Uniform 最大值 $M_n$ 的非正态 $\text{Exp}(1)$ 极限完整证明，Slides 61–62）]
设 $X_1, \dots, X_n \stackrel{\text{iid}}{\sim} U(0, \theta)$，$M_n = \max_{1 \le i \le n} X_i$，令 $W_n = \frac{n(\theta - M_n)}{\theta} \in [0, n]$。

* 对任意 $t < 0$，$F_{W_n}(t) = P_\theta(W_n \le t) = 0$；

* 对任意固定的 $t \ge 0$，当 $n > t$ 时，先求尾概率：

  $$

  P_\theta(W_n > t) = P_\theta\left(M_n < \theta\left(1 - \frac{t}{n}\right)\right) = \prod_{i=1}^n P_\theta\left(X_i < \theta\left(1 - \frac{t}{n}\right)\right) = \left(1 - \frac{t}{n}\right)^n \xrightarrow{n \to \infty} e^{-t}

  $$

  故分布函数 $F_{W_n}(t) = 1 - \left(1 - \frac{t}{n}\right)^n \to 1 - e^{-t}\ (t \ge 0)$，即 $W_n \xrightarrow{d} \text{Exp}(1)$！

  :::

## 三、区间估计：精确置信区间、渐近置信区间与正态样本独立性（4.3 节）

### 3.1 置信区间的定义与置信水平 $1 - \alpha$ 的正确解释

1. **置信区间（Confidence Interval）与覆盖概率（Slides 73–75）**：

   设统计量 $L_n(X) \le U_n(X)$ **只依赖样本、不含未知参数** $\theta$，构成随机区间 $C_n(X) = [L_n(X), U_n(X)]$：

   * **有限样本** $1 - \alpha$ **置信区间**：对所有 $\theta \in \Theta$ 恒有 $P_\theta\big(\theta \in C_n(X)\big) \ge 1 - \alpha$（若等号恒成立，称覆盖率精确为 $1 - \alpha$）；

   * **渐近** $1 - \alpha$ **置信区间**：对每个固定的 $\theta \in \Theta$，有 $\liminf_{n \to \infty} P_\theta\big(\theta \in C_n(X)\big) \ge 1 - \alpha$。

2. **95% 置信区间的标准表述（概念辨析，Slide 73）**：

   * **抽样之前**：$C_n(X) = [\bar{X}_{64} - 0.98,\, \bar{X}_{64} + 0.98]$ 的两个端点是随机变量，$\mu$ 是固定常数，$P_\mu(\mu \in C_{64}(X)) = 0.95$ 是该**区间构造方法**在重复抽样下的覆盖概率；

   * **抽样之后**：代入数据算出的具体区间 $[49.02, 50.98]$ 是两个确定的实数，$\mu$ 也是固定的常数，“$\mu \in [49.02, 50.98]$”要么为真（概率 1）、要么为假（概率 0），**95% 属于构造区间的方法，而不是某个已算出数值区间的概率**！

   * **常用标准正态双侧临界值** $z_{1-\alpha/2} = \Phi^{-1}(1 - \alpha/2)$：90% 置信度取 $1.645$；95% 置信度取 $1.96$；99% 置信度取 $2.576$。

### 3.2 正态型渐近置信区间定理（Theorem 6.16）及证明

:::important[Theorem 6.16（正态型置信区间通用定理，Slides 76–78）]
设 $T_n = T_n(X)$ 是 $\theta$ 的估计量，$s_n = s_n(X)$ 是由数据算出的估计标准误（满足 $P_\theta(s_n > 0) = 1$）。若在 $P_\theta$ 下标准化统计量满足：

$$

Z_n = \frac{T_n - \theta}{s_n} \xrightarrow{d} N(0, 1)

$$

则对 $0 < \alpha < 1$，令 $z = z_{1-\alpha/2} = \Phi^{-1}(1 - \alpha/2)$，构造正态型置信区间：

$$

C_n(X) = \big[T_n - z_{1-\alpha/2}\, s_n,\ T_n + z_{1-\alpha/2}\, s_n\big]

$$

必满足 $\lim_{n \to \infty} P_\theta\big(\theta \in C_n(X)\big) = 1 - \alpha$。

:::

**证明（两步严格推导，Slides 77–78）**：

1. **覆盖事件的等价变形**：在 $\{s_n > 0\}$ 上，将不等式链中的未知参数 $\theta$ 与估计量 $T_n$ 互换：

   $$

   \{\theta \in C_n\} = \{T_n - z s_n \le \theta \le T_n + z s_n\} = \{-z s_n \le T_n - \theta \le z s_n\} = \left\{-z \le \frac{T_n - \theta}{s_n} \le z\right\} = \{-z \le Z_n \le z\}

   $$

   故对每个 $n$ 恒有 $P_\theta(\theta \in C_n) = P_\theta(-z \le Z_n \le z) = F_n(z) - P_\theta(Z_n < -z)$（其中 $F_n(x) = P_\theta(Z_n \le x)$）。

2. **由分布收敛导出覆盖率极限**：因标准正态分布函数 $\Phi(x)$ 处处连续，由 $Z_n \xrightarrow{d} N(0, 1)$ 知右端点 $F_n(z) \to \Phi(z)$；对左端点严格不等号，任取 $\delta > 0$，利用单调性夹逼 $F_n(-z - \delta) \le P_\theta(Z_n < -z) \le F_n(-z)$，先令 $n \to \infty$ 再令 $\delta \downarrow 0$ 并由 $\Phi$ 连续性得 $P_\theta(Z_n < -z) \to \Phi(-z)$。因此：

   $$

   \lim_{n \to \infty} P_\theta(\theta \in C_n) = \Phi(z) - \Phi(-z) = \left(1 - \frac{\alpha}{2}\right) - \frac{\alpha}{2} = 1 - \alpha \quad \blacksquare

   $$

### 3.3 正态样本均值与样本方差独立性的正交变换证明（Slides 95–100）

为什么正态总体方差 $v = \sigma^2$ 未知时，样本均值与样本方差能够组合成精确的 $t_{n-1}$ 分布？这源于正态分布独有的**样本均值与样本方差独立定理**！

:::important[定理 3.1（正态样本的 $\bar{X}_n \perp\!\!\!\perp S_n^2$ 与卡方分布定理，Slides 95–97）]
设 $X_1, \dots, X_n \stackrel{\text{iid}}{\sim} N(\mu, v)\ (n \ge 2,\ v = \sigma^2 > 0)$，记样本无偏方差 $S_n^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X}_n)^2$，MLE 方差 $\hat{v}_n = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X}_n)^2 = \frac{n-1}{n}S_n^2$。则：

1. **独立性**：$\bar{X}_n \perp\!\!\!\perp S_n^2$（等价地，$\bar{X}_n \perp\!\!\!\perp \hat{v}_n$）；

2. **精确卡方分布**：$W_n \triangleq \frac{(n-1)S_n^2}{v} = \frac{n\hat{v}_n}{v} \sim \chi_{n-1}^2$。

   :::

   **证明（极其漂亮的三步正交变换法，Slides 96–97）**：

3. **标准化**：令 $Z_i = \frac{X_i - \mu}{\sqrt{v}}\ (i=1,\dots,n)$，则随机向量 $Z = (Z_1, \dots, Z_n)^\mathsf{T} \sim N_n(0, I_n)$。

4. **沿均值方向作正交变换**：取 $n \times n$ 正交矩阵 $Q$（满足 $Q Q^\mathsf{T} = I_n$），使其第一行为单位向量 $\left(\frac{1}{\sqrt{n}}, \frac{1}{\sqrt{n}}, \dots, \frac{1}{\sqrt{n}}\right)$（将其扩充为 $\mathbb{R}^n$ 的标准正交基即可）。令 $Y = Q Z$，则：

   $$

   Y \sim N_n(0, Q I_n Q^\mathsf{T}) = N_n(0, I_n) \implies Y_1, Y_2, \dots, Y_n \stackrel{\text{iid}}{\sim} N(0, 1)

   $$

   且第一个分量恰为标准化的样本均值：

   $$

   Y_1 = \frac{1}{\sqrt{n}}\sum_{i=1}^n Z_i = \frac{\sqrt{n}(\bar{X}_n - \mu)}{\sqrt{v}}

   $$

5. **利用正交保长性分解平方和**：因为正交变换保持欧氏范数不变（$\sum_{j=1}^n Y_j^2 = \|Y\|_2^2 = \|Z\|_2^2 = \sum_{i=1}^n Z_i^2$），移项并利用恒等式 $\sum_{i=1}^n (X_i - \mu)^2 = \sum_{i=1}^n (X_i - \bar{X}_n)^2 + n(\bar{X}_n - \mu)^2$ 得：

   $$

   \sum_{j=2}^n Y_j^2 = \sum_{i=1}^n Z_i^2 - Y_1^2 = \frac{1}{v}\left\{\sum_{i=1}^n (X_i - \mu)^2 - n(\bar{X}_n - \mu)^2\right\} = \frac{1}{v}\sum_{i=1}^n (X_i - \bar{X}_n)^2 = \frac{n\hat{v}_n}{v} = \frac{(n-1)S_n^2}{v}

   $$

   * **结论 ①**：$\sum_{j=2}^n Y_j^2$ 是 $n - 1$ 个独立同分布 $N(0, 1)$ 随机变量的平方和，故 $\frac{n\hat{v}_n}{v} = \frac{(n-1)S_n^2}{v} \sim \chi_{n-1}^2$！

   * **结论 ②**：$\bar{X}_n = \mu + \sqrt{\frac{v}{n}} Y_1$ **只依赖** $Y_1$，而 $\hat{v}_n$（及 $S_n^2$）**只依赖** $(Y_2, \dots, Y_n)$；因为 $Y_1 \perp\!\!\!\perp (Y_2, \dots, Y_n)$，它们的函数也必然相互独立，即 $\bar{X}_n \perp\!\!\!\perp \hat{v}_n$ 且 $\bar{X}_n \perp\!\!\!\perp S_n^2$！$\blacksquare$
